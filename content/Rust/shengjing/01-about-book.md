# 关于本书

Rust 连续多年位居「最受欢迎语言」之列：无 GC、无需手动内存管理、性能接近 C/C++、安全性高、Cargo 生态成熟。但也有人认为「Rust 太难、学了也没用」。

本书的定位是**降低学习门槛**：若以找工作论，国内 Rust 岗位仍在增长期；若以提升编程功底或参与开源论，Rust 值得投入。若简介尚不足以打动你，建议先读 [进入 Rust 编程世界](https://beatai.org/rust-course/into-rust)。

## 创作说明

全书 170+ 章、110 余万字，章节均为手工撰写。选择开源而非出版，是希望为 Rust 在国内的普及尽一份力；读者的一颗 🌟 也是作者持续更新的动力。
