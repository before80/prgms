# 进入 Rust 编程世界

## Rust 发展历程

Graydon Hoare 2006 年起在 Mozilla 资助下开发 Rust，2015 年 5 月 15 日发布 1.0。相较 Go（2009 发布、2012 即 1.0），Rust 打磨更久，原因包括：语言特性复杂需全盘权衡、社区意见多元、团队对 1.0 后不可大改的特性极为审慎。

> 趣闻：作者曾因公寓电梯程序崩溃、维修不便而「痛定思痛」——Rust 由此诞生。

## 为何需要这门语言？

**目标**：无 GC、无需手动内存管理、高性能、工程化、语言级安全，且同时获工程派与学院派认可。

**主要代价**：学习曲线陡峭；生态成熟后，入门难度会相对缓解。

### 缓解内卷

Rust 门槛接近 C++，优秀 Rust 开发者全球供不应求。掌握后具备较强不可替代性，而非可随意替换的「工具人」。

### 效率

| 维度 | 要点 |
|------|------|
| 学习 | 语法易学，难在融会贯通、排错（生命周期/借用）、标准库熟练度 |
| 运行 | 零开销抽象 + 优质库实现，正确用法下往往无需额外优化即有出色性能 |
| 开发 | 前期慢于 Go/Java；熟悉所有权与标准库后，效率与代码质量同步提升 |

### 个人收益

- **更好程序员**：深入理解内存、堆栈、引用；编译器与 Clippy 半强迫写出更优代码
- **不可替代性**：掌握成本高，岗位竞争相对缓和

### 团队收益

- 编译期严格检查 → 代码质量下限高，Review 可聚焦业务逻辑
- 工具链与 Cargo 成熟 → 适合大型协作
- Rust 开发者普遍自驱性强，对团队有带动效应

### 开源主战场

- **前端/WASM**：swc、deno、Next.js 押宝 Rust
- **基础设施**：数据库、搜索引擎、云原生大量 Rust 项目
- **系统**：Linux 内核纳入 Rust（继 C 后第二门内核语言）；ripgrep、bat、fd 等工具重写潮
- **区块链**：Rust 份额领先

### 与其他语言简比

| 语言 | Rust 相对优势 |
|------|---------------|
| Go | 表达力更强、线程安全更好、包管理更完善 |
| C++ | 性能相当，安全性与第三方库质量更可控 |
| Java | 多数场景性能更优、内存占用更小 |
| Python | 性能完胜，适用面互补 |

### 行业采用（节选）

AWS（Lambda/Fargate、Bottlerocket、Nitro）、Cloudflare、Dropbox、Google/Fuchsia、Meta、Microsoft Azure、GitHub/npm、TiDB 等。AWS 已将 Rust 提升至 **first-class** 地位。

## 版本发布节奏

- 每 **6 周** 一个 stable 小版本
- 每 **2–3 年** 一个 Edition（2015 / 2018 / 2021 / 2024）

## 总结

连续数年「最受欢迎」并非偶然。语言只是工具，不必神化，但值得给一次机会。
