# 入门 {#getting-started}


> 原文链接: [https://rust-lang.github.io/async-book/01_getting_started/01_chapter.html](https://rust-lang.github.io/async-book/01_getting_started/01_chapter.html)


欢迎阅读《Rust 异步编程》！如果你想开始学习编写异步 Rust 代码，你来对地方了。无论你是在构建 Web 服务器、数据库还是操作系统，本书都会向你展示如何使用 Rust 的异步编程工具，充分发挥硬件性能。

## 本书涵盖的内容

本书旨在成为一份全面、与时俱新的指南，介绍如何使用 Rust 的异步语言特性与库，适合初学者和有经验的开发者。

- 前几章对异步编程进行总体介绍，并讲解 Rust 的独特做法。

- 中间章节讨论编写异步代码时可用的关键工具与控制流，并描述如何组织库与应用以最大化性能与可复用性。

- 本书最后一部分介绍更广泛的异步生态，并提供完成常见任务的若干示例。

介绍就到这里，让我们一起探索 Rust 异步编程的精彩世界吧！
