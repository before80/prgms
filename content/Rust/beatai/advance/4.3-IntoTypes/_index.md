# 深入类型

　Rust 是强类型语言，同时也是强安全语言，这些特性导致了 Rust 的类型注定比一般语言要更深入也更困难。

　本章将深入讲解一些进阶的 Rust 类型以及类型转换，希望大家喜欢。
