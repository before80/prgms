# 官方 Rust 书籍

下列书籍维护于 [rust-lang.org](https://www.rust-lang.org/)。
其中许多也出现在 [Learn Rust](https://www.rust-lang.org/learn) 中。

## 入门

* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) — 用可运行示例说明 Rust 概念
* [*Rustlings*](https://github.com/rust-lang/rustlings) — 小型练习，帮助熟悉读写 Rust 代码
* [The Rust Programming Language](https://doc.rust-lang.org/book/) — 「那本」书

## 核心

* [The Cargo Book](https://doc.rust-lang.org/cargo/index.html) — Rust 包管理器
* [The Edition Guide](https://doc.rust-lang.org/edition-guide/index.html) — 如何向 Rust 语言引入变更的指南
* [The rustc Book](https://doc.rust-lang.org/rustc/index.html) — Rust 编程语言编译器指南
* [The rustdoc Book](https://doc.rust-lang.org/stable/rustdoc/) — 为 Rust 项目生成文档的工具指南
* [The rustup Book](https://rust-lang.github.io/rustup/index.html) — 从发行通道安装 Rust 语言的工具指南

## 进阶

* [Guide to Rustc Development](https://rustc-dev-guide.rust-lang.org/) — 编译器内部原理
* [Rust Forge](https://forge.rust-lang.org/) — Rust 团队文档
* [The Rust Reference](https://doc.rust-lang.org/reference/) — Rust 语言的主要参考
* [The Rust Unstable Book](https://doc.rust-lang.org/unstable-book/) — 仅限 nightly 的特性
* [The Rustonomicon](https://doc.rust-lang.org/nomicon/) — unsafe Rust 的黑暗艺术
* [Unsafe Code Guidelines Reference](https://rust-lang.github.io/unsafe-code-guidelines/) — `unsafe` 编码实践

## 工作组

* [*Compiler team working groups*](https://rust-lang.github.io/compiler-team/working-groups/) — 工作组列表
* [Const Generics Project Group](https://rust-lang.github.io/project-const-generics/index.html) — const generics 特性的设计与实现
* [Rust Project Goals](https://rust-lang.github.io/rust-project-goals/) — Rust 项目目标跟踪
* [Standard library developers Guide](https://std-dev-guide.rust-lang.org/about.html)
* [The Rust Language Design Team](https://lang-team.rust-lang.org/design_notes.html) — 与语言团队工作相关的信息
* [The Types Team](https://rust-lang.github.io/types-team/) — traits 实现方面的改进
* [wg-async](https://rust-lang.github.io/wg-async/) — 异步 I/O 基础

## 倡议项目

* [async fn fundamentals initiative](https://rust-lang.github.io/async-fundamentals-initiative/index.html)
* [Dyn upcast initiative](https://rust-lang.github.io/dyn-upcasting-coercion-initiative/index.html)
* [Generic Associated Types Initiative](https://rust-lang.github.io/generic-associated-types-initiative/index.html)
* [Impl trait initiative](https://rust-lang.github.io/impl-trait-initiative/index.html)

## 其他

* [Asynchronous Programming in Rust](https://rust-lang.github.io/async-book/) — 非阻塞协程
* [cargo-bisect-rustc](https://rust-lang.github.io/cargo-bisect-rustc/) — 自动下载并二分 rustc 产物与测试，直至找到给定回归的工具
* [Clippy Documentation](https://doc.rust-lang.org/nightly/clippy/development/infrastructure/book.html) — 面向程序员的代码 lint
* [Criterion.rs](https://bheisler.github.io/criterion.rs/book/getting_started.html) — 基于统计的微基准测试
* [Error Codes Index](https://doc.rust-lang.org/stable/error_codes/error-index.html) — Rust 编译器发出的全部错误码列表
* [mdBook](https://rust-lang.github.io/mdBook/) — 用 Markdown 撰写、渲染并托管书籍
* [Polonius](https://rust-lang.github.io/polonius/) — 实验性借用检查器 crate
* [Rust API Guidelines](https://rust-lang.github.io/api-guidelines/) — 如何设计与呈现 API
* [Rust RFCs](https://rust-lang.github.io/rfcs/) — 针对 Rust 变更的征求意见（RFC）列表
* [The Chalk Book](https://rust-lang.github.io/chalk/book/) — Rust 新的 trait 系统实现
* [The `bindgen` User Guide](https://rust-lang.github.io/rust-bindgen/) — 自动为 C 与 C++ 库生成 Rust FFI 绑定
