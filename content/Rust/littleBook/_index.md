# Rust 小书之书

本书是一份 Rust 书籍宝库，收录：

* [官方书籍](./official-rust-books/)（维护于 [rust-lang.org](https://www.rust-lang.org/)）
* [非官方书籍](./unofficial-rust-books/)（维护于其他站点）
* [应用类书籍](./rust-application-books/)（面向特定 Rust 应用）

若你还知道其它好书，不妨提交一个 [pull request](https://github.com/lborb/book#pull-requests)？

未采用 [mdbook](https://github.com/rust-lang/mdBook) 格式的书名会以 *斜体* 标出。
其它格式的更多书籍，见 [Rust Books](https://github.com/sger/RustBooks)。
