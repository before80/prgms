# Rust 应用类书籍

## Rust 的应用

* [*An Introduction to Chip-8 Emulation using the Rust Programming Language*](https://github.com/aquova/chip8-book/releases) — PDF 书籍
* [A thoughtful introduction to the pest parser](https://pest.rs/book/) — 用于编写纯文本解析器的库
* [Build a Lua Interpreter in Rust](https://wubingzheng.github.io/build-lua-in-rust/en/)
* [Book of crosvm](https://google.github.io/crosvm/) — 托管式（又称 type-2）虚拟机监视器
* [Cross-platform Rust Components](https://mozilla.github.io/application-services/book/index.html) — 用于 Firefox 集成的 Rust 组件
* [Create Your Own Programming Language with Rust](https://createlang.rs/)
* [`delta`](https://dandavison.github.io/delta/introduction.html) — 为 git、diff 与 grep 输出提供语法高亮的分页器
* 嵌入式
  * [Anachro](https://anachro.computer/) — 面向微控制器的网络协议与 PC 架构
  * [Discovery](https://docs.rust-embedded.org/discovery/) — 使用 F3 Discovery 开发板与 Rust
  * [The Rust on ESP Book](https://esp-rs.github.io/book/)
* 游戏开发
  * [Amethyst Game Engine](https://book.amethyst.rs/stable/)
  * [*BEVY The Book*](https://bevyengine.org/learn/book/introduction/) — 数据驱动的游戏引擎
  * [DMG-01: How to Emulate a Game Boy](https://rylev.github.io/DMG-01/public/book/)
  * [Emergent AI](https://psichix.github.io/emergent/) — 智能代理与事件
  * [Fyrox Cheat Book](https://fyrox-book.github.io/) — 通用游戏引擎
  * [Roguelike Tutorial - In Rust](https://bfnightly.bracketproductions.com/) — [Roguelike](https://en.wikipedia.org/wiki/Roguelike) 游戏开发
  * [Rust sokoban](https://sokoban.iolivia.me/) — 益智游戏
  * [The Specs Book](https://specs.amethyst.rs/docs/tutorials/) — [实体–组件–系统（ECS）](https://en.wikipedia.org/wiki/Entity_component_system) 与 Specs API 入门
  * [Writing NES Emulator in Rust](https://bugzmanov.github.io/nes_ebook/index.html) — NES 即任天堂娱乐系统游戏平台
* GPU 开发
  * [Rust GPU Dev Guide](https://embarkstudios.github.io/rust-gpu/book/)
* GraphQL
  * [Async-graphql Book](https://async-graphql.github.io/async-graphql/en/index.html) — GraphQL 服务端库
  * [Cynic - A GraphQL Client For Rust](https://cynic-rs.dev/)
  * [Juniper - GraphQL Server for Rust](https://graphql-rust.github.io/)
* GUI 开发
  * [Druid](https://linebender.org/druid/)
  * [GUI development with Relm4](https://relm4.org/book/stable/)
  * [GUI development with Rust and GTK 4](https://gtk-rs.org/gtk4-rs/stable/latest/book/)
  * [SixtyFPS Memory Game Tutorial (Rust)](https://sixtyfps.io/releases/0.1.4/docs/tutorial/rust/) — 使用 SixtyFPS GUI 工具包的教程
* [*Hypervisor in 1000 lines*](https://1000hv.seiya.me/en/)
* [intermezzOS OS](http://intermezzos.github.io/book/second-edition/)
* [*nalgebra*](https://nalgebra.org/docs/) — 线性代数库
* [OpenPGP Card](https://openpgp-card.gitlab.io/guide/)
* [Plotly.rs](https://plotly.github.io/plotly.rs/content/getting_started.html)
* [PNGme: An Intermediate Rust Project](https://jrdngr.github.io/pngme_book/)
* [Prusti user guide](https://viperproject.github.io/prusti-dev/user-guide/) — Rust 验证器
* [Rama Proxy](https://ramaproxy.org/book/) — 模块化服务框架
* [Scaphandre](https://hubblo-org.github.io/scaphandre-documentation/index.html) — 专注于能耗监测的代理
* [*SeaORM*](https://www.sea-ql.org/SeaORM/docs/index) — 异步、动态 ORM
* [Serde](https://serde.rs/) — **ser**ialize（序列化）与 **de**serialize（反序列化）Rust 数据结构
* [Stakker actor runtime guide](https://uazu.github.io/stakker/about.html) — 低层、单线程 actor 运行时
* [Tealdeer User Manual](https://dbrgn.github.io/tealdeer/) — [tldr](https://github.com/tldr-pages/tldr) 的实现（类似 `man`，但更易上手）
* [*The DNS Protocol*](https://github.com/EmilHernvall/dnsguide/blob/master/chapter1.md)
* [The Nom Guide (Nominomicon)](https://tfpk.github.io/nominomicon/) — 解析器组合子库
* [The Redox Operating System](https://doc.redox-os.org/book/)
* [Thesus OS](https://theseus-os.github.io/Theseus/book/index.html)
* [*Writing an OS in Rust*](https://os.phil-opp.com/)
* [The Zebra Book](https://zebra.zfnd.org/)
