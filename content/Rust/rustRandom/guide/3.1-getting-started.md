> 原文链接: [https://rust-random.github.io/book/guide-start.html](https://rust-random.github.io/book/guide-start.html)

如果尚未安装，请先[安装 Rust](https://www.rust-lang.org/learn/get-started)。

接下来，创建一个新 crate 并将 rand 添加为依赖：
```sh
cargo new randomly
cd randomly
cargo add rand 
```

现在，将以下内容粘贴到 `src/main.rs`：
```rust
use rand::prelude::*;

fn main() {
    let mut rng = rand::rng();

    println!("Random die roll: {}", rng.random_range(1..=6));
    println!("Random UUID: 0x{:X}", rng.random::<u128>());

    if rng.random() {
        println!("You got lucky!");
    }
}
```

运行起来：
```sh
$ cargo run
   Compiling [..]
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.99s
     Running `target/debug/randomly`
Random die roll: 4
Random UUID: 0xEC3936A465339F8295EE11AB853CCDBF
You got lucky!
```
