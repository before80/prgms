# 1 欢迎

我们已经讲过 Rust 的基础：

- **基本类型：** 整数、布尔值、字符、元组与数组。
- **控制流：** `if` 表达式、循环与 `match` 表达式。
- **函数：** 如何定义与调用函数。
- **用户自定义类型：** 用 `struct` 与 `enum` 建模数据。
- **引用：** 用 `&` 与 `&mut` 做基本借用（borrowing）。

现在你可以构造 Rust 中的任意类型，并实现基本逻辑了！
