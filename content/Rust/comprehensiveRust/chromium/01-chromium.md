# 1 欢迎

Chromium 对第三方库支持 Rust，并用第一方胶水代码连接 Rust 与现有的 Chromium C++ 代码。

> 今天，我们将调用 Rust 对字符串做点傻事。如果你的代码角落里有要向用户显示 UTF-8 字符串的地方，欢迎在你那部分代码库中按本配方操作，而不必拘泥于我们讨论的具体位置。
