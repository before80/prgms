# 2 代码示例

本培训主要通过可在浏览器中执行的示例来探索 Rust 语言。这样安装更简单，也能保证每个人体验一致。

仍建议安装 Cargo：做练习时会更方便。最后一天会有一个更大的练习，演示如何使用依赖，那时需要 Cargo。

本课程中的代码块是完全可交互的：

```rust
// Copyright 2022 Google LLC
// SPDX-License-Identifier: Apache-2.0
fn main() {
    println!("Edit me!");
}
```

焦点在文本框中时，可用 <kbd>Ctrl</kbd> + <kbd>Enter</kbd> 执行代码。

> 多数代码示例可像上面那样编辑。少数因各种原因不可编辑：
>
> - 嵌入式 Playground 无法执行单元测试。请把代码复制到真正的 Playground 中打开，以演示单元测试。
>
> - 嵌入式 Playground 一旦离开页面就会丢失状态！因此学员应在本地 Rust 环境或 Playground 中完成练习。
