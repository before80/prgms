# 2 键盘快捷键

mdBook 中有若干实用键盘快捷键：

- <kbd>Arrow-Left</kbd>：转到上一页。
- <kbd>Arrow-Right</kbd>：转到下一页。
- <kbd>Ctrl</kbd> + <kbd>Enter</kbd>：执行当前获得焦点的代码示例。
- <kbd>s</kbd>：激活搜索栏。

> - 说明这些快捷键是 `mdbook` 的标准功能，浏览任何 `mdbook` 生成的站点时都可能用得上。
> - 你可以当场向学员演示每个快捷键。
> - 用 <kbd>s</kbd> 搜索特别实用，能快速找回先前讨论过的主题。
> - <kbd>Ctrl</kbd> + <kbd>Enter</kbd> 对你尤其重要，因为你会做大量现场编码。
