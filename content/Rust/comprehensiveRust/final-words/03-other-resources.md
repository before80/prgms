# 3 其他资源

Rust 社区在线创作了大量高质量、免费的资源。

## 官方文档

Rust 项目托管了许多资源，涵盖 Rust 的通用主题：

- [The Rust Programming Language](https://doc.rust-lang.org/book/)：关于 Rust 的权威免费书籍，详细介绍语言并包含若干供读者构建的项目。
- [Rust By Example](https://doc.rust-lang.org/rust-by-example/)：通过一系列示例展示不同 Rust 语法结构，有时包含小型练习，要求你扩展示例中的代码。
- [Rust Standard Library](https://doc.rust-lang.org/std/)：Rust 标准库的完整文档。
- [The Rust Reference](https://doc.rust-lang.org/reference/)：一本尚未完稿的书，描述 Rust 语法与内存模型。
- [Rust API Guidelines](https://rust-lang.github.io/api-guidelines/)：API 设计建议。

官方 Rust 站点上还托管了更多专题指南：

- [The Rustonomicon](https://doc.rust-lang.org/nomicon/)：涵盖 unsafe Rust，包括使用原始指针及与其他语言（FFI）交互。
- [Asynchronous Programming in Rust](https://rust-lang.github.io/async-book/)：介绍在《Rust 程序设计语言》成书之后出现的异步编程模型。
- [The Embedded Rust Book](https://doc.rust-lang.org/stable/embedded-book/)：介绍在无操作系统的嵌入式设备上使用 Rust。

## 非官方学习材料

以下是 Rust 指南与教程的一小部分精选：

- [Learn Rust the Dangerous Way](http://cliffle.com/p/dangerust/)：从底层 C 程序员的视角讲解 Rust。
- [Rust for Embedded C Programmers](https://opentitan.org/book/doc/rust_for_c_devs.html)：从用 C 编写固件的开发者视角讲解 Rust。
- [Rust for professionals](https://overexact.com/rust-for-professionals/)：通过与 C、C++、Java、JavaScript、Python 等语言的并排对比讲解 Rust 语法。
- [Rust on Exercism](https://exercism.org/tracks/rust)：100 多道练习帮助学习 Rust。
- [Ferrous Teaching Material](https://ferrous-systems.github.io/teaching-material/index.html)：一系列小型演示，涵盖 Rust 语言的基础与进阶部分，还包括 WebAssembly、async/await 等主题。
- [Advanced testing for Rust applications](https://rust-exercises.com/advanced-testing/)：超越 Rust 内置测试框架的自定进度工作坊，涵盖 `googletest`、快照测试、mock，以及如何编写自定义测试 harness。
- [Beginner's Series to Rust](https://docs.microsoft.com/en-us/shows/beginners-series-to-rust/) 与 [Take your first steps with Rust](https://docs.microsoft.com/en-us/learn/paths/rust-first-steps/)：面向新开发者的两份 Rust 指南。前者是 35 集视频，后者是 11 个模块，涵盖 Rust 语法与基本构造。
- [Learn Rust With Entirely Too Many Linked Lists](https://rust-unofficial.github.io/too-many-lists/)：通过实现多种链表结构，深入探讨 Rust 内存管理规则。
- [The Little Book of Rust Macros](https://danielkeep.github.io/tlborm/)：以实用示例涵盖 Rust 宏的许多细节。

更多 Rust 书籍请参见 [Little Book of Rust Books](https://lborb.github.io/book/)。
