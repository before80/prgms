# 2.2.1.2 Is

检查数据类型上的某个条件。

```rust
// Copyright 2025 Google LLC
// SPDX-License-Identifier: Apache-2.0
impl<T> Vec<T> {
    fn is_empty(&self) -> bool;
}

impl f32 {
    fn is_nan(self) -> bool;
}

impl u32 {
    fn is_power_of_two(self) -> bool;
}
```

> - 对某个值的布尔条件。
>
> - 比起名称中带 `not` 的方法，更偏好 `is` 前缀。标准库方法中没有 `is_not_` 的实例，直接用 `!value.is_[condition]`。
