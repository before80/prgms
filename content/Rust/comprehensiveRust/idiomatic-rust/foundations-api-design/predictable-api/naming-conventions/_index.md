# 2.2.1 命名约定

> - 可读性与可预测性的一个核心要素，是函数名的构成方式。
>
> 正式且一致应用的命名约定，让开发者能把名称当作领域特定语言，快速理解方法的功能与用例。
>
> Rust 社区很早就形成了命名约定，使得标准库等处大多保持一致。
>
> - 这里我们将学习 Rust 方法名的常见组成部分，给出标准库中的例子，并附上相关语境。
