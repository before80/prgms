# Windows 环境配置 {#windows-setup}


> 原文链接: [https://rust-fuzz.github.io/book/cargo-fuzz/windows/setup.html](https://rust-fuzz.github.io/book/cargo-fuzz/windows/setup.html)


可以在 Windows 上使用 cargo-fuzz 对 Rust 代码进行模糊测试。本指南说明如何在 Windows 系统上安装并运行 cargo-fuzz。

## 1. 安装 Visual Studio

确保已安装 Visual Studio；模糊测试代码的构建还需要一并安装若干组件。
按[此指南](https://learn.microsoft.com/en-us/visualstudio/install/install-visual-studio)
安装「Visual Studio Installer」。使用它确保已安装以下单独组件：

* MSVC v143 - VS 2022 C++ x64/x86 生成工具
    * （撰写本文时此为最新版本——若你阅读时已有更新版本，可安装更新的版本！）
* C++ AddressSanitizer

## 2. 配置 PowerShell

为使构建成功且部分 cargo-fuzz 命令可用，某些目录必须位于 PowerShell 系统 `$env:PATH` 中。`Developer
PowerShell for VS 2022` 和/或 `x64 Native Tools Command Prompt for VS 2022`
可能已将上述目录加入 PATH。若没有，或你使用的是其他 PowerShell，请确保将以下目录加入 shell 的
`$env:PATH`：

* `C:\Program Files\Microsoft Visual Studio\Community\VC\Tools\MSVC\<VERSION_NUMBER>\bin\Hostx86\64`
    * 其中 `<VERSION_NUMBER>` 为你已安装的 MSVC 版本。
* （可选）`C:\Program Files (x86)\Windows Kits\10\Debuggers\x64`
    * 若希望使用 [Windows
      调试器](https://learn.microsoft.com/en-us/windows-hardware/drivers/debuggercmds/windbg-overview)
      调试模糊测试目标，请添加此项。

这些路径在你的机器上可能略有不同，但要点是 shell 必须能找到基于 MSVC 的 AddressSanitizer DLL 以及其他 MSVC 相关二进制文件。
