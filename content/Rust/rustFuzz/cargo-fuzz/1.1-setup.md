# 安装 {#setup}


> 原文链接: [https://rust-fuzz.github.io/book/cargo-fuzz/setup.html](https://rust-fuzz.github.io/book/cargo-fuzz/setup.html)


## 环境要求

libFuzzer 需要 LLVM 消毒器支持；适用于 x86-64 Linux、x86-64 macOS、Apple Silicon（aarch64）macOS 以及 Windows（得益于 [MSVC AddressSanitizer][msvc-asan]）。需要支持 C++11 的 C++ 编译器。Rust 提供多种编译器。本项目需要 nightly 编译器，因为它使用 `-Z` 编译器标志以启用地址消毒。若你通过 [rustup][rustup] 安装 Rust，可用以下命令检查默认编译器：

```shell
$ rustup default
stable-x86_64-unknown-linux-gnu (default) # 不是我们需要的编译器。
```

切换到 nightly 编译器：

```shell
$ rustup install nightly
$ rustup default nightly
nightly-x86_64-unknown-linux-gnu (default) # 正确的编译器。
```

## 安装

```sh
cargo install cargo-fuzz
```

## 升级

```sh
cargo install --force cargo-fuzz
```

[rustup]: https://github.com/rust-lang/rustup
