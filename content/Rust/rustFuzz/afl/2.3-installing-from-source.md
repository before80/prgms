# 从源码安装 {#installing-from-source}


> 原文链接: [https://rust-fuzz.github.io/book/afl/installing-from-source.html](https://rust-fuzz.github.io/book/afl/installing-from-source.html)


首先克隆 afl.rs：

```sh
git clone https://github.com/rust-fuzz/afl.rs
cd afl.rs
```

接着检出 afl.rs 的子模块（[AFL++]）。注意不需要 `--recursive`。

```sh
git submodule update --init
```

最后安装 `cargo-afl`：

```sh
cargo install --path cargo-afl
```

## 故障排除

若 `cargo-afl` 发生 panic，可尝试使用 `--debug` 安装，并以 `RUST_BACKTRACE=1` 运行 `cargo-afl`，例如：

```sh
cargo install --path cargo-afl --debug
...
RUST_BACKTRACE=1 cargo afl ...
```

向 `cargo install` 添加 `--debug` 可使 `cargo-afl` 产生更详细的回溯信息。

[AFL++]: https://github.com/AFLplusplus/AFLplusplus
