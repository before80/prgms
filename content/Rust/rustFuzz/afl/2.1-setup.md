# 安装 {#afl-setup}


> 原文链接: [https://rust-fuzz.github.io/book/afl/setup.html](https://rust-fuzz.github.io/book/afl/setup.html)


## 环境要求

### 工具

- C 编译器（如 gcc 或 clang）
- make

### 平台

afl.rs 支持 x86-64 Linux、x86-64 macOS 和 ARM64 macOS。

```sh
cargo install cargo-afl
```

或者，也可以[从源码安装] `cargo-afl`。

## 升级

```sh
cargo install --force cargo-afl
```
