# 常见问题

## 如何贡献？

前往 [我们的 GitHub 页面](https://github.com/microsoft/rust-guidelines) 提交 issue 或 PR。新指南应与
[元设计原则](../about/#meta-design-principles) 兼容。

## 我不同意某条指南……

若发现错误或问题，[请告诉我们](https://github.com/microsoft/rust-guidelines)。若某条标为 _必须_ 的条目妨碍了
合理用例，也请告知。若你不同意某条标为 _应当_ 的条目，通常存在我们尚未文档化的合理例外。若你认为某条标为 _应当_ 的条目
通常会带来更差结果，请告诉我们。
