# 反模式

[反模式](https://en.wikipedia.org/wiki/Anti-pattern)是对「反复出现的问题」给出的一种解决方案，但通常无效，且很可能适得其反。与知道如何解决问题同样有价值的是，知道*不该*怎样解决。反模式为我们提供了相对于设计模式的优秀反例。反模式并不局限于代码——例如，某个流程本身也可以是一种反模式。
