# Rust 程序设计语言 {#the-rust-programming-language}


> 原文链接: [https://doc.rust-lang.org/stable/book/title-page.html](https://doc.rust-lang.org/stable/book/title-page.html)


　　_作者：Steve Klabnik、Carol Nichols 与 Chris Krycho，并得到 Rust 社区的贡献_

　　本版正文假定你使用的是 Rust 1.97.1（发布于 2026-07-09）或更新版本，并在所有项目的 *Cargo.toml* 中设置 `edition = "2024"`，以便采用 Rust 2024 Edition 的惯用法。安装或更新 Rust 的说明见[第 1 章「安装」一节](getting-started/01-installation/)；关于 Edition 的说明见[附录 E](appendix/05-e-editions/)。

　　HTML 版可在线阅读：
　　[https://doc.rust-lang.org/stable/book/](https://doc.rust-lang.org/stable/book/)
　　若通过 `rustup` 安装了 Rust，也可离线阅读：运行 `rustup doc --book` 即可打开。

　　社区还提供了若干[译本](appendix/06-f-translation/)。

　　本书亦有 [No Starch Press 出版的平装本与电子书](https://nostarch.com/rust-programming-language-3rd-edition)。

> **🚨 想要更互动的学习体验？** 可以试试另一版 Rust Book（含测验、高亮、可视化等）：<https://rust-book.cs.brown.edu>
