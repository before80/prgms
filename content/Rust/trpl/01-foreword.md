# 前言 {#foreword}


> 原文链接: [https://doc.rust-lang.org/stable/book/foreword.html](https://doc.rust-lang.org/stable/book/foreword.html)


　　短短几年间，Rust 编程语言走过了漫长的道路：从一群新兴爱好者的创造与孕育，成长为全球最受喜爱、需求最旺盛的编程语言之一。回望过去，Rust 的力量与潜力吸引目光、在系统编程领域站稳脚跟，似乎是必然的。并不必然的，是那种席卷开源社区的全球性热情与创新，以及由此催生的跨行业大规模采用。

　　时至今日，人们很容易用 Rust 那些出色的特性来解释这种兴趣与采用的爆发。谁不想要内存安全，*并且*性能出色，*并且*有友好的编译器，*并且*拥有一流的工具链，外加一长串其他优点呢？你今天所看到的 Rust，把系统编程多年的研究成果，与一个充满活力、充满热情的社区所积累的实践智慧结合在了一起。这门语言带着明确的目标被精心打磨，为开发者提供了一件更容易写出安全、快速、可靠代码的工具。

　　但真正让 Rust 与众不同的，是它植根于赋能你——使用者——去达成目标。这是一门希望你成功的语言；赋能的原则贯穿于构建、维护并倡导这门语言的社区核心。自本书上一版以来，Rust 已进一步成长为真正全球化、值得信赖的语言。Rust 项目如今得到 Rust 基金会（Rust Foundation）的有力支持；基金会也持续投入关键举措，确保 Rust 安全、稳定、可持续。

　　本版《Rust 程序设计语言》是一次全面更新，反映了这些年来语言的演进，并提供了宝贵的新内容。但它不仅是语法与库的指南——更是一封邀请函，邀请你加入一个珍视质量、性能与深思熟虑之设计的社区。无论你是首次探索 Rust 的资深开发者，还是希望精进技艺的老练 Rustacean，本版都能为你带来收获。

　　Rust 的历程，是协作、学习与迭代的历程。语言及其生态的成长，直接映照着背后那个充满活力、多元的社区。从核心语言设计者到偶一为之的贡献者，成千上万开发者的付出，造就了 Rust 这一独特而强大的工具。拿起这本书，你不只是在学习一门新的编程语言——你也在加入一场让软件更好、更安全、更令人愉悦的运动。

　　欢迎加入 Rust 社区！

　　— Bec Rumbul，Rust 基金会执行董事
