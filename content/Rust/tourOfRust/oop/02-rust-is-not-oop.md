# Rust 不是 OOP

Rust 缺乏任何有意义的数据和行为的继承。

* 结构体不能从父结构继承字段。
* 结构体不能从父结构继承函数。

尽管如此，Rust 实现了许多编程语言的特性，所以你可能不会在意这个缺失。
