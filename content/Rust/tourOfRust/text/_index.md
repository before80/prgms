# 第六章 - 文本

了解完了 Rust 内存管理的机制，是时候更为详尽地了解文本相关的内容了。
Rust 非常关注文本国际化与字节层级的问题，这意味着 Rust 有许多实用的工具来解决这些问题。虽然你可能对其它语言中的这些问题并不熟悉。
