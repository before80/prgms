# 别名涉及时的签名修改建议 {#signature-advice-aliases}


> 原文链接: [https://quinedot.github.io/rust-learning/c-signatures.html](https://quinedot.github.io/rust-learning/c-signatures.html)


[这是本指南前面出现的一个场景。](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&gist=54379d0c026ccdf73eb3fdde3292b4fb) 编译器的建议是：
```rust
error[E0621]: explicit lifetime required in the type of `s`
 --> src/lib.rs:5:9
  |
5 |         Self(s)
  |         ^^^^^^^ lifetime `'a` required
  |
help: add explicit lifetime `'a` to the type of `s`
  |
4 |     fn new(s: &'a str) -> Node<'_> {
  |                ++
```

但[这样同样有效：](https://play.rust-lang.org/?version=stable&mode=debug&edition=2024&gist=268f52ef82439f2036f787a5490aa114)
```diff
-        Self(s)
+        Node(s)
```

在实现 trait 时，你甚至可能收到上述编译器建议，而那时你通常*不能*修改签名。
