# 非引用类型 {#non-references}


> 原文链接: [https://quinedot.github.io/rust-learning/st-non-references.html](https://quinedot.github.io/rust-learning/st-non-references.html)


你自己定义的 `struct` 的生命周期和类型参数的型变，会根据你在字段中如何使用这些参数自动推断。例如，如果你有：
```rust
struct AllMine<'a, T>(&'a mut T);
```

那么 `AllMine` 在 `'a` 上是协变的，在 `T` 上是不变的，就像 `&'a mut T` 一样。
