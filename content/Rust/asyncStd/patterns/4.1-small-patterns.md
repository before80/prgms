## 拆分流

`async-std` 并未在 `io` 句柄上提供 `split()` 方法。将流拆分为读端和写端可以这样做：

```rust
# extern crate async_std;
use async_std::{io, net::TcpStream};
async fn echo(stream: TcpStream) {
    let (reader, writer) = &mut (&stream, &stream);
    io::copy(reader, writer).await;
}
```
