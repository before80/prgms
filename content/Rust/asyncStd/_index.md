> 原文链接: [https://book.async.rs/introduction.html](https://book.async.rs/introduction.html)

![async-std logo](images/horizontal_color.svg)

本书是 `async-std` 的高层文档，也是通过它学习 Rust 异步编程的途径。因此，本书聚焦于 `async-std` API 及其提供的任务模型。

请注意，Rust 项目提供了自己的异步编程书籍，名为 ["Asynchronous Programming in Rust"][async-book]（《Rust 中的异步编程》），我们强烈建议与本书一并阅读，因为它从不同的、更广阔的视角阐述这一主题。

[async-book]: https://rust-lang.github.io/async-book/
