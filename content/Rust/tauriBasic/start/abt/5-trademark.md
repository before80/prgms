这份商标政策旨在帮助你理解如何使用由 Commons Conservancy 中的 Tauri 项目所拥有的 TAURI 商标、服务标志和标识。

虽然我们的软件以自由开源软件许可证提供，但该版权许可证并不包含使用我们商标的许可。本政策的目的是说明如何在符合相关法律与社区期望的前提下使用我们的标志。

**本政策涵盖：**

- 我们的文字商标与服务标志：TAURI、TAO、WRY
- 我们的标识：TAURI、TAO、WRY 标识（以及所有视觉衍生品）

本政策涵盖所有商标与服务标志，无论是否已注册。

## 通用准则

每当你使用我们的某个标志时，都必须以不会让任何人对其所获得的东西及来源产生误解的方式进行。例如，当你在分发修改版（也就是 Fork）时，不能声称自己在分发 TAURI 软件，因为接收者可能无法理解你的修改版与我们自己的版本之间的差别。

你也不能以暗示你的网站是官方网站、或暗示我们为你的网站背书的方式，在你的网站上使用我们的标识。

不过，你可以说你喜欢 TAURI 软件、你参与了 TAURI 社区、你提供的是未经修改的 TAURI 软件版本。

你不得将我们的标志或其变体用作或注册为你自己的商标、服务标志、域名、公司名称、商业名称、产品名称或服务名称的一部分。

商标法不允许你使用与我们的名称或商标过于相似的名称或商标。因此，你不得为类似或兼容的产品或服务使用我们任何标志的明显变体、任何发音等同物、外语等同物、模仿或缩写。我们认为以下名称与我们的某个标志过于相似：

- TAURIMAGE
- Tauri Wallet App

## 可接受的使用方式

### 应用

TAURI 是一个为计算设备制作应用的框架。你可以声明你的应用使用了 TAURI，但要注意避免给人造成你的应用获得了 Commons Conservancy 中 Tauri 项目批准、或是官方应用的印象。务必注意不要用默认图标发布你的应用。

### 插件与模板

你可以使用恰当的命名约定发布插件和模板的代码，但请说明这些作品并未获得官方批准。只有在 GitHub 组织 `tauri-apps` 内由该组织管理的代码库才被视为官方项目。

## 核心修改版（Fork）

如果你分发我们软件（TAURI CORE）的修改版，你必须从中移除我们所有的标识和命名。你必须以 SPDX 格式保留我们的原始许可证。你可以使用我们的文字商标（但不能使用标识）来如实说明你所提供软件的来源。例如，如果你分发的代码是我们软件的修改版，你可以说：“本软件派生自 TAURI 软件的源代码。”

### 关于兼容性的声明

你可以使用文字商标（但不能使用标识）来如实描述你的软件与我们软件之间的关系。任何其它使用方式都可能暗示我们认证或批准了你的软件。如果你希望使用我们的标识，请联系我们商讨许可条款。

### 命名兼容产品

如果你想在提及 TAURI 软件的情况下描述你的产品，以下是你被允许这样做的条件。只有当满足以下条件时，你才可以把你的软件称为 XYZ（XYZ 为你的产品名）for TAURI：

- 你随产品一起分发的所有 TAURI 软件版本都是我们提供的精确二进制文件，或由我们提供的核心软件与工具制造而成。
- 你的产品与 TAURI 软件的 API 完全兼容。
- 你在营销材料或产品描述中使用以下声明：“TAURI is a trademark of The Tauri Programme within the Commons Conservancy. https://tauri.app/ ”

### 用户组

你可以把文字商标用作你的用户组名称的一部分，前提是：

- 该组的主要关注点是我们软件
- 该组不以营利为目的
- 参加会议所收取的任何费用仅用于覆盖场地、餐饮成本

你无权使用我们的标志举办会议。

### 不得注册域名

你不得注册任何包含我们文字商标或其任何变体、组合的域名。

### 其它营利性使用 TAURI 标志

如果你制作视频、教程系列、书籍或其它教育材料，并通过订阅、销售、广告等获得报酬，那么你必须从 Commons Conservancy 中的 Tauri 项目获得明确的许可授权。

## 如何展示我们的标志

当你拥有使用我们标志的权利时，以下是展示方式。

### 商标标注与声明

在网页、文档或文档资料中首次或最显著地提及某个标志时，应当附上一个符号，表明该标志是注册商标（“®”）还是未注册商标（“™”）。如果你不确定适用哪一种，请联系我们。（TAURI 本身就是注册商标。）

请在使用该标志的页面底部放置以下声明：TAURI is trademark of [The Tauri Programme within the Commons Conservancy]。

### 在文本中使用商标

始终以准确的形式使用商标，拼写正确，不缩写、不加连字符，也不与任何其它单词组合。

- 不可接受：TAUREE
- 可接受：TAURI

不要把商标变成复数。

- 不可接受：I have seventeen TAURIs running on my computer.
- 可接受：I am running seventeen TAURI applications on my computer and have ram to spare.

始终把商标用作修饰名词的形容词。

- 不可接受：This is a TAURI.
- 可接受：This is a TAURI software application.

### 标识的使用

除缩放外，你不得对任何标识做改动。这意味着你不得添加装饰元素、更改颜色、更改比例、使其变形、添加元素，或把它与其它标识组合。
