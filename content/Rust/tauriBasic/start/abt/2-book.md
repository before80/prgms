### 概述

《Tauri 之书》将带你了解 Tauri 的历史以及我们所做的设计决策。它还会深入讨论为什么隐私、安全和可持续性是需要认真对待且根本性的议题，这些讨论适用于任何现代软件项目。

涵盖的主题包括：

- Tauri 设计背后的方法与理由
- 使用 Tauri 构建时你可以有哪些选择
- 你不必在快速交付与可持续、负责任之间做取舍
- 我们为什么选择 Rust 语言作为 Tauri 的绑定与应用层
- 为什么二进制审查很重要

### 历史

2020 年，原生应用的制造变得比以往任何时候都更容易、更易获得。尽管如此，在快速变化的安全与隐私格局中，无论是初学者还是资深开发者都面临着艰难的抉择。在用户设备这种半可信环境中尤其如此。

Tauri 把猜测从等式中去掉：它从底层开始设计，拥抱安全开发与创造性灵活性的新范式，充分利用 Rust 的语言特性，并让你可以用任何你喜欢的前端框架来构建应用。来了解如何用完全相同的一套代码库，在创纪录的时间内为各大桌面和移动平台设计、构建、审计并发布小巧、快速、健壮且安全的应用——甚至无需懂 Rust 编程语言。

作者兼 Tauri 联合创始人 Daniel 和 Lucas 将带你从理论走到实践，在此过程中你会了解 Tauri 为何被构建以及它在底层如何工作。书中还结合了开源、DevOps、安全和企业架构领域的嘉宾洞见，以对话形式呈现哲学讨论与开源可持续性观点，你的下一代应用将从中获益——你的用户也将受益。
