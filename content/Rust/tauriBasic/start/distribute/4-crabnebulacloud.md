> 原文链接: [https://tauri.app/distribute/crabnebula-cloud/](https://tauri.app/distribute/crabnebula-cloud/)

[CrabNebula](https://crabnebula.dev) 是 Tauri 的官方合作伙伴，为 Tauri 应用提供服务和工具。
[CrabNebula Cloud](https://crabnebula.dev/cloud/) 是一个与 Tauri 更新器无缝集成的应用分发平台。

该 Cloud 提供内容分发网络（CDN），能够以高性价比的方式在全球范围分发你的应用安装包与更新，并公开下载指标。

借助 CrabNebula Cloud 服务，实现多个发布渠道、为你的应用网站提供下载按钮等等都变得很简单。

让你的 Tauri 应用使用该 Cloud 很简单：你只需用 GitHub 账号登录 [Cloud 网站](https://web.crabnebula.cloud/)，
创建你的组织和应用，并安装它的 CLI 来创建发布并上传 Tauri 打包产物。此外还提供了 [GitHub Action](https://github.com/crabnebula-dev/cloud-release/) 来简化在 GitHub workflow 中使用该 CLI 的流程。

更多信息请参阅 [CrabNebula Cloud 文档](https://docs.crabnebula.dev/cloud/)。
