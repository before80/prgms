眼尖的读者可能已经注意到，我们其实重新发明了一个很糟糕的 Option 版本：

```rust
enum Link {
    Empty,
    More(Box<Node>),
}
```

`Link` 其实就是 `Option<Box<Node>>`。当然，不必到处写 `Option<Box<Node>>` 也挺舒服；而且不像 `pop`，我们并没有把它暴露给外部，所以也许还能接受。不过 Option 有一些*非常好用*的方法，而我们一直在手动实现。咱们*别*这么干了，把所有东西都换成 Option。首先，我们天真地把所有名字改成 `Some` 和 `None`：

```rust
use std::mem;

pub struct List {
    head: Link,
}

// 类型别名，好耶！
type Link = Option<Box<Node>>;

struct Node {
    elem: i32,
    next: Link,
}

impl List {
    pub fn new() -> Self {
        List { head: None }
    }

    pub fn push(&mut self, elem: i32) {
        let new_node = Box::new(Node {
            elem: elem,
            next: mem::replace(&mut self.head, None),
        });

        self.head = Some(new_node);
    }

    pub fn pop(&mut self) -> Option<i32> {
        match mem::replace(&mut self.head, None) {
            None => None,
            Some(node) => {
                self.head = node.next;
                Some(node.elem)
            }
        }
    }
}

impl Drop for List {
    fn drop(&mut self) {
        let mut cur_link = mem::replace(&mut self.head, None);
        while let Some(mut boxed_node) = cur_link {
            cur_link = mem::replace(&mut boxed_node.next, None);
        }
    }
}
```

这稍微好一点，但真正的收益来自 Option 的方法。

首先，`mem::replace(&mut option, None)` 是如此常见的惯用法，Option 直接把它做成了一个方法：`take`。

```rust
pub struct List {
    head: Link,
}

type Link = Option<Box<Node>>;

struct Node {
    elem: i32,
    next: Link,
}

impl List {
    pub fn new() -> Self {
        List { head: None }
    }

    pub fn push(&mut self, elem: i32) {
        let new_node = Box::new(Node {
            elem: elem,
            next: self.head.take(),
        });

        self.head = Some(new_node);
    }

    pub fn pop(&mut self) -> Option<i32> {
        match self.head.take() {
            None => None,
            Some(node) => {
                self.head = node.next;
                Some(node.elem)
            }
        }
    }
}

impl Drop for List {
    fn drop(&mut self) {
        let mut cur_link = self.head.take();
        while let Some(mut boxed_node) = cur_link {
            cur_link = boxed_node.next.take();
        }
    }
}
```

其次，`match option { None => None, Some(x) => Some(y) }` 也是极其常见的惯用法，它就叫 `map`。`map` 接受一个函数，对 `Some(x)` 里的 `x` 执行，得到 `Some(y)` 里的 `y`。我们可以写一个正式的 `fn` 传给 `map`，但更想*内联*地写要做什么。

做法是用*闭包*。闭包是匿名函数，还有一个额外超能力：可以引用闭包*外部*的局部变量！这让它们非常适合做各种条件逻辑。我们唯一做 `match` 的地方在 `pop`，那就重写它：

```rust
pub fn pop(&mut self) -> Option<i32> {
    self.head.take().map(|node| {
        self.head = node.next;
        node.elem
    })
}
```
