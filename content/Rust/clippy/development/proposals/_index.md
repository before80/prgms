# 提案 {#proposals}


> 原文链接: [https://doc.rust-lang.org/nightly/clippy/development/proposals/index.html](https://doc.rust-lang.org/nightly/clippy/development/proposals/index.html)


本章收录已接受的、应在 Clippy 内外长期推进的变更提案。

除了不断添加 lint、改进现有 lint 之外，Clippy 也致力于持续改善用户、开发者与维护者的体验。处理这类「大图景」事项的项目通常耗时较长，事先撰写提案很有价值。此类提案集中存放在此处，便于推进时引用。
