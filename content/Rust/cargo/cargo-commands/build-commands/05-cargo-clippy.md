## 名称 {#name}
cargo-clippy --- 检查包以捕获常见错误并改进 Rust 代码

## 描述 {#description}
这是随 Rust 工具链分发的可选组件中的外部命令。
它并非内置于 Cargo，可能需要额外安装。

关于用法与安装，请参阅 [Clippy 文档](https://doc.rust-lang.org/clippy/)。
