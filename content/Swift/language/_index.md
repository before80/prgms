# Swift 编程语言

用一门现代的通用编程语言，写出安全、快速而又富有表现力的代码。

本书是《The Swift Programming Language》（Swift 6.4 beta）的中文译本，按原书结构分为四个部分：

- [欢迎使用 Swift](welcometoswift/) —— 语言的总体目标、兼容性说明，以及一节快速上手的语言导览。
- [语言指南](languageguide/) —— 逐个特性地讲解 Swift 语言。
- [语言参考](languagereference/) —— 用正式语法描述这门语言。
- [修订历史](revisionhistory/) —— 记录文档随版本发生的变化。
