# 2.9 使用 shell 补全脚本

定制你的 shell，让它自动补全 swift package 命令。

## 概述 {#Overview}

包管理器自带 Bash、Zsh 和 Fish 的补全脚本。为你的 shell 生成补全列表即可使用。

### Bash {#Bash}

用下面的命令把 Bash 补全安装到 `~/.swift-package-complete.bash`，并通过 `~/.bash_profile` 文件自动加载它们。

```bash
swift package completion-tool generate-bash-script > ~/.swift-package-complete.bash
echo -e "source ~/.swift-package-complete.bash\n" >> ~/.bash_profile
source ~/.swift-package-complete.bash
```

另一种做法是把下面的命令加入 `~/.bash_profile` 文件，直接加载补全：

```bash
# 加载 Swift 补全
if [ -n "`which swift`" ]; then
    eval "`swift package completion-tool generate-bash-script`"
fi
```

### Zsh {#Zsh}

用下面的命令把 Zsh 补全安装到 `~/.zsh/_swift`。你也可以选择其他文件夹，但文件名必须是 `_swift`。这还会通过 `~/.zshrc` 文件把 `~/.zsh` 加入你的 `$fpath`。

```bash
mkdir ~/.zsh
swift package completion-tool generate-zsh-script > ~/.zsh/_swift
echo -e "fpath=(~/.zsh \$fpath)\n" >> ~/.zshrc
compinit
```
