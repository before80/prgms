# 2.2 设置 Swift 工具版本

定义使用你的包所需的 Swift 编译器最低版本。

## 概述 {#Overview}

工具版本声明使用该包所需的 Swift 编译器最低版本，并决定如何解析 `Package.swift` 清单。当你用 [swift package init](../../swiftcommands/7.3-SwiftPackageCommands/7.3.1-PackageInit/) 创建新包时，最低版本会自动设为当前版本。该版本通过注释 `// swift-tools-version:` 加上 Swift 编译器版本号来指定。按照惯例，这条注释出现在清单的第一行；当指定的版本早于 6.0 时它必须如此；从 Swift 6.0 起，它也可以出现在后面的行上，例如在前导注释之后。版本号是语义化版本，唯一例外是：如果你不写补丁版本，它就推断为 `0`。

例如，下面这一行声明该包需要 Swift 编译器 6.1 或更高版本：

```swift
// swift-tools-version:6.1
```

### 解析使用不同工具版本的依赖 {#Resolving-dependencies-with-different-tools-versions}

解析包依赖时，如果某个依赖的工具版本高于当前使用的版本，那么该版本的依赖就不适用，解析会继续评估次优版本。

如果某个依赖的所有版本（在其他方面都满足包的版本要求）都不支持当前使用的 Swift 工具版本，包管理器就会给出依赖解析错误。关于为特定 Swift 版本提供包清单的更多内容，参见[按 Swift 版本打包](../2.4-SwiftVersionSpecificPackaging/)。

### 调整工具版本 {#Adjusting-the-tools-version}

编辑 `Package.swift` 来调整版本，或者用 [swift package tools-version](../../swiftcommands/7.3-SwiftPackageCommands/7.3.18-PackageToolsVersion/) 报告或设置工具版本。
