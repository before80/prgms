# 7.3.29 swift package config get-mirror
打印指定包依赖的镜像配置。它读取的是 `swift package config set-mirror` 写入的本地配置，不会联网查询。

```
package config get-mirror [--package-path=<package-path>]
  [--cache-path=<cache-path>] [--config-path=<config-path>]
  [--security-path=<security-path>]
  [--scratch-path=<scratch-path>]
  [--swift-sdks-path=<swift-sdks-path>]
  [--toolset=<toolset>...]
  [--pkg-config-path=<pkg-config-path>...]
  [--enable-dependency-cache] [--disable-dependency-cache]
  [--enable-build-manifest-caching]
  [--disable-build-manifest-caching]
  [--manifest-cache=<manifest-cache>]
  [--enable-experimental-prebuilts]
  [--disable-experimental-prebuilts] [--verbose]
  [--very-verbose|vv] [--quiet] [--color-diagnostics]
  [--no-color-diagnostics] [--disable-sandbox] [--netrc]
  [--enable-netrc] [--disable-netrc]
  [--netrc-file=<netrc-file>] [--enable-keychain]
  [--disable-keychain]
  [--resolver-fingerprint-checking=<resolver-fingerprint-checking>]
  [--resolver-signing-entity-checking=<resolver-signing-entity-checking>]
  [--enable-signature-validation]
  [--disable-signature-validation] [--enable-prefetching]
  [--disable-prefetching]
  [--force-resolved-versions|disable-automatic-resolution|only-use-versions-from-resolved-file]
  [--skip-update] [--disable-scm-to-registry-transformation]
  [--use-registry-identity-for-scm]
  [--replace-scm-with-registry]
  [--default-registry-url=<default-registry-url>]
  [--configuration=<configuration>] [--=<Xcc>...]
  [--=<Xswiftc>...] [--=<Xlinker>...] [--=<Xcxx>...]
  [--triple=<triple>] [--sdk=<sdk>] [--toolchain=<toolchain>]
  [--swift-sdk=<swift-sdk>] [--sanitize=<sanitize>...]
  [--auto-index-store] [--enable-index-store]
  [--disable-index-store]
  [--enable-parseable-module-interfaces] [--jobs=<jobs>]
  [--use-integrated-swift-driver]
  [--explicit-target-dependency-import-check=<explicit-target-dependency-import-check>]
  [--build-system=<build-system>] [--=<debug-info-format>]
  [--enable-dead-strip] [--disable-dead-strip]
  [--disable-local-rpath] [--original=<original>] [--version]
  [--help]
```

## 参数说明

- **--package-path=\<package-path\>**：

*指定要操作的包路径（默认为当前目录）。这会先切换工作目录，然后再执行其他任何操作。*

- **--cache-path=\<cache-path\>**：

*指定共享缓存目录的路径。*

- **--config-path=\<config-path\>**：

*指定共享配置目录的路径。*

- **--security-path=\<security-path\>**：

*指定共享安全目录的路径。*

- **--scratch-path=\<scratch-path\>**：

*指定自定义的临时构建目录路径。（默认 .build）*

- **--swift-sdks-path=\<swift-sdks-path\>**：

*包含已安装 Swift SDK 的目录路径。*

- **--toolset=\<toolset\>**：

*指定为目标平台构建时使用的工具集 JSON 文件。可以多次使用该选项来指定多个工具集。各个工具集会按指定顺序合并为当前构建的单个最终工具集。*

- **--pkg-config-path=\<pkg-config-path\>**：

*指定搜索 pkg-config `.pc` 文件的备用路径。可以多次使用该选项来指定多个路径。*

- **--enable-dependency-cache|disable-dependency-cache**：

*获取依赖时使用共享缓存。*

- **--enable-build-manifest-caching|disable-build-manifest-caching**：

*是否缓存构建清单（build manifest）。*

- **--manifest-cache=\<manifest-cache\>**：

*Package.swift 清单的缓存模式。可选值：shared（共享缓存）、local（包自身的构建目录）、none（禁用）。*

- **--enable-experimental-prebuilts|disable-experimental-prebuilts**：

*是否为宏使用预编译的 swift-syntax 库。*

- **--verbose**：

*提高输出详细程度，包含信息性输出。*

- **--very-verbose|vv**：

*进一步提高输出详细程度，包含调试输出。*

- **--quiet**：

*降低输出详细程度，只输出错误信息。*

- **--color-diagnostics|no-color-diagnostics**：

*在向终端输出时启用或禁用彩色诊断信息。默认情况下，连接终端时启用彩色诊断，否则禁用。*

- **--disable-sandbox**：

*执行子进程时禁用沙盒。*

- **--netrc**：

*即使存在其他更优先的凭据存储方式，也使用 netrc 文件。*

- **--enable-netrc|disable-netrc**：

*从 netrc 文件加载凭据。*

- **--netrc-file=\<netrc-file\>**：

*指定 netrc 文件的路径。*

- **--enable-keychain|disable-keychain**：

*在 macOS 钥匙串中查找凭据。*

- **--resolver-fingerprint-checking=\<resolver-fingerprint-checking\>**：

*设置依赖解析器对指纹（fingerprint）的校验级别。*

- **--resolver-signing-entity-checking=\<resolver-signing-entity-checking\>**：

*设置依赖解析器对签名主体（signing entity）的校验级别。*

- **--enable-signature-validation|disable-signature-validation**：

*校验从注册表下载的已签名发布包的签名。*

- **--enable-prefetching|disable-prefetching**：

*是否对依赖进行预取（prefetch）。*

- **--force-resolved-versions|disable-automatic-resolution|only-use-versions-from-resolved-file**：

*只使用 Package.resolved 文件中记录的版本，如果该文件已过期则解析失败。*

- **--skip-update**：

*解析依赖时跳过从远端更新依赖。*

- **--disable-scm-to-registry-transformation**：

*禁用从源代码管理（SCM）到注册表的转换。*

- **--use-registry-identity-for-scm**：

*在注册表中查找源代码管理依赖，并尽可能使用其注册表标识，以便在两种来源之间去重。*

- **--replace-scm-with-registry**：

*在注册表中查找源代码管理依赖，并尽可能改用注册表来获取它们，而不是走源代码管理。*

- **--default-registry-url=\<default-registry-url\>**：

*要使用的默认注册表 URL，替代 registries.json 配置文件。*

- **--configuration=\<configuration\>**：

*以指定的构建配置进行构建。*

- **--=\<Xcc\>**：

*把该标志透传给所有 C 编译器调用。*

- **--=\<Xswiftc\>**：

*把该标志透传给所有 Swift 编译器调用。*

- **--=\<Xlinker\>**：

*把该标志透传给所有链接器调用。*

- **--=\<Xcxx\>**：

*把该标志透传给所有 C++ 编译器调用。*

- **--triple=\<triple\>**：

*指定目标平台三元组（triple）。*

- **--sdk=\<sdk\>**：

*指定构建所用的 SDK。*

- **--toolchain=\<toolchain\>**：

*指定构建所用的工具链。*

- **--swift-sdk=\<swift-sdk\>**：

*筛选构建时要使用的特定 Swift SDK。*

- **--sanitize=\<sanitize\>**：

*开启针对错误行为的运行时检查，可选值：address、thread、undefined、scudo。*

- **--auto-index-store|enable-index-store|disable-index-store**：

*启用或禁用边构建边建立索引（indexing-while-building）功能。*

- **--enable-parseable-module-interfaces**：

*产出可解析的模块接口文件（`.swiftinterface`）。*

- **--jobs=\<jobs\>**：

*构建过程中并行执行的任务数量。*

- **--use-integrated-swift-driver**：

*使用集成在 SwiftPM 内的 Swift 驱动，而不是外部驱动。*

- **--explicit-target-dependency-import-check=\<explicit-target-dependency-import-check\>**：

*该标志指示本次构建是否应检查各个 target 是否只导入了显式声明的依赖。*

- **--build-system=\<build-system\>**：

*指定构建系统（默认 native，可选 xcode）。*

- **--=\<debug-info-format\>**：

*要使用的调试信息格式。*

- **--enable-dead-strip|disable-dead-strip**：

*启用/禁用链接器的死代码剥离（dead code stripping）。*

- **--disable-local-rpath**：

*禁用默认把 $ORIGIN/@loader_path 加入 rpath 的行为。*

- **--original=\<original\>**：

*原始 url 或标识。*

- **--version**：

*显示版本。*

- **--help**：

*显示帮助信息。*
