# 2.6 发布与公开 Swift 包

共享你包的某个特定版本。

## 概述 {#Overview}

Swift Package Manager 期望包以一个 Git 仓库的形式远程共享，带有一个符合完整语义化版本的标签，并在仓库根目录下有一个 `Package.swift` 清单。

要发布托管在 Git 仓库中的包，就创建并推送一个语义化版本标签。Swift 包管理器要求该标签是完整的语义化版本，即标签中包含主版本、次版本和补丁版本。

下面的命令演示了如何添加标签 `1.0.0` 并把标签推送到远程仓库：

```bash
$ git tag 1.0.0
$ git push origin --tags
```

> 警告：形如 `1.0` 的标签不会被 Swift Package Manager 识别为完整的语义化版本。
> 请把反映主版本、次版本和补丁版本信息的三个整数都写上。

标签就位之后，其他包就可以通过你的源代码仓库依赖你打过标签的包。已发布包的示例可以在 [github.com/apple/example-package-playingcard](https://github.com/apple/example-package-playingcard/) 找到，其中提供了多个发布版本。

关于为包添加依赖的更多内容，参见[为 Swift 包添加依赖](../../dependencies/3.1-AddingDependencies/)。
