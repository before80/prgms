# Swift Package Manager

组织、管理和编辑 Swift 包。

本文档是《Swift Package Manager》（SwiftPM）文档的中文译本，按官方左侧导航分为十个部分：

- [基础](essentials/) —— 快速上手、包的概念，以及包的安全性。
- [构建包](buildingpackages/) —— 创建包、设置工具版本、构建配置、资源打包与发布。
- [依赖](dependencies/) —— 添加与解析依赖、包注册表，以及资源打包。
- [目标](targets/) —— C 语言目标、模块映射与模块别名。
- [共享包](sharingpackages/) —— 发布包与包集合。
- [扩展包管理器](extendingpackagemanager/) —— 插件，以及把包管理器作为库使用。
- [swift 命令](swiftcommands/) —— `swift build`、`swift test`、`swift package` 等命令参考。
- [设计](design/) —— 包注册表服务规范。
- [版本发布说明](releases/) —— 各版本 SwiftPM 的发布说明。
- [专题文章](articles/) —— 预览 Swift 构建系统集成等专题。
