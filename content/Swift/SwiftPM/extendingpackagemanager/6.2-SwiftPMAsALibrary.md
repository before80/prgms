# 6.2 把包管理器作为库使用

在你的 Swift 包中把 Swift Package Manager 作为依赖引入。

## 概述 {#Overview}

> 警告：**libSwiftPM API 是*不稳定的*，随时可能变化。**

Swift Package Manager 采用基于库的架构，顶层库产品名为 `libSwiftPM`。其他包可以把 SwiftPM 添加为包依赖，并基于 `libSwiftPM` 打造强大的自定义构建工具。

`libSwiftPM` 中只包含数据模型（不含包管理器的构建系统）的一个子集以 `libSwiftPMDataModel` 的形式提供。任何客户端都应当只依赖其中之一，而不要两个都依赖。
