# 2.1 在 Apple Silicon Mac 上搭建开发环境

你使用的是 MacBook Pro M4，CPU 架构是 **Apple Silicon（arm64）**。好消息是：Rust 和 Tauri 对 Apple Silicon 的支持已经非常成熟，下面这组工具装好后，桌面应用和 iOS 开发都能跑。

## 你的“四件套”

| 工具 | 作用 | 是否必需 |
| --- | --- | --- |
| Xcode Command Line Tools | 提供编译器和 macOS 系统头文件 | 开发桌面应用必需 |
| Xcode | 提供完整 iOS/macOS 原生工具链 | 开发 iOS 必需 |
| Rust（rustup 管理） | 编译 Tauri 后端 | 必需 |
| Node.js LTS | 运行前端构建工具（Vite 等） | 使用 JS/TS 前端时必需 |

## 1. 安装 Xcode Command Line Tools

打开“终端”（Terminal），执行：

```sh
xcode-select --install
```

系统会弹出安装窗口。如果只想做 **macOS 桌面应用**，装完它就可以继续。要开发 **iOS** 或想在 Xcode 中调试，还需要从 App Store 安装完整版 Xcode，并至少启动一次让 Xcode 完成初始化。

安装完成后检查：

```sh
xcode-select -p
```

能看到类似 `/Library/Developer/CommandLineTools` 的路径，就说明安装成功。

## 2. 安装 Rust

推荐用 [rustup](https://rustup.rs/) 安装 Rust，因为之后切换/添加移动端目标架构非常方便。

```sh
curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh
```

安装脚本结束时会提示你更新 `PATH`。重新打开终端后，运行：

```sh
rustc --version
cargo --version
```

能看到版本号即可。

> 对 M 系列芯片来说，默认安装的 Rust 主机目标就是 `aarch64-apple-darwin`，这正是 M4 Mac 运行原生应用需要的目标，通常无需额外处理。

## 3. 安装 Node.js（可选，但强烈建议）

如果前端想用 React、Vue、Svelte 等框架，就去 [Node.js 官网](https://nodejs.org) 下载 **LTS 版本**并安装。安装后用下面的命令验证：

```sh
node -v
npm -v
```

如果还想用 pnpm/yarn，可以启用 Node 自带的 Corepack：

```sh
corepack enable
```

## 4. 可选：安装 Homebrew

Homebrew 是 macOS 常用的软件包管理器。本教程后续安装 CocoaPods 时会用到；即使不开发 iOS，很多开发者也会提前装好。

```sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

## 5. 确认 M 系列 CPU 信息

想确认当前终端跑的是 arm64 架构，可以执行：

```sh
uname -m
```

在 Apple Silicon 上通常输出 `arm64`。

## 装完后的自检清单

```sh
xcode-select -p          # 1. Xcode CLT 路径
rustc --version          # 2. Rust 编译器版本
cargo --version          # 3. Cargo 版本
node -v                  # 4. Node 版本
```

全部能输出版本号，就可以进入 [3.1 创建第一个 Tauri 应用](../../quick-start/3.1-create-your-first-app/)。

如果之后还要开发 **Android/iOS 移动端**，请继续阅读 [2.2 配置移动端开发环境](../2.2-mobile-prerequisites/)。
