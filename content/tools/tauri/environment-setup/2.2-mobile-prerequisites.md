# 2.2 配置移动端开发环境

本章解决一个问题：**同一套 Tauri 工程，怎么在 Android 和 iOS 上跑起来？**

先记住结论：Tauri 不会让你“为每个平台重写一遍业务”。你的 Web 前端和大部分 Rust 代码共享，平台差异主要发生在：

- 构建工具（Android Studio vs Xcode）；
- 原生壳工程（Kotlin/Gradle 与 Objective-C++/Xcode）；
- 系统权限、签名、商店上架。

## iOS 需要什么

iOS 开发只能在 macOS 上进行。你需要：

1. 完整版 **Xcode**（不是只有 Command Line Tools）。
2. **Xcode 的 iOS 组件**：Xcode 安装后可在 Settings → Components 中下载对应 iOS Simulator。
3. Rust 的 **iOS 编译目标**。
4. **CocoaPods**（Tauri 的 iOS 原生工程用它管理依赖）。

在终端添加 iOS 目标：

```sh
rustup target add aarch64-apple-ios x86_64-apple-ios aarch64-apple-ios-sim
```

其中：

- `aarch64-apple-ios`：真机（arm64）；
- `x86_64-apple-ios`：Intel 模拟器；
- `aarch64-apple-ios-sim`：Apple Silicon 上运行的模拟器。

安装 CocoaPods：

```sh
brew install cocoapods
```

## Android 需要什么

Android 开发在 macOS、Windows、Linux 上都可以。建议安装 **Android Studio**，因为 Tauri 的 Android 壳工程就是标准 Android Studio 工程。

### 1. 安装 Android Studio

从 [Android Developers](https://developer.android.com/studio) 下载安装 Android Studio，并在 SDK Manager 中安装：

- Android SDK Platform；
- Android SDK Platform-Tools；
- Android SDK Build-Tools；
- NDK（Side by side）；
- Android SDK Command-line Tools。

### 2. 设置环境变量

以 zsh 为例，编辑 `~/.zshrc`，加入：

```sh
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
export ANDROID_HOME="$HOME/Library/Android/sdk"
export NDK_HOME="$ANDROID_HOME/ndk/$(ls -1 $ANDROID_HOME/ndk)"
```

保存后执行 `source ~/.zshrc`，再运行 `echo $ANDROID_HOME` 验证。

> 小技巧：`$(ls -1 $ANDROID_HOME/ndk)` 会自动选中已安装的 NDK 目录。不同项目需要的 NDK 版本不同，Tauri 模板通常会声明默认版本。

### 3. 添加 Rust 的 Android 编译目标

Android 上 Rust 会编译成 `.so` 动态库，因此需要四个常见 ABI 的编译目标：

```sh
rustup target add aarch64-linux-android armv7-linux-androideabi i686-linux-android x86_64-linux-android
```

对应关系：

| Rust target | 常见设备 |
| --- | --- |
| `aarch64-linux-android` | 现代 64 位 ARM 手机（主流） |
| `armv7-linux-androideabi` | 旧 32 位 ARM 设备 |
| `x86_64-linux-android` | 模拟器/部分 x86 平板 |
| `i686-linux-android` | 旧模拟器 |

## 检查全部目标

```sh
rustup target list --installed
```

你应该能看到桌面目标、Android 目标、iOS 目标都列在其中。

## 常见安装坑

1. **Xcode 第一次启动**必须完成额外组件安装，否则 iOS 构建会报找不到工具链。
2. **Android Studio 里的 SDK 路径**默认在 `~/Library/Android/sdk`；若你换过位置，`ANDROID_HOME` 要改成实际路径。
3. **不要随便删除 NDK 版本**：Tauri 生成的 Gradle 工程会按模板声明的 NDK 版本查找。
4. 如果 `tauri android` 命令报“找不到 Java”，先确认 `JAVA_HOME` 指向 Android Studio 自带的 JBR。
