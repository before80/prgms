# 5.11.4 Rust 支持

编译 uv 所需的最低受支持 Rust 版本列在 `Cargo.toml` 中 `[workspace.package]` 段落的 `rust-version` 键中。它可能在任何发布（次要或补丁）中变化，并且永远不会比 N-2 个 Rust 版本更新，其中 N 是最新的稳定版本。例如，如果最新的稳定 Rust 版本是 1.85，uv 的最低受支持 Rust 版本最多是 1.83。

这仅对从源码构建 uv 的用户有意义。从 Python 包索引安装 uv 通常安装的是预构建二进制文件，不需要 Rust 编译。
