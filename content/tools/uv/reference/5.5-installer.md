# 5.5 安装器选项

## 更改安装路径

默认情况下，uv 安装在用户的[可执行文件目录](./5.4-storage/#executable-directory)中。

要更改安装路径，请使用 `UV_INSTALL_DIR`：

{{< tabpane text=true persist=disabled >}}

{{% tab header="macOS 和 Linux" %}}

```console
$ curl -LsSf https://astral.sh/uv/install.sh | env UV_INSTALL_DIR="/custom/path" sh
```

{{% /tab %}}

{{% tab header="Windows" %}}

```pwsh
PS> powershell -ExecutionPolicy ByPass -c {$env:UV_INSTALL_DIR = "C:\Custom\Path";irm https://astral.sh/uv/install.ps1 | iex}
```

{{% /tab %}}

{{< /tabpane >}}

> **注意**
>
> 更改安装路径只影响 uv 二进制文件的安装位置。uv 仍会把它的数据（缓存、Python 安装、工具等）存放在默认位置。关于这些位置以及如何自定义它们，请参阅[存储参考](./5.4-storage/)。

## 禁用 shell 修改

安装器还可能更新你的 shell 配置文件，以确保 uv 二进制文件位于 `PATH` 上。要禁用该行为，请使用 `UV_NO_MODIFY_PATH`。例如：

```console
$ curl -LsSf https://astral.sh/uv/install.sh | env UV_NO_MODIFY_PATH=1 sh
```

如果使用 `UV_NO_MODIFY_PATH` 安装，后续操作（例如 `uv self update`）不会修改你的 shell 配置文件。

## 非受管安装

在 CI 这类临时环境中，请使用 `UV_UNMANAGED_INSTALL` 把 uv 安装到特定路径，同时阻止安装器修改 shell 配置文件或环境变量：

```console
$ curl -LsSf https://astral.sh/uv/install.sh | env UV_UNMANAGED_INSTALL="/custom/path" sh
```

使用 `UV_UNMANAGED_INSTALL` 还会禁用自我更新（通过 `uv self update`）。

## 向安装脚本传递选项

推荐使用环境变量，因为它们在各个平台上保持一致。不过选项也可以直接传给安装脚本。例如，要查看可用选项：

```console
$ curl -LsSf https://astral.sh/uv/install.sh | sh -s -- --help
```
