# 5.4 存储

## 存储目录

uv 使用以下高层目录进行存储。

对于每个位置，uv 会按给定顺序检查环境变量是否存在，并使用找到的第一个路径。

存储目录的路径与平台相关。uv 在 Linux 和 macOS 上遵循 [XDG](https://specifications.freedesktop.org/basedir-spec/latest/) 约定，在 Windows 上遵循 [Known Folder](https://learn.microsoft.com/en-us/windows/win32/shell/known-folders) 方案。

### 临时目录

临时目录用于存放短暂数据。

{{< tabpane text=true persist=disabled >}}

{{% tab header="Unix" %}}

1. `$TMPDIR`
1. `/tmp`

{{% /tab %}}

{{% tab header="Windows" %}}

1. `%TMP%`
1. `%TEMP%`
1. `%USERPROFILE%`

{{% /tab %}}

{{< /tabpane >}}

### 缓存目录

缓存目录用于存放可丢弃、但长期保留会有用的数据。

{{< tabpane text=true persist=disabled >}}

{{% tab header="Unix" %}}

1. `$XDG_CACHE_HOME/uv`
1. `$HOME/.cache/uv`

{{% /tab %}}

{{% tab header="Windows" %}}

1. `%LOCALAPPDATA%\uv\cache`
1. [`FOLDERID_LocalAppData`](https://learn.microsoft.com/en-us/windows/win32/shell/knownfolderid#FOLDERID_LocalAppData) 中的 `uv\cache`

{{% /tab %}}

{{< /tabpane >}}

### 持久数据目录

持久数据目录用于存放不可丢弃的数据。

{{< tabpane text=true persist=disabled >}}

1. `$HOME/.local/share/uv`
1. `$CWD/.uv`

{{% /tab %}}

{{% tab header="Windows" %}}

1. `%APPDATA%\uv\data`

{{% /tab %}}

## 数据类型

### 依赖缓存

uv 使用本地缓存以避免重复下载和重复构建依赖。

默认情况下缓存存放在[缓存目录](#cache-directory)中，但可以通过命令行参数、环境变量或设置覆盖，细节见[缓存文档](../concepts/3.16-cache/#cache-directory)。缓存被禁用时，缓存会存放在[临时目录](#temporary-directory)中。

使用 `uv cache dir` 显示当前的缓存目录路径。

> **重要**
>
> 为获得最佳性能，缓存目录需要与虚拟环境位于同一文件系统上。

### Python 版本

uv 可以安装受管的 [Python 版本](../concepts/3.12-python-versions/)，例如通过 `uv python install`。

默认情况下，uv 管理的 Python 版本存放在[持久数据目录](#persistent-data-directory)的 `python/` 子目录中，例如 `~/.local/share/uv/python`。

使用 `uv python dir` 显示 Python 安装目录。

使用 `UV_PYTHON_INSTALL_DIR` 环境变量覆盖安装目录。

> **注意**
>
> 改变 Python 的安装位置不会自动反映到既有虚拟环境；它们会继续指向旧位置，需要手动更新（例如重新创建它们）。

### Python 可执行文件

uv 会为 [Python 版本](#python-versions)安装可执行文件，例如 `python3.13`。

默认情况下，Python 可执行文件存放在[可执行文件目录](#executable-directory)中。

使用 `uv python dir --bin` 显示 Python 可执行文件目录。

使用 `UV_PYTHON_BIN_DIR` 环境变量覆盖 Python 可执行文件目录。

### 工具

uv 可以通过 `uv tool install` 把 Python 包安装为[命令行工具](../concepts/3.11-tools/)。

默认情况下，工具安装在[持久数据目录](#persistent-data-directory)的 `tools/` 子目录中，例如 `~/.local/share/uv/tools`。

使用 `uv tool dir` 显示工具安装目录。

使用 `UV_TOOL_DIR` 环境变量配置安装目录。

### 工具可执行文件

uv 会为已安装的[工具](#tools)安装可执行文件，例如 `ruff`。

默认情况下，工具可执行文件存放在[可执行文件目录](#executable-directory)中。

使用 `uv tool dir --bin` 显示工具可执行文件目录。

使用 `UV_TOOL_BIN_DIR` 环境变量配置工具可执行文件目录。

### uv 可执行文件

使用 uv 的[独立安装器](./5.5-installer/)安装 uv 时，`uv` 和 `uvx` 可执行文件会被安装到[可执行文件目录](#executable-directory)。

使用 `UV_INSTALL_DIR` 环境变量配置 uv 的安装目录。

### 配置文件

uv 的行为可以通过 TOML 文件配置。

配置文件会在[配置目录](#configuration-directories)中发现。

更多细节请参阅[配置文件文档](../concepts/3.13-configuration-files/)。

### 项目虚拟环境

处理[项目](../concepts/3.4-projects/)时，uv 会为每个项目创建专用虚拟环境。

默认情况下，项目虚拟环境创建在项目或工作区根目录的 `.venv` 中，即 `pyproject.toml` 旁边。

使用 `UV_PROJECT_ENVIRONMENT` 环境变量覆盖该位置。更多细节请参阅[项目环境文档](../concepts/3.4-projects/3.4.6-config/#project-environment-path)。

借助 [`centralized-project-envs` 预览特性](../concepts/3.17-preview/)，uv 会把默认项目环境存放在[缓存目录](#cache-directory)中。它们可以通过 `uv cache clean` 或 `uv cache prune` 移除，并在下次需要时重建。细节请参阅[集中式项目环境](../concepts/3.4-projects/3.4.1-layout/#centralized-project-environments)文档。

### 脚本虚拟环境

运行[带内联元数据的脚本](../guides/2.2-scripts/)时，uv 会为每个脚本在[缓存目录](#cache-directory)中创建专用虚拟环境。
