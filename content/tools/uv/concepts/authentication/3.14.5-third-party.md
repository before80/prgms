## Hugging Face 支持

uv 支持对 Hugging Face Hub 的自动身份验证。具体来说，如果设置了 `HF_TOKEN` 环境变量，uv 会把它传播到对 `huggingface.co` 的请求中。

这对访问 Hugging Face Datasets 中的私有脚本特别有用。例如，你可以运行下面的命令来执行私有数据集中的 `main.py` 脚本：

```console
$ HF_TOKEN=hf_... uv run https://huggingface.co/datasets/<user>/<name>/resolve/<branch>/main.py
```

你可以通过设置 `UV_NO_HF_TOKEN=1` 环境变量禁用 Hugging Face 自动身份验证。
