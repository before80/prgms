# 4.3 检查环境

## 列出已安装的包

列出环境中的所有包：

```console
$ uv pip list
```

以 JSON 格式列出包：

```console
$ uv pip list --format json
```

以 `requirements.txt` 格式列出环境中的所有包：

```console
$ uv pip freeze
```

## 检查某个包

要显示已安装包的信息，例如 `numpy`：

```console
$ uv pip show numpy
```

可以一次性检查多个包。

## 校验环境

如果分多步安装，有可能把需求相互冲突的包安装到同一个环境中。

要检查环境中的冲突或缺失依赖：

```console
$ uv pip check
```
