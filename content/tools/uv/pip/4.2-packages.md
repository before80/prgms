# 4.2 管理包

## 安装包

要把包安装到虚拟环境中，例如 Flask：

```console
$ uv pip install flask
```

要安装启用了可选依赖的包，例如带 “dotenv” extra 的 Flask：

```console
$ uv pip install "flask[dotenv]"
```

要安装多个包，例如 Flask 和 Ruff：

```console
$ uv pip install flask ruff
```

要安装带约束的包，例如 Ruff v0.2.0 或更新：

```console
$ uv pip install 'ruff>=0.2.0'
```

要安装特定版本的包，例如 Ruff v0.3.0：

```console
$ uv pip install 'ruff==0.3.0'
```

要从磁盘安装包：

```console
$ uv pip install "ruff @ ./projects/ruff"
```

要从 GitHub 安装包：

```console
$ uv pip install "git+https://github.com/astral-sh/ruff"
```

要从 GitHub 的特定引用安装包：

```console
$ # 安装标签
$ uv pip install "git+https://github.com/astral-sh/ruff@v0.2.0"

$ # 安装提交
$ uv pip install "git+https://github.com/astral-sh/ruff@1fadefa67b26508cc59cf38e6130bde2243c929d"

$ # 安装分支
$ uv pip install "git+https://github.com/astral-sh/ruff@main"
```

关于从私有仓库安装，请参阅 [Git 身份验证](../concepts/3.14-authentication/3.14.3-git/)文档。

## 可编辑包

可编辑包无需重装即可让源码修改生效。

要把当前项目安装为可编辑包：

```console
$ uv pip install -e .
```

要把其他目录中的项目安装为可编辑包：

```console
$ uv pip install -e "ruff @ ./project/ruff"
```

## 从文件安装包

可以按标准文件格式一次安装多个包。

从 `requirements.txt` 文件安装：

```console
$ uv pip install -r requirements.txt
```

关于 `requirements.txt` 文件的更多信息，请参阅 [`uv pip compile`](./4.5-compile/)文档。

从 `pyproject.toml` 文件安装：

```console
$ uv pip install -r pyproject.toml
```

从启用了可选依赖（例如 “foo” extra）的 `pyproject.toml` 文件安装：

```console
$ uv pip install -r pyproject.toml --extra foo
```

从启用了所有可选依赖的 `pyproject.toml` 文件安装：

```console
$ uv pip install -r pyproject.toml --all-extras
```

要安装当前项目目录 `pyproject.toml` 中的依赖组，例如 `foo` 组：

```console
$ uv pip install --group foo
```

要指定依赖组的来源项目目录：

```console
$ uv pip install --project some/path/ --group foo --group bar
```

另一种方式是，你可以为每个组指定 `pyproject.toml` 的路径：

```console
$ uv pip install --group some/path/pyproject.toml:foo --group other/pyproject.toml:bar
```

> **注意**
>
> 与 pip 一样，`--group` 标志不适用于通过 `-r` 或 `-e` 等标志指定的其他来源。例如 `uv pip install -r some/path/pyproject.toml --group foo` 会从 `./pyproject.toml` 而不是 `some/path/pyproject.toml` 获取 `foo`。

## 卸载包

要卸载包，例如 Flask：

```console
$ uv pip uninstall flask
```

要卸载多个包，例如 Flask 和 Ruff：

```console
$ uv pip uninstall flask ruff
```
