# 1.4 获取帮助

## 帮助菜单

`--help` 标志可用于查看某个命令的帮助菜单，例如查看 `uv` 的：

```console
$ uv --help
```

要查看某个特定命令的帮助菜单，例如 `uv init`：

```console
$ uv init --help
```

使用 `--help` 标志时，uv 显示的是精简版帮助菜单。要查看某个命令的更长的帮助菜单，请使用 `uv help`：

```console
$ uv help
```

要查看某个特定命令的长帮助菜单，例如 `uv init`：

```console
$ uv help init
```

使用长帮助菜单时，uv 会尝试使用 `less` 或 `more` 对输出进行分页，以免一次性全部显示。要退出分页器，请按 `q`。

## 显示详细输出

`-v` 标志可用于显示某个命令的详细输出，例如 `uv sync`：

```console
$ uv sync -v
```

`-v` 标志可以重复使用以提高详细程度，例如：

```console
$ uv sync -vv
```

详细输出中通常会包含额外的信息，说明 uv 为什么会有某种行为。

## 查看版本

寻求帮助时，确定你正在使用的 uv 版本很重要 —— 有时问题在新版本中已经修复。

检查已安装的版本：

```console
$ uv self version
```

以下命令同样有效：

```console
$ uv --version      # 输出与 `uv self version` 相同
$ uv -V             # 不会包含构建提交和日期
```

> **注意**
>
> 在 uv 0.7.0 之前，使用的是 `uv version` 而不是 `uv self version`。
