# 1.2 第一步

在[安装 uv](./1.1-installation/)之后，你可以运行 `uv` 命令来确认 uv 是否可用：

```console
$ uv
An extremely fast Python package manager.

Usage: uv [OPTIONS] <COMMAND>

...
```

你应该会看到一个列出可用命令的帮助菜单。

## 后续步骤

现在你已确认 uv 安装成功，可以查看[功能概览](./1.3-features/)，了解遇到问题时如何[获取帮助](./1.4-help/)，或者直接跳到[指南](../guides/)开始使用 uv。
