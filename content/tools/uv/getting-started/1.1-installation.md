# 1.1 安装

## 安装方式

你可以使用我们的独立安装器或你偏好的包管理器来安装 uv。

### 独立安装器

uv 提供了独立安装器来下载并安装 uv：

{{< tabpane text=true persist=disabled >}}

{{% tab header="macOS 和 Linux" %}}

使用 `curl` 下载脚本并使用 `sh` 执行：

```console
$ curl -LsSf https://astral.sh/uv/install.sh | sh
```

如果你的系统没有 `curl`，可以使用 `wget`：

```console
$ wget -qO- https://astral.sh/uv/install.sh | sh
```

在 URL 中指定版本即可请求特定版本：

```console
$ curl -LsSf https://astral.sh/uv/0.12.19/install.sh | sh
```

{{% /tab %}}

{{% tab header="Windows" %}}

使用 `irm` 下载脚本并使用 `iex` 执行：

```pwsh
PS> powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

更改[执行策略](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_execution_policies?view=powershell-7.4#powershell-execution-policies)后即可运行来自互联网的脚本。

在 URL 中指定版本即可请求特定版本：

```pwsh
PS> powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/0.12.19/install.ps1 | iex"
```

{{% /tab %}}

{{< /tabpane >}}

> **提示**
>
> 使用安装脚本之前可以先检查它的内容：
>
> {{< tabpane text=true persist=disabled >}}
>
> {{% tab header="macOS 和 Linux" %}}
>
> ```console
> $ curl -LsSf https://astral.sh/uv/install.sh | less
> ```
>
> {{% /tab %}}
>
> {{% tab header="Windows" %}}
>
> ```pwsh
> PS> powershell -c "irm https://astral.sh/uv/install.ps1 | more"
> ```
>
> {{% /tab %}}
>
> {{< /tabpane >}}
>
> 另外，安装器或二进制文件也可以直接从 [GitHub](#github-releases) 下载。

关于自定义 uv 安装的细节，请参阅[安装器](../reference/installer/)的参考文档。

### PyPI

为方便起见，uv 已发布到 [PyPI](https://pypi.org/project/uv/)。

如果从 PyPI 安装，我们建议把 uv 安装到隔离环境中，例如使用 `pipx`：

```console
$ pipx install uv
```

不过，也可以使用 `pip`：

```console
$ pip install uv
```

> **注意**
>
> uv 为许多平台提供了预构建的分发包（wheel）；如果某个平台没有可用的 wheel，uv 将从源码构建，这需要 Rust 工具链。从源码构建 uv 的细节请参阅[贡献指南](https://github.com/astral-sh/uv/blob/main/CONTRIBUTING.md#setup)。

### Homebrew

uv 已在 Homebrew 核心软件包中提供。

```console
$ brew install uv
```

### MacPorts

uv 可通过 [MacPorts](https://ports.macports.org/port/uv/) 安装。

```console
$ sudo port install uv
```

### WinGet

uv 可通过 [WinGet](https://winstall.app/apps/astral-sh.uv) 安装。

```console
$ winget install --id=astral-sh.uv  -e
```

### Scoop

uv 可通过 [Scoop](https://scoop.sh/#/apps?q=uv) 安装。

```console
$ scoop install main/uv
```

### Docker

uv 提供了位于 [`ghcr.io/astral-sh/uv`](https://github.com/astral-sh/uv/pkgs/container/uv) 的 Docker 镜像。

更多细节请参阅我们关于[在 Docker 中使用 uv](../guides/integration/docker/) 的指南。

### GitHub Releases

uv 的发布产物可以直接从 [GitHub Releases](https://github.com/astral-sh/uv/releases) 下载。

每个发布页面都包含适用于所有受支持平台的二进制文件，以及通过 `github.com`（而不是 `astral.sh`）使用独立安装器的说明。

### Cargo

uv 可通过 [crates.io](https://crates.io) 安装。

```console
$ cargo install --locked uv
```

> **注意**
>
> 这种方式会从源码构建 uv，因此需要兼容的 Rust 工具链。

## 升级 uv

当 uv 通过独立安装器安装时，它可以按需自我更新：

```console
$ uv self update
```

> **提示**
>
> 更新 uv 会重新运行安装器，并可能修改你的 shell 配置文件。要禁用此行为，请设置 `UV_NO_MODIFY_PATH=1`。

使用其他安装方式时，自我更新被禁用。请改用相应包管理器的升级方式。例如使用 `pip`：

```console
$ pip install --upgrade uv
```

## Shell 自动补全

> **提示**
>
> 你可以运行 `echo $SHELL` 来帮助确定自己使用的 shell。

要为 uv 命令启用 shell 自动补全，请运行以下命令之一：

{{< tabpane text=true persist=disabled >}}

{{% tab header="Bash" %}}

```bash
echo 'eval "$(uv generate-shell-completion bash)"' >> ~/.bashrc
```

{{% /tab %}}

{{% tab header="Zsh" %}}

```bash
echo 'eval "$(uv generate-shell-completion zsh)"' >> ~/.zshrc
```

{{% /tab %}}

{{% tab header="fish" %}}

```bash
echo 'uv generate-shell-completion fish | source' > ~/.config/fish/completions/uv.fish
```

{{% /tab %}}

{{% tab header="Elvish" %}}

```bash
echo 'eval (uv generate-shell-completion elvish | slurp)' >> ~/.elvish/rc.elv
```

{{% /tab %}}

{{% tab header="PowerShell / pwsh" %}}

```powershell
if (!(Test-Path -Path $PROFILE)) {
  New-Item -ItemType File -Path $PROFILE -Force
}
Add-Content -Path $PROFILE -Value '(& uv generate-shell-completion powershell) | Out-String | Invoke-Expression'
```

{{% /tab %}}

{{< /tabpane >}}

要为 uvx 启用 shell 自动补全，请运行以下命令之一：

{{< tabpane text=true persist=disabled >}}

{{% tab header="Bash" %}}

```bash
echo 'eval "$(uvx --generate-shell-completion bash)"' >> ~/.bashrc
```

{{% /tab %}}

{{% tab header="Zsh" %}}

```bash
echo 'eval "$(uvx --generate-shell-completion zsh)"' >> ~/.zshrc
```

{{% /tab %}}

{{% tab header="fish" %}}

```bash
echo 'uvx --generate-shell-completion fish | source' > ~/.config/fish/completions/uvx.fish
```

{{% /tab %}}

{{% tab header="Elvish" %}}

```bash
echo 'eval (uvx --generate-shell-completion elvish | slurp)' >> ~/.elvish/rc.elv
```

{{% /tab %}}

{{% tab header="PowerShell / pwsh" %}}

```powershell
if (!(Test-Path -Path $PROFILE)) {
  New-Item -ItemType File -Path $PROFILE -Force
}
Add-Content -Path $PROFILE -Value '(& uvx --generate-shell-completion powershell) | Out-String | Invoke-Expression'
```

{{% /tab %}}

{{< /tabpane >}}

然后重启 shell 或重新加载 shell 配置文件。

## 卸载

如果你需要从系统中移除 uv，请按以下步骤操作：

1.  清理已存储的数据（可选）：

    ```console
    $ uv cache clean
    $ rm -r "$(uv python dir)"
    $ rm -r "$(uv tool dir)"
    ```

    > **提示**
    >
    > 在移除二进制文件之前，你可能想先删除 uv 已存储的数据。uv 存储数据的位置请参阅[存储参考](../reference/storage/)。

2.  移除 uv、uvx 和 uvw 二进制文件：

    {{< tabpane text=true persist=disabled >}}

    {{% tab header="macOS 和 Linux" %}}

    ```console
    $ rm ~/.local/bin/uv ~/.local/bin/uvx
    ```

    {{% /tab %}}

    {{% tab header="Windows" %}}

    ```pwsh
    PS> rm $HOME\.local\bin\uv.exe
    PS> rm $HOME\.local\bin\uvx.exe
    PS> rm $HOME\.local\bin\uvw.exe
    ```

    {{% /tab %}}

    {{< /tabpane >}}

    > **注意**
    >
    > 在 0.5.0 之前，uv 被安装到 `~/.cargo/bin`。可以把那里的二进制文件删除以完成卸载。从旧版本升级不会自动移除 `~/.cargo/bin` 中的二进制文件。
