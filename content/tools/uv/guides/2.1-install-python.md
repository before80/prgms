# 2.1 安装和管理 Python

如果你的系统已经安装了 Python，uv 会无需配置地[检测并使用](#using-existing-python-versions)它。不过，uv 也可以安装和管理 Python 版本。uv 会按需[自动安装](#automatic-python-downloads)缺失的 Python 版本 —— 你无需先安装 Python 就能开始使用。

## 快速开始

安装最新的 Python 版本：

```console
$ uv python install
```

> **注意**
>
> Python 并不发布官方的可分发包。因此，uv 使用来自 Astral [`python-build-standalone`](https://github.com/astral-sh/python-build-standalone) 项目的发行版。更多细节请参阅 [Python 发行版](../concepts/3.12-python-versions/#managed-python-distributions)文档。

Python 安装完成后，`uv` 命令会自动使用它。uv 还会把已安装的版本加入你的 `PATH`：

```console
$ python3.13
```

uv 默认只安装带版本号的可执行文件。要同时安装 `python` 和 `python3` 可执行文件，请加上实验性的 `--default` 选项：

```console
$ uv python install --default
```

> **提示**
>
> 更多细节请参阅[安装 Python 可执行文件](../concepts/3.12-python-versions/#installing-python-executables)文档。

## 安装指定版本

安装特定的 Python 版本：

```console
$ uv python install 3.12
```

安装多个 Python 版本：

```console
$ uv python install 3.11 3.12
```

安装其他 Python 实现，例如 PyPy：

```console
$ uv python install pypy@3.10
```

更多细节请参阅 [`python install`](../concepts/3.12-python-versions/#installing-a-python-version) 文档。

## 重新安装 Python

要重新安装 uv 管理的 Python 版本，请使用 `--reinstall`，例如：

```console
$ uv python install --reinstall
```

这会重新安装所有此前安装过的 Python 版本。Python 发行版一直在持续改进，因此即使 Python 版本号没有变化，重新安装也可能解决某些缺陷。

## 查看 Python 安装情况

查看可用和已安装的 Python 版本：

```console
$ uv python list
```

更多细节请参阅 [`python list`](../concepts/3.12-python-versions/#viewing-available-python-versions) 文档。

## 自动下载 Python

使用 uv 并不需要显式安装 Python。默认情况下，uv 会在需要时自动下载 Python 版本。例如，如果尚未安装 Python 3.12，下面的命令会自动下载它：

```console
$ uvx python@3.12 -c "print('hello world')"
```

即使没有请求特定 Python 版本，uv 也会按需下载最新版本。例如，如果你的系统上没有任何 Python 版本，下面的命令会先安装 Python，再创建新的虚拟环境：

```console
$ uv venv
```

> **提示**
>
> 如果你希望对 Python 的下载时机有更多控制，可以[轻松禁用](../concepts/3.12-python-versions/#disabling-automatic-python-downloads)自动下载 Python。

## 使用已安装的 Python

如果系统中已存在 Python 安装，uv 会使用它们。这种行为无需任何配置：只要系统的 Python 满足命令调用的要求，uv 就会使用它。细节请参阅 [Python 发现](../concepts/3.12-python-versions/#discovery-of-python-versions)文档。

要强制 uv 使用系统 Python，请提供 `--no-managed-python` 标志。更多细节请参阅 [Python 版本偏好](../concepts/3.12-python-versions/#requiring-or-disabling-managed-python-versions)文档。

## 升级 Python 版本

> **重要**
>
> 升级 Python 补丁版本的支持处于*预览*阶段。这意味着该行为是实验性的，可能发生变化。

要把某个 Python 版本升级到最新的受支持补丁版本：

```console
$ uv python upgrade 3.12
```

升级所有由 uv 管理的 Python 版本：

```console
$ uv python upgrade
```

更多细节请参阅 [`python upgrade`](../concepts/3.12-python-versions/#upgrading-python-versions) 文档。
