# 6.7.2 测试 Web 应用

　　浏览器工具为智能体提供 Web 应用程序的闭环开发循环。智能体可以创建应用、在集成浏览器中打开、按验收标准交互、识别问题、修复并重复检查。

　　本指南通过构建并验证一个计算器应用来演示该循环。浏览器工具的能力、会话类型、隐私控制和提示模式，请参阅[2.2.10.3 BrowserTools](../../../ai-in-vs-code/work-with-ai/plan-and-run-tasks/2.2.10.3-BrowserTools/)。

## 前提条件 {#prerequisites}

* 在计算机上[安装 Visual Studio Code](https://code.visualstudio.com/download)。
* 拥有 [9.1 设置 GitHub Copilot](../../../advanced-setup/9.1-GitHubCopilotSetup/)。
* 已开启 `workbench.browser.enableChatTools` 设置（默认开启）。

## 智能体验证的内容 {#what-the-agent-validates}

　　要求智能体测试计算器之前，请定义可观察的验收标准：

* 每个数字按钮输入正确的值。
* 加、减、乘、除返回预期结果。
* **清除** 重置计算器。
* 除以零时显示错误，而不是无效的数字结果。

　　这些标准为智能体提供明确的成功定义，并使其最终验证报告更易于审查。

## 第 1 步：验证浏览器工具 {#step-1-verify-browser-tools}

1. 打开聊天视图（`Ctrl + Alt + I`，macOS：`Ctrl + Cmd + I`），从智能体下拉列表中选择 **智能体**。
2. 在聊天视图标题栏中选择 **打开自定义项** > **工具**，确认已选择 **集成浏览器**。

　　智能体现在可以使用这些工具与网页交互。如果工具缺失，请确认 `workbench.browser.enableChatTools` 已开启。组织策略也可能关闭浏览器工具。

## 第 2 步：让智能体构建计算器 {#step-2-ask-the-agent-to-build-a-calculator}

1. 创建一个新的项目文件夹，并在 VS Code 中打开它。
2. 在聊天视图中输入以下提示词：

    ```text
    创建一个计算器，包含数字 0-9、运算（加、减、乘、除）、清除和等号按钮。
    使用 HTML、CSS 和 JavaScript。采用简洁现代的设计风格。
    ```

3. 智能体创建 `index.html`、`styles.css` 和 `script.js` 时，审查生成的文件。
4. [2.2.8 审查和还原更改](../../../ai-in-vs-code/work-with-ai/2.2.8-ReviewAndRevertChanges/)。如果编辑待审查，请选择 **保留** 或 **撤销**。**保留** 会清除待审查状态；文件已经保存到工作区。

## 第 3 步：让智能体测试计算器 {#step-3-let-the-agent-test-the-calculator}

1. 在聊天视图中输入以下提示词：

    ```text
    在浏览器中打开计算器，并按照以下标准验证：
    每个数字按钮输入正确的值；加、减、乘、除返回预期结果；清除会重置
    计算器；除以零时显示错误。报告每项标准的结果。如果任何标准失败，
    请修复问题并重复完整验证。
    ```

2. 观察智能体在集成浏览器中打开 `index.html`、解析页面内容以了解结构，并通过模拟单击和检查结果系统测试每个按钮和运算。

　　智能体会报告哪些运算正常，以及发现的问题。

## 第 4 步：观察智能体调试并修复问题 {#step-4-watch-the-agent-debug-and-fix-issues}

1. 通过移除除零检查来引入一个错误：

    ```javascript
    function calculate() {
        if (!operator || shouldReset) return;

        const a = parseFloat(previous);
        const b = parseFloat(current);
        let result;

        switch (operator) {
        case '+': result = a + b; break;
        case '-': result = a - b; break;
        case '*': result = a * b; break;
        case '/': result = a / b; break;
    }
    ```

2. 要求智能体重现问题、修复并再次验证验收标准：

    ```text
    测试除以零。如果产生无效数字结果而不是错误，请修复问题。
    然后重复测试并报告结果。
    ```

3. 观察智能体在除以零时遇到错误、分析并修复代码，最后验证修复。

　　智能体使用浏览器工具完成了完整的开发循环：构建、验证、调试、修复并重新验证。

## 第 5 步：与智能体共享浏览器页面（可选） {#step-5-share-a-browser-page-with-the-agent-optional}

　　也可以手动打开网页，并显式与智能体共享以进行分析或交互。默认情况下，智能体只能与它自己打开的网页交互。

1. 从命令面板（`Ctrl + Shift + P`，macOS：`Cmd + Shift + P`）运行 **Browser: Open Integrated Browser** 命令。
2. 导航到希望智能体分析或交互的网页。
3. 选择浏览器工具栏中的 **与智能体共享** 按钮。浏览器选项卡上的视觉指示器会显示页面正在共享。
4. 要求智能体在共享页面上执行操作：

    ```text
    这个页面的主标题是什么？单击第一个链接，并告诉我它指向哪里。
    ```

　　智能体现在可以访问共享页面并代表你执行交互。完成后，再次选择 **与智能体共享** 撤销访问权限。

> **提示**：共享页面使用现有浏览器会话，包括 Cookie 和登录状态。智能体打开的页面使用隔离的临时会话，不与其他选项卡共享 Cookie 或存储。

## 尝试这些场景 {#try-these-scenarios}

* **表单验证测试**：让智能体通过构建和测试联系表单来验证验证规则、错误消息和成功提交。
* **响应式布局验证**：要求智能体在不同视口大小下截取页面截图，并验证响应式行为。
* **身份验证流程测试**：让智能体测试登录页面的凭据验证、错误处理和成功重定向。
* **交互功能测试**：让智能体验证用户交互和状态管理。
* **辅助功能审计**：要求智能体检查网页是否缺少替代文本、标题层级、键盘导航和颜色对比度问题。
