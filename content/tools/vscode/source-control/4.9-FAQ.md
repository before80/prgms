# 4.9 常见问题

　　本文回答有关 VS Code 源代码管理的支持与兼容性问题。要执行 Git 任务，请使用[任务指南](#common-tasks)。有关错误和意外行为，请参阅[4.8 故障排除](../4.8-Troubleshooting/)。如果你是首次设置 Git，请从[4.1 快速入门](../4.1-Quickstart/)开始。

## Git 客户端和提供程序 {#git-clients-and-providers}

### VS Code 可以使用 GitHub Desktop 执行 Git 操作吗？ {#can-vs-code-use-github-desktop-for-git-operations}

　　不可以。VS Code 的内置 Git 集成使用[官方 Git 发行版](https://git-scm.com/)。安装 GitHub Desktop 并不能替代此要求。

### 我可以使用 Team Foundation 版本控制吗？ {#can-i-use-team-foundation-version-control}

　　安装 [Azure Repos 扩展](https://marketplace.visualstudio.com/items?itemName=ms-vsts.team)，为 VS Code 添加 Team Foundation 版本控制支持。

### 我可以使用其他源代码管理提供程序吗？ {#can-i-use-another-source-control-provider}

　　可以。Git 支持内置于 VS Code，扩展可以为其他源代码管理系统提供支持。在扩展视图（`Ctrl + Shift + X`）中搜索 `@category:"scm providers"`。

## 身份验证 {#authentication}

### 我可以在 VS Code 中使用 SSH 身份验证吗？ {#can-i-use-ssh-authentication-with-vs-code}

　　可以。VS Code 使用 Git 安装中的 SSH 配置。如果 SSH 密钥有密码短语，请配置 SSH 代理，以便 Git 可以请求或复用密码短语。

　　有关特定平台的配置，请参阅 [GitHub 的 SSH 文档](https://docs.github.com/authentication/connecting-to-github-with-ssh)。

### 如何向要求多重身份验证的 Azure DevOps 组织进行身份验证？ {#how-do-i-authenticate-with-an-azure-devops-organization-that-requires-multifactor-authentication}

　　使用 [Git Credential Manager](https://github.com/GitCredentialManager/git-credential-manager)，这是 Windows、macOS 和 Linux 上推荐的 Git 凭据助手。Git for Windows 包含 Git Credential Manager。

## GitHub {#github}

### 是否支持 GitHub Enterprise Server？ {#is-github-enterprise-server-supported}

　　支持。VS Code 支持使用 GitHub Enterprise Server 进行身份验证。打开 GitHub Enterprise Server 仓库的本地检出，并按照登录提示操作。

　　[GitHub Pull Requests and Issues 扩展](https://marketplace.visualstudio.com/items?itemName=GitHub.vscode-pull-request-github)也支持 GitHub Enterprise Server。在管理拉取请求或议题之前，请为你的服务器配置该扩展。
