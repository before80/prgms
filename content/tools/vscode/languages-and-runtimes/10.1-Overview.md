# 10.1 编程语言

## 支持数百种编程语言 {#hundreds-of-programming-languages-supported}

　　VS Code 支持几乎所有主流编程语言。JavaScript、TypeScript、CSS 和 HTML 等几种语言开箱即用，更多丰富的语言扩展可在 [Visual Studio Marketplace](https://marketplace.visualstudio.com/vscode/Languages)中找到。

　　Marketplace 提供了热门语言扩展示例。请前往 [Marketplace](https://marketplace.visualstudio.com/vscode)，或使用集成的[扩展视图](../../editor/3.3-ConfigureTheEditor/3.3.6-Extensions/3.3.6.1-Overview/)搜索所需编程语言，以查找代码片段、代码补全/IntelliSense 提供程序、linter、调试器等。

> **注意**：如果要更改 VS Code 的显示语言（例如改为中文），请参阅[显示语言](../../editor/3.3-ConfigureTheEditor/3.3.1-DisplayLanguage/)主题。

## 特定语言文档 {#language-specific-documentation}

　　了解 VS Code 支持的编程语言：[C++](../language-support/10.2.9-C++/)、[C#](../language-support/10.2.19-CSharp/)、[CSS](../language-support/10.2.5-CSS/)、[Dart](https://dart.dev/tools/vs-code)、[Dockerfile](https://code.visualstudio.com/docs/azure/docker)、[F#](../language-support/10.2.20-NET/#create-an-f-hello-world-app)、[Go](../language-support/10.2.17-Go/)、[HTML](../language-support/10.2.3-HTML/)、[Java](../language-support/10.2.10-Java/)、[JavaScript](../language-support/10.2.1-JavaScript/)、[JSON](../language-support/10.2.2-JSON/)、[Julia](../language-support/10.2.13-Julia/)、[Less](../language-support/10.2.5-CSS/)、[Markdown](../language-support/10.2.7-Markdown/)、[PHP](../language-support/10.2.11-PHP/)、[PowerShell](../language-support/10.2.8-PowerShell/)、[Python](../language-support/10.2.12-Python/)、[R](../language-support/10.2.14-R/)、[Ruby](../language-support/10.2.15-Ruby/)、[Rust](../language-support/10.2.16-Rust/)、[SCSS](../language-support/10.2.5-CSS/)、[Swift](../language-support/10.2.21-Swift/)、[T-SQL](../language-support/10.2.18-T-SQL/)和 [TypeScript](../language-support/10.2.6-TypeScript/)。

　　单击任何链接可以了解在该语言上下文中如何使用 VS Code。大多数语言扩展还会在 README 中总结其核心功能。

## VS Code 中的语言功能 {#language-features-in-vs-code}

不同语言及其扩展的支持丰富程度各不相同，通常包括：

* 语法突出显示和括号匹配。
* 智能补全（IntelliSense，以及 [GitHub Copilot](../../ai-in-vs-code/work-with-ai/2.2.1-InlineSuggestions/) 的人工智能功能）。
* Linting 和更正。
* 代码导航（转到定义、查找所有引用）。
* 调试。
* 重构。

## 使用 AI 增强补全 {#enhance-completions-with-ai}

　　GitHub Copilot 会在编辑器中输入时提供编码建议。也可以向 Copilot 询问与编码相关的问题，例如如何更好地编写代码、如何修复错误，或他人的代码如何工作。

　　请参阅 [VS Code 中的 AI](../../ai-in-vs-code/)了解入门方法。

## 更改所选文件的语言 {#change-the-language-for-the-selected-file}

　　VS Code 默认根据文件扩展名确定语言支持。有时可能想更改语言模式：单击状态栏右侧的语言指示器，打开 **选择语言模式** 下拉列表，为当前文件选择另一种语言。

![语言选择器](../images/languageselect.png)

**提示**：运行 **Change Language Mode** 命令（`Ctrl + K M`）也可以打开同一列表。

## 语言标识符 {#language-identifier}

　　VS Code 将语言模式与特定语言标识符关联，以便根据当前语言模式启用各种功能。

　　语言标识符通常是（但不总是）小写编程语言名称。大小写对精确标识符匹配很重要（`Markdown` != `markdown`）。未知语言文件的标识符为 `plaintext`。

可以在 **Change Language Mode**（`Ctrl + K M`）下拉列表中查看当前已安装的语言及其标识符。

![语言标识符](../images/language-identifiers.png)

已知标识符列表请参阅[语言标识符参考](https://code.visualstudio.com/docs/languages/identifiers)。

## 将文件扩展名添加到语言 {#add-a-file-extension-to-a-language}

　　可以使用 `files.associations` [设置](../../editor/3.3-ConfigureTheEditor/3.3.4-Settings/)将新的文件扩展名添加到现有语言。

例如，以下设置将 `.myphp` 文件扩展名添加到 `php` 语言标识符：

```json
    "files.associations": {
        "*.myphp": "php"
    }
```

　　IntelliSense（`Ctrl + Space`）会显示可用的语言标识符。

![语言 ID IntelliSense](../images/language-id-intellisense.png)

## 常见问题 {#common-questions}

### 我可以贡献自己的语言服务吗？ {#can-i-contribute-my-own-language-service}

　　可以！请查看 [VS Code 扩展 API](https://code.visualstudio.com/api)文档中的[语言服务器示例](https://code.visualstudio.com/api/language-extensions/language-server-extension-guide)。

### 如果不想创建完整的语言服务，可以复用现有 TextMate 语法包吗？ {#what-if-i-dont-want-to-create-a-full-language-service-can-i-reuse-existing-textmate-bundles}

　　可以。也可以通过 TextMate 着色器添加对喜欢的语言的支持。请参阅扩展 API 部分的[语法高亮指南](https://code.visualstudio.com/api/language-extensions/syntax-highlight-guide)，了解如何将 TextMate `.tmLanguage` 语法文件集成到 VS Code。

### 可以将其他文件扩展名映射到语言吗？ {#can-i-map-additional-file-extensions-to-a-language}

　　可以。使用 `files.associations` [设置](../../editor/3.3-ConfigureTheEditor/3.3.4-Settings/)可以全局或按工作区将文件扩展名映射到现有语言。

以下示例将更多文件扩展名关联到 PHP：

```json
"files.associations": {
    "*.php4": "php",
    "*.php5": "php"
}
```

　　也可以按需配置完整文件路径。以下示例将 `somefolder` 文件夹中的所有文件关联到 PHP：

```json
"files.associations": {
    "**/somefolder/*.*": "php"
}
```

　　模式是 [glob 模式](https://code.visualstudio.com/docs/editor/glob-patterns)：包含 `/` 时匹配文件完整路径，否则匹配文件名。

### 如何设置新文件的默认语言？ {#how-do-i-set-the-default-language-for-new-files}

　　使用 `files.defaultLanguage` [设置](../../editor/3.3-ConfigureTheEditor/3.3.4-Settings/)，可以将所有新文件映射到默认语言。每次打开新的空白文件时，编辑器都会配置为该语言模式。

以下示例将新文件关联到 HTML：

```json
  // 分配给新文件的默认语言模式。
  "files.defaultLanguage": "html"
```
