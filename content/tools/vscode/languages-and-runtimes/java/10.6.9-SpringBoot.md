# 10.6.9 Spring Boot

　　VS Code 是 Spring Boot 开发的理想轻量环境，常用扩展包括：

* [Spring Boot Tools](https://marketplace.visualstudio.com/items?itemName=vmware.vscode-spring-boot)
* [Spring Initializr](https://marketplace.visualstudio.com/items?itemName=vscjava.vscode-spring-initializr)
* [Spring Boot Dashboard](https://marketplace.visualstudio.com/items?itemName=vscjava.vscode-spring-boot-dashboard)

建议安装 [Spring Boot Extension Pack](https://marketplace.visualstudio.com/items?itemName=vmware.vscode-boot-dev-pack)，包含以上全部扩展。

遇到问题可以在 [vscode-java-pack](https://github.com/microsoft/vscode-java-pack/issues) 创建议题。

## 前提条件 {#prerequisites}

* [Java Development Kit（JDK）](https://www.microsoft.com/openjdk)
* [Extension Pack for Java](https://marketplace.visualstudio.com/items?itemName=vscjava.vscode-java-pack)
* [Spring Boot Extension Pack](https://marketplace.visualstudio.com/items?itemName=vmware.vscode-boot-dev-pack)

> **注意**：入门说明请参阅 [Java 入门](10.6.1-Tutorial/)。

可以使用 [Java Spring 配置文件模板](../../../editor/3.3-ConfigureTheEditor/3.3.8-Profiles/)，其中包含有用扩展、设置和 Spring Boot 代码片段。

## 创建项目 {#create-the-project}

　　Spring Initializr 扩展可以搜索依赖并生成新的 Spring Boot 项目。

安装后打开命令面板（`Ctrl + Shift + P`），输入 `Spring Initializr` 启动向导，生成 Maven 或 Gradle 项目。

<video src="https://code.visualstudio.com/assets/docs/java/java-spring-boot/spring-initializr.mp4" autoplay loop muted playsinline controls title="创建项目"></video>

## 编辑项目 {#edit-the-project}

生成项目后可以添加依赖。打开 `pom.xml`，右键选择 **Add starters...**。下拉列表显示已有依赖（前缀 `√`），可以搜索要添加的依赖，或单击现有依赖移除。

<video src="https://code.visualstudio.com/assets/docs/java/java-spring-boot/spring-initializr-add-starters.mp4" autoplay loop muted playsinline controls title="编辑项目"></video>

## 开发应用 {#develop-the-application}

　　Spring Boot Tools 扩展为 `application.properties`、`application.yml` 和 `.java` 文件提供丰富语言支持：

* 快速导航到工作区中的 Spring 元素。
* Spring 特定组件的智能代码补全。
* 快速访问运行中的 Spring 应用。
* 实时应用信息。
* 代码模板。

`.properties` 和 `.yml` 文件也支持补全和验证。详细用法请参阅[使用指南](https://github.com/spring-projects/sts4/tree/main/vscode-extensions/vscode-spring-boot#usage)。

实时应用信息和指标示例：

<video src="https://code.visualstudio.com/assets/docs/java/java-spring-boot/spring-live-info.mp4" autoplay loop muted playsinline controls title="实时应用信息和指标"></video>

## 运行应用 {#run-the-application}

除了按 `F5` 运行，[Spring Boot Dashboard](https://marketplace.visualstudio.com/items?itemName=vscjava.vscode-spring-boot-dashboard)扩展可以查看和管理工作区所有 Spring Boot 项目，并快速启动、停止或调试。
