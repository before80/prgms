# 10.6.15 Java 常见问题

## 这些 Java 扩展是开源的吗？ {#are-these-java-extensions-open-source}

　　是的。Red Hat、Microsoft 和 VMware 提供的所有 [Java 扩展](10.6.14-Extensions/)以及大多数社区扩展都是开源的。可以在 Marketplace 页面找到对应的 GitHub 仓库。

## VS Code 的 Java 支持还会增加其他功能吗？ {#are-there-any-other-features-coming-to-java-on-vs-code}

　　会。我们使用 GitHub 议题跟踪请求和计划工作。目前正在增加重构和 Lint 功能以提高编辑效率，并进行性能改进。

大部分工作来自客户反馈并按其优先级排序。可以到项目仓库提交新议题分享想法。

团队容量有限，欢迎 Java 社区贡献。值得考虑的方向包括 Gradle 支持、代码分析和测试覆盖率工具、分析器，以及 DropWizard、JavaFX、JPA、Play、Akka、OSGi 等框架支持。

## 可以使用其他 IDE 的快捷键吗？ {#can-i-use-keyboard-shortcuts-from-other-ide}

　　可以。VS Code 的[快捷键映射扩展](../../../editor/3.3-ConfigureTheEditor/3.3.3-KeyboardShortcuts/#keymap-extensions)可以修改快捷键以匹配其他编辑器。Marketplace 的[快捷键映射类别](https://marketplace.visualstudio.com/search?target=VSCode&category=Keymaps&sortBy=Installs)中有 [IntelliJ IDEA](https://marketplace.visualstudio.com/items?itemName=k--kato.intellij-idea-keybindings)、[Eclipse](https://marketplace.visualstudio.com/items?itemName=alphabotsec.vscode-eclipse-keybindings)等映射。

## 在哪里查看 VS Code Java 支持的最新进展？ {#where-can-i-find-the-latest-progress-of-java-support-on-vs-code}

　　可以关注 [Java at Microsoft](https://devblogs.microsoft.com/java/)博客。更新 Extension Pack for Java 后，扩展可能显示 **Release Notes** 部分，概述重要更新。

## 如何在新 Java 版本中使用 VS Code？ {#how-can-i-use-vs-code-with-new-java-versions}

　　借助 JDT 上游更新，VS Code 可以构建到 Java 22 的项目。使用实验/预览语言功能需要修改项目设置。

**Maven**：修改 `pom.xml`：

```xml
  <build>
    <pluginManagement>
      <plugins>
        <plugin>
          <artifactId>maven-compiler-plugin</artifactId>
          <configuration>
            <release>22</release>
            <compilerArgs>--enable-preview</compilerArgs>
          </configuration>
        </plugin>
      </plugins>
    </pluginManagement>
  </build>
```

**Gradle**：

```groovy
sourceCompatibility = 22
tasks.withType(JavaCompile) {
    options.compilerArgs += '--enable-preview'
}
tasks.withType(Test) {
    jvmArgs += "--enable-preview"
}
```

> **注意**：修改已在 VS Code 中打开的项目后，可能需要强制清理工作区并重新加载。运行 **Java: Clean Java Language Server Workspace** 命令。

## 如何在企业代理后使用？ {#how-can-i-use-it-behind-a-corporate-proxy}

　　在企业代理后使用 Java 语言支持扩展时，需要让 Java 语言服务器知道如何通过代理连接互联网，以下载构建运行时、Java 依赖及其源代码。

在 VS Code 首选项中配置 `java.jdt.ls.vmargs`（全部在一行）：

```json
{
"java.jdt.ls.vmargs": "-Dhttp.proxyHost=webproxy.corp.net -Dhttp.proxyPort=proxyport -Dhttp.proxyUser=user -Dhttp.proxyPassword=password -Dhttps.proxyHost=webproxy.corp.net -Dhttps.proxyPort=proxyport -Dhttps.proxyUser=user -Dhttps.proxyPassword=password"
}
```

## 会提供给 Visual Studio 吗？ {#will-this-be-available-for-visual-studio}

　　目前不计划将 Java 支持扩展到 Visual Studio。已有优秀的 Java IDE，我们专注于在 VS Code 这个多语言编辑器中提供轻量体验。

## VS Code Java 支持其他显示语言吗？ {#does-vs-code-java-support-other-display-languages}

　　目前 [Debugger for Java](https://marketplace.visualstudio.com/items?itemName=vscjava.vscode-java-debug)、[Test Runner for Java](https://marketplace.visualstudio.com/items?itemName=vscjava.vscode-java-test)、[Maven for Java](https://marketplace.visualstudio.com/items?itemName=vscjava.vscode-maven)和 [Project Manager for Java](https://marketplace.visualstudio.com/items?itemName=vscjava.vscode-java-dependency)等扩展支持中文和英文。切换显示语言请参阅[显示语言](../../../editor/3.3-ConfigureTheEditor/3.3.1-DisplayLanguage/)。

有兴趣支持其他显示语言可以向扩展仓库贡献。
