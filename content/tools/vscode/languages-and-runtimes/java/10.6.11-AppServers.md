# 10.6.11 应用服务器

　　VS Code 是以代码编辑器为中心的开发工具，不内置应用服务器。大多数服务器需要通过命令行部署，然后使用适当的调试器[配置](10.6.7-Debugging/#configure)附加。

　　对于某些 Java 工作负载，服务器集成非常有用。可以安装流行应用服务器的第三方扩展，例如 [Tomcat](https://tomcat.apache.org/)、[Jetty](https://www.eclipse.org/jetty/)和 [Open Liberty](https://openliberty.io/)。

[Spring Boot Dashboard](https://marketplace.visualstudio.com/items?itemName=vscjava.vscode-spring-boot-dashboard)请参阅 [VS Code 中的 Spring Boot](10.6.9-SpringBoot/)。

遇到问题可以在 [vscode-java-pack](https://github.com/microsoft/vscode-java-pack/issues) 创建议题。

## Community Server Connectors {#community-server-connectors}

　　[Community Server Connectors](https://marketplace.visualstudio.com/items?itemName=redhat.vscode-community-server-connector)由 Red Hat 发布，提供基于 Remote Server Protocol 的服务器连接器，可以启动、停止、发布和控制 [Apache Felix](https://felix.apache.org/documentation/index.html)、[Karaf](https://karaf.apache.org/)和 [Tomcat](https://tomcat.apache.org/)等社区运行时和服务器。

## 其他服务器 {#other-servers}

　　[Open Liberty Tools](https://marketplace.visualstudio.com/items?itemName=Open-Liberty.liberty-dev-vscode-ext)扩展可以在 Open Liberty 上运行应用，并从 VS Code 部署、测试和调试。

　　Red Hat 的 [Server Connector](https://marketplace.visualstudio.com/items?itemName=redhat.vscode-server-connector)扩展可以启动、停止和部署到 WildFly、JBoss EAP、Minishift、CDK 等 Red Hat 服务器和运行时。

　　[Extension Pack for MicroProfile](https://marketplace.visualstudio.com/items?itemName=MicroProfile-Community.vscode-microprofile-pack)提供创建 MicroProfile 项目并部署到 Open Liberty、Quarkus、Payara 等运行时的工具。
