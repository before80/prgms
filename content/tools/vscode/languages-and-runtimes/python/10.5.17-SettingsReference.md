# 10.5.17 Python 设置参考

　　VS Code Python 扩展高度可配置。本页介绍常用设置。通用设置操作请参阅[用户和工作区设置](../../../editor/3.3-ConfigureTheEditor/3.3.4-Settings/)，预定义变量请参阅[变量参考](../../../editor/3.4-Reference/3.4.3-SubstitutionVariables/)。

## 常规 Python 设置 {#general-python-settings}

| 设置（`python.`） | 默认值 | 说明 |
| --- | --- | --- |
| `condaPath` | `"conda"` | `conda` 可执行文件路径。 |
| `defaultInterpreterPath` | `"python"` | 工作区首次加载时使用的默认解释器路径，或包含解释器的文件夹路径。可使用 `${workspaceFolder}` 和 `${workspaceFolder}/.venv` 等变量。指向文件夹可让团队成员在 `.venv` 中创建适合操作系统的环境，从而将 `settings.json` 纳入版本控制。**注意**：选择解释器后修改此设置不会生效。 |
| `envFile` | `"${workspaceFolder}/.env"` | 环境变量定义文件绝对路径。请参阅 [.env 文件支持](10.5.8-Environments/#env-file-support)。 |
| `experiments.enabled` | `true` | 启用 Python 扩展 A/B 实验，可能提供实验性功能。 |
| `globalModuleInstallation` | `false` | 为当前用户安装包（`--user`）还是全局安装。虚拟环境中忽略。 |
| `interpreter.infoVisibility` | `"onPythonRelated"` | 状态栏解释器信息显示时机：`onPythonRelated`、`always`、`never`。 |
| `pipenvPath` | `"pipenv"` | pipenv 可执行文件路径。 |
| `poetryPath` | `"poetry"` | Poetry 依赖管理器路径。存在 `poetry.lock` 时用于安装包。 |
| `REPL.enableREPLSmartSend` | `true` | `Shift + Enter` 是否使用 Smart Send。 |
| `terminal.activateEnvInCurrentTerminal` | `false` | 扩展激活时是否在当前终端激活所选虚拟环境。 |
| `terminal.activateEnvironment` | `true` | 创建新终端时是否自动激活所选环境。配置 `python-envs.terminal.autoActivationType` 后此设置被取代。 |
| `terminal.executeInFileDir` | `false` | 是否在文件所在目录运行文件。 |
| `terminal.focusAfterLaunch` | `false` | 启动 Python 终端后是否将焦点切换到终端。 |
| `terminal.launchArgs` | `[]` | 运行文件时传给解释器的启动参数。调试时忽略，使用 `launch.json` 参数。 |
| `terminal.useEnvFile` | `false` | 是否将 env 文件和 `python.envFile` 中的环境变量注入终端。 |
| `venvFolders` | `[]` | 虚拟环境所在文件夹路径。会自动与 `python-envs.globalSearchPaths` 合并。 |

## Python Environments 扩展设置 {#python-environments-extension-settings}

### 环境管理 {#environment-management-settings}

| 设置（`python-envs.`） | 默认值 | 说明 |
| --- | --- | --- |
| `defaultEnvManager` | `"ms-python.python:venv"` | 创建和管理环境的默认管理器。 |
| `defaultPackageManager` | `"ms-python.python:pip"` | 安装包的默认包管理器。 |
| `pythonProjects` | `[]` | Python 项目列表。每项包含 `path`、`envManager`、`packageManager`，用于多根工作区按文件夹配置环境。 |
| `workspaceSearchPaths` | `["./**/.venv"]` | 工作区环境搜索 glob 模式。必须在工作区或文件夹级别配置。 |
| `globalSearchPaths` | `[]` | 跨工作区搜索环境的绝对路径，例如 `~/envs`。旧设置 `python.venvPath` 和 `python.venvFolders` 会自动合并。 |
| `alwaysUseUv` | `true` | uv 可用时是否用 uv 管理所有虚拟环境；`false` 时只管理 uv 创建的环境。 |

### 终端设置 {#terminal-settings}

| 设置（`python-envs.terminal.`） | 默认值 | 说明 |
| --- | --- | --- |
| `autoActivationType` | `"command"` | 终端环境激活方式：`command`（执行命令）、`shellStartup`（shell 集成或修改启动脚本，支持 zsh、fish、pwsh、bash、cmd）、`off`（不自动激活）。优先于 `python.terminal.activateEnvironment`。 |
| `showActivateButton` | `false` | （实验性）是否在终端菜单显示“激活”按钮。 |

### 旧设置迁移 {#legacy-settings-migration}

| 旧设置 | 新设置 | 说明 |
| --- | --- | --- |
| `python.venvPath` | `python-envs.globalSearchPaths` 或 `workspaceSearchPaths` | 旧设置仍有效并自动合并。 |
| `python.venvFolders` | `python-envs.globalSearchPaths` 或 `workspaceSearchPaths` | 旧设置仍有效并自动合并。 |
| `python.terminal.activateEnvironment` | `python-envs.terminal.autoActivationType` | 设为 `"off"` 禁用自动激活。新设置优先。 |

| 设置（`python.analysis.`） | 默认值 | 说明 |
| --- | --- | --- |

| `autoFormatStrings` | `false` | 字符串中输入 `{` 时自动添加 `f` 前缀。 |
| `autoImportCompletions` | `false` | 补全中提供自动导入。 |
| `autoIndent` | `true` | 根据语言语义自动调整缩进。 |
| `autoSearchPaths` | `true` | 自动添加 `src` 等预定义搜索路径。 |
| `completeFunctionParens` | `false` | 函数补全时添加括号。 |
| `diagnosticMode` | `openFilesOnly` | 分析范围：`workspace` 或 `openFilesOnly`。 |
| `diagnosticSeverityOverrides` | `{}` | 覆盖单条诊断严重性：`error`、`warning`、`information`、`none`。 |
| `enableEditableInstalls` | `false` | 解析可编辑安装（`pip install -e .`）的导入路径。 |
| `exclude` | `[]` | 不分析的文件/目录，支持 `**`、`*`、`?`。默认排除 `**/node_modules`、`**/__pycache__`、`.git` 和虚拟环境。 |
| `extraPaths` | `[]` | 导入解析的额外搜索路径。 |
| `importFormat` | `absolute` | 自动导入格式：`absolute` 或 `relative`。 |
| `include` | `[]` | 要分析的文件/目录。未指定时默认为工作区根。 |
| `fixAll` | `[]` | **全部修复** 运行的代码操作：`source.unusedImports`、`source.convertImportFormat`。 |
| `includeAliasesFromUserFiles` | `false` | 自动导入中是否包含用户文件别名。 |
| `ignore` | `[]` | 抑制诊断的文件/目录。 |
| `indexing` | `true` | 是否索引用户文件和第三方库。 |
| `inlayHints.callArgumentNames` | `off` | 调用参数名内联提示：`off`、`partial`、`all`。 |
| `inlayHints.functionReturnTypes` | `false` | 函数返回类型内联提示。 |
| `inlayHints.pytestParameters` | `false` | pytest fixture 参数类型内联提示。 |
| `inlayHints.variableTypes` | `false` | 变量类型内联提示。 |
| `languageServerMode` | `default` | `default` 或 `light`。`light` 模式关闭索引、库类型等以节省内存。 |
| `logLevel` | `Error` | 日志级别：`Error`、`Warning`、`Information`、`Trace`。 |
| `nodeArguments` | `"--max-old-space-size=8192"` | 传给自定义 Node.js 可执行文件的参数。 |
| `nodeExecutable` | `""` | Pylance 使用的 Node.js 可执行文件路径，`""` 使用 VS Code 自带，`"auto"` 自动下载。 |

| `userFileIndexingLimit` | `2000` | 索引用户文件上限，`-1` 表示全部。 |

**诊断严重性规则**

可以在 `python.analysis.diagnosticSeverityOverrides` 中覆盖：

```json
{
    "python.analysis.diagnosticSeverityOverrides": {
        "reportUnboundVariable": "information",
        "reportImplicitStringConcatenation": "warning"
    }
}
```

常用规则：

| 规则 | 说明 |
| --- | --- |
| `reportAssertAlwaysTrue` | 断言可能始终为真。 |
| `reportCallInDefaultInitializer` | 默认值初始化中的函数调用。 |
| `reportConstantRedefinition` | 重新定义全大写常量。 |
| `reportDuplicateImport` | 重复导入。 |
| `reportFunctionMemberAccess` | 函数成员访问。 |
| `reportGeneralTypeIssues` | 通用类型不一致。 |
| `reportImportCycles` | 循环导入。 |
| `reportImplicitStringConcatenation` | 隐式字符串拼接。 |
| `reportIncompatibleMethodOverride` | 不兼容的方法重写。 |
| `reportIncompatibleVariableOverride` | 不兼容的变量重写。 |
| `reportInvalidStringEscapeSequence` | 无效字符串转义。 |
| `reportInvalidStubStatement` | 存根文件中的无效语句。 |
| `reportInvalidTypeVarUse` | 类型变量使用不当。 |
| `reportMissingImports` | 找不到导入文件或存根。 |
| `reportMissingModuleSource` | 找到存根但找不到模块源文件。 |
| `reportMissingTypeArgument` | 泛型缺少类型参数。 |
| `reportMissingTypeStubs` | 缺少类型存根。 |
| `reportOptionalCall` | 调用 Optional 类型。 |
| `reportOptionalContextManager` | Optional 作为上下文管理器。 |
| `reportOptionalIterable` | Optional 作为可迭代对象。 |
| `reportOptionalMemberAccess` | 访问 Optional 成员。 |
| `reportOptionalOperand` | Optional 作为运算对象。 |
| `reportOptionalSubscript` | Optional 下标访问。 |
| `reportPrivateUsage` | 私有/受保护成员使用不当。 |
| `reportPropertyTypeMismatch` | 属性 getter/setter 类型不匹配。 |
| `reportSelfClsParameterName` | `self`/`cls` 参数缺失或名称错误。 |
| `reportUndefinedVariable` | 未定义变量。 |
| `reportUnboundVariable` | 未绑定变量。 |
| `reportUnknownArgumentType` | 参数类型未知。 |
| `reportUnknownLambdaType` | lambda 类型未知。 |
| `reportUnknownMemberType` | 成员类型未知。 |
| `reportUnknownParameterType` | 参数类型未知。 |
| `reportUnknownVariableType` | 变量类型未知。 |
| `reportUnnecessaryCast` | 不必要的 `cast`。 |
| `reportUnnecessaryIsInstance` | 不必要的 `isinstance`/`issubclass`。 |
| `reportUnusedCallResult` | 未使用非 None 调用结果。 |
| `reportUnusedClass` | 未使用的私有类。 |
| `reportUnusedCoroutine` | 未使用的协程结果。 |
| `reportUnusedFunction` | 未使用的私有函数。 |
| `reportUnusedImport` | 未使用导入。 |
| `reportUnusedVariable` | 未使用变量。 |
| `reportUnsupportedDunderAll` | `__all__` 上的不支持操作。 |
| `reportWildcardImportFromLibrary` | 从外部库通配符导入。 |

## 预定义变量 {#predefined-variables}

Python 扩展设置支持 `${variableName}` 语法：

* `${cwd}`：任务运行器启动时的工作目录。
* `${workspaceFolder}`：VS Code 中打开的文件夹路径。
* `${workspaceRootFolderName}`：打开的文件夹名称（不含斜杠）。
* `${workspaceFolderBasename}`：打开的文件夹名称（不含斜杠）。
* `${file}`：当前打开文件。
* `${relativeFile}`：当前文件相对于 `workspaceFolder` 的路径。
* `${relativeFileDirname}`：当前文件目录相对于 `workspaceFolder` 的路径。
* `${fileBasename}`：当前文件名。
* `${fileBasenameNoExtension}`：不含扩展名的当前文件名。
* `${fileDirname}`：当前文件目录。
* `${fileExtname}`：当前文件扩展名。
* `${lineNumber}`：活动文件当前选中行号。
* `${selectedText}`：活动文件当前选中文本。
* `${execPath}`：运行中的 VS Code 可执行文件路径。

更多变量示例请参阅[变量参考](../../../editor/3.4-Reference/3.4.3-SubstitutionVariables/)。
