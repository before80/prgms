# 10.5.6 Python 格式化

　　格式化通过执行行距、缩进和运算符周围空格等规则，使源代码更易阅读。格式化不影响代码本身的功能。

　　[Lint](10.5.5-Linting/)通过分析常见语法、风格和功能错误帮助防止错误。格式化和 Lint 略有重叠，但功能互补。

## 设置默认格式化程序 {#set-a-default-formatter}

安装格式化扩展后，可以将其设为 Python 文件默认格式化程序：

1. 打开 Python 文件。
2. 右键单击编辑器显示上下文菜单。
3. 选择 **格式化文档方式...**。
4. 从下拉菜单选择 **配置默认格式化程序...**。
5. 从列表选择格式化扩展。

也可以在用户 `settings.json` 的 `[python]` 作用域中设置 `"editor.defaultFormatter"`，将所有 Python 文件设为默认。可以使用 **Preferences: Open User Settings (JSON)** 命令打开。

例如将 Black Formatter 设为默认：

```json
  "[python]": {
    "editor.defaultFormatter": "ms-python.black-formatter"
  }
```

要将格式化扩展设为导入排序器，请在用户或工作区 `settings.json` 的 `[python]` 作用域中配置 `"editor.codeActionsOnSave"`。这会在保存时对所有 Python 文件启用导入排序。

例如将 Ruff 设为导入排序器：

```json
{
  "[python]": {
    "editor.codeActionsOnSave": {
      "source.organizeImports.ruff": "explicit"
    }
  }
}
```

## 格式化代码 {#format-your-code}

右键单击编辑器选择 **格式化文档**，或使用 `Shift + Alt + F` 快捷键。

也可以在用户 `settings.json` 中启用保存时格式化：

```json
  "[python]": {
    "editor.formatOnSave": true
  }
```

## 常规格式化设置 {#general-formatting-settings}

各格式化扩展支持的设置请参阅其 README。大多数格式化扩展支持：

| 设置后缀 | 默认值 | 说明 |
| --- | --- | --- |
| `args` | `[]` | 传递给格式化程序的参数，每个参数作为单独字符串。例如 `black-formatter.args: ["--line-length", "100"]`。 |
| `importStrategy` | `useBundled` | `useBundled` 使用扩展自带版本；`fromEnvironment` 先从所选 Python 环境加载，找不到时回退到自带版本。 |
| `path` | `""` | 格式化程序二进制文件路径。**注意**：可能拖慢格式化。 |
| `interpreter` | `[]` | 设置为 Python 可执行文件路径时，扩展用它启动格式化服务器及其子进程。 |
| `showNotifications` | `off` | 控制扩展通知时机，支持 `off`、`always`、`onError`、`onWarning`。 |

## 格式化故障排除 {#troubleshoot-formatting}

| 问题 | 解决方案 |
| --- | --- |
| Python 文件有多个可用格式化程序。 | 按[设置默认格式化程序](#set-a-default-formatter)操作。 |
| 没有“格式化文档方式...”选项。 | 很可能未安装或启用格式化扩展。请参阅[选择格式化程序](#choose-a-formatter)。 |
| 格式化程序自定义参数不正确。 | 检查 `<formatter>.path` 不包含参数，`<formatter>.args` 包含独立参数列表。 |
| 显示“You have deprecated linting or formatting settings”通知。 | `python.linting` 或 `python.formatting` 等设置已不再支持，lint 和格式化已迁移到工具扩展。请在用户、工作区或远程设置中删除这些已弃用设置。 |
| 使用 Black Formatter 时 **格式化选定内容** 失败。 | `black` 不支持格式化代码片段。可以禁用粘贴时格式化，并设置 `"[python]": {"editor.formatOnPaste": false, "editor.formatOnSaveMode": "file"}` 以保存时格式化整个文件。 |
| 已安装格式化扩展但格式化不工作。 | 检查代码语法、Python 版本和格式化程序配置。在 **输出** 面板选择格式化扩展通道查看失败原因。 |

> **注意**：找不到所需格式化程序时，可以通过扩展添加支持。[Python 扩展模板](https://code.visualstudio.com/api/advanced-topics/python-extension-template)可简化集成。
