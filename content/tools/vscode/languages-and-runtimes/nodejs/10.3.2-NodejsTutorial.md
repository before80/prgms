# 10.3.2 Node.js 教程

　　[Node.js](https://nodejs.org/)是使用 JavaScript 构建快速可扩展服务器应用的平台。Node.js 是运行时，[npm](https://www.npmjs.com/)是 Node.js 模块的包管理器。

　　VS Code 开箱即用支持 JavaScript、TypeScript 和 Node.js 调试。但运行 Node.js 应用需要在机器上安装 Node.js 运行时。

请先为平台[安装 Node.js](https://nodejs.org/en/download/)。Node.js 发行版包含 npm。需要打开新终端（命令提示符），使 `node` 和 `npm` 出现在 PATH 中。

要测试 Node.js 是否正确安装，请打开新终端输入 `node --version`，应看到当前安装的 Node.js 版本。

> **Linux**：各种 Linux 发行版有特定 Node.js 包。请参阅[通过包管理器安装 Node.js](https://nodejs.org/en/download/package-manager)。

> **Windows Subsystem for Linux**：Windows 上 WSL 是进行 Node.js 开发的好方法。可以在 Windows 上运行 Linux 发行版并在 Linux 环境中安装 Node.js。配合 [WSL 扩展](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-wsl)，在 WSL 上下文中运行时可以获得完整的 VS Code 编辑和调试支持。详情请参阅[在 WSL 中开发](../../../remote/8.6-WSL/)，或尝试[在 WSL 中工作](../../../remote/8.7-WSLTutorial/)教程。

## Hello World {#hello-world}

创建最简单的 Node.js 应用“Hello World”。

创建空文件夹 `hello`，进入并打开 VS Code：

```bash
mkdir hello
cd hello
code .
```

> **提示**：可以直接从命令行打开文件或文件夹。句点 `.` 表示当前文件夹，因此 VS Code 会启动并打开 `hello` 文件夹。

在文件资源管理器工具栏单击新建文件按钮：

![文件资源管理器新建文件](./images/toolbar-new-file.png)

命名为 `app.js`：

![文件资源管理器中的 app.js](./images/app-js-file-created.png)

使用 `.js` 扩展名时，VS Code 会将其解释为 JavaScript，并使用 JavaScript 语言服务分析内容。JavaScript 支持详情请参阅 [JavaScript 语言](../../language-support/10.2.1-JavaScript/)。

在 `app.js` 中创建简单字符串变量并输出到控制台：

```javascript
var msg = 'Hello World';
console.log(msg);
```

输入 `console.` 时会自动显示 `console` 对象的 [IntelliSense](../../../editor/3.2-WriteCode/3.2.2-IntelliSense/)。

![console IntelliSense](./images/consoleintellisense.png)

VS Code 根据 `'Hello World'` 初始化知道 `msg` 是字符串。输入 `msg.` 会看到字符串函数的 IntelliSense。

![字符串 IntelliSense](./images/stringintellisense.png)

实验后请还原示例代码并保存文件（`Ctrl + S`）。

### 运行 Hello World {#running-hello-world}

使用 Node.js 运行 `app.js` 很简单。在终端输入：

```bash
node app.js
```

应看到终端输出“Hello World”，然后 Node.js 返回。

### 集成终端 {#integrated-terminal}

　　VS Code 有[集成终端](../../../terminal/5.2-TerminalBasics/)，可以运行 shell 命令，无需离开 VS Code。

**视图** > **终端**（`Ctrl + 反引号`）会打开集成终端，可以在其中运行 `node app.js`：

![集成终端](./images/integrated-terminal.png)

本演练可以使用外部终端或 VS Code 集成终端运行命令行工具。

### 调试 Hello World {#debugging-hello-world}

　　VS Code 自带 Node.js 应用调试器。为 `app.js` 设置断点：将光标放在第一行，按 `F9` 或单击行号左侧装订线。装订线会出现红圈。

![app.js 设置断点](./images/app-js-breakpoint-set.png)

在活动栏选择 **运行和调试** 视图：

![运行图标](./images/debugicon.png)

单击调试工具栏绿色箭头或按 `F5` 启动并调试“Hello World”。会命中断点，可以查看并单步执行应用。注意 VS Code 会显示不同颜色状态栏表示调试模式，并显示调试控制台。

![Hello World 调试](./images/hello-world-debugging.png)

> **注意**：完成“Hello World”示例后，请离开该文件夹再创建 Express 应用。可以删除 `hello` 文件夹，后续演练不需要。

## Express 应用 {#an-express-application}

　　[Express](https://expressjs.com/)是构建和运行 Node.js 应用的流行框架。可以使用 Express Generator 创建新应用。Express Generator 作为 npm 模块发布，通过 `npm` 安装。

> **提示**：要测试 npm 是否正确安装，请在终端输入 `npm --help`。

安装 Express Generator：

```bash
npm install -g express-generator
```

`-g` 开关将 Express Generator 全局安装到机器上，可以在任何位置运行。

创建名为 `myExpressApp` 的新 Express 应用：

```bash
express myExpressApp --view pug
```

这会创建包含应用内容的 `myExpressApp` 文件夹。`--view pug` 参数告诉生成器使用 [pug](https://pugjs.org/api/getting-started.html) 模板引擎。

安装应用依赖：

```bash
cd myExpressApp
npm install
```

生成的 Express 应用包含 `package.json`，其中 `start` 脚本运行 `node ./bin/www`。

在 Express 应用文件夹终端运行：

```bash
npm start
```

Node.js Web 服务器会启动，可以浏览 [http://localhost:3000](http://localhost:3000) 查看应用。

![第一个 Node Express 应用](./images/express.png)

## 出色的代码编辑 {#great-code-editing}

关闭浏览器，在 `myExpressApp` 文件夹终端按 `Ctrl+C` 停止 Node.js 服务器。

启动 VS Code：

```bash
code .
```

> **注意**：如果一直使用 VS Code 集成终端安装 Express Generator 并创建应用，可以通过 **文件** > **打开文件夹** 打开 `myExpressApp`。

[Node.js](https://nodejs.org/api/)和 [Express](https://expressjs.com/api.html) 文档详细说明如何使用平台和框架构建应用。VS Code 通过出色的代码编辑和导航体验提高开发效率。

打开 `app.js`，悬停在 Node.js 全局对象 `__dirname` 上。VS Code 知道 `__dirname` 是字符串。还可以获得 Node.js 框架的完整 IntelliSense。例如 require `http` 后，输入时可以获得 `http` 类的完整 IntelliSense。

![http IntelliSense](./images/node-intellisense.png)

　　VS Code 使用 TypeScript 类型声明（typings）文件（例如 `node.d.ts`）提供 JavaScript 框架元数据。类型声明文件用 TypeScript 编写，可以表达参数和函数类型，从而提供丰富 IntelliSense。`Automatic Type Acquisition` 会自动下载和安装这些文件。

也可以引用其他文件中的模块。例如 `app.js` require `./routes/index`，它导出 `Express.Router` 类。在 `index` 上打开 IntelliSense 可以看到 `Router` 类的结构。

![Express.Router IntelliSense](./images/moduleintellisense.png)

## 调试 Express 应用 {#debug-your-express-app}

需要为 Express 应用创建调试配置文件 `launch.json`。在活动栏选择 **运行和调试**（`Ctrl + Shift + D`），选择 **创建 launch.json 文件** 链接创建默认文件。选择 **Node.js** 环境，确保 `configurations` 中 `type` 为 `"node"`。首次创建文件时，VS Code 会查找 `package.json` 的 `start` 脚本，并将其作为 **Launch Program** 配置的 `program`（本例为 `"${workspaceFolder}\\bin\\www"`）。

```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "type": "node",
            "request": "launch",
            "name": "Launch Program",
            "program": "${workspaceFolder}\\bin\\www"
        }
    ]
}
```

保存文件，确保 **运行和调试** 视图顶部下拉列表选择 **Launch Program**。打开 `app.js`，在创建 Express 应用对象附近的行号左侧单击设置断点。按 `F5` 启动调试。VS Code 会在新终端启动服务器并命中断点，可以检查变量、创建监视并单步执行代码。

![调试会话](./images/debugsession.png)
