# 7.4 遥测

　　Visual Studio Code 会收集遥测数据，以帮助了解产品的使用方式并改进产品。组织可以集中管理遥测设置，控制整个开发团队收集哪些数据。本文介绍 IT 管理员如何通过[7.1 企业策略](../7.1-Policies/)配置遥测。

## 遥测相关策略 {#telemetry-related-policies}

　　VS Code 提供以下用于管理遥测的策略：

| 策略 | 说明 | VS Code 设置 | 起始版本 |
|------------------|------------------------------------------------------------|---------------------------------------|-----------------|
| `TelemetryLevel` | 指定遥测数据级别 | `telemetry.telemetryLevel` | 1.99 |
| `EnableFeedback` | 配置反馈机制（问题报告器和调查） | `telemetry.feedback.enabled` | 1.99 |

　　了解如何向组织设备[7.1 企业策略](../7.1-Policies/)。

## 配置遥测级别 {#configure-telemetry-level}

　　`TelemetryLevel` 策略控制 VS Code 遥测、第一方扩展遥测以及参与计划的第三方扩展遥测。

> **注意**：某些第三方扩展可能不遵守此设置。请查阅特定扩展的文档，了解其遥测报告方式。

### 遥测级别选项 {#telemetry-level-options}

| 值 | 崩溃报告 | 错误遥测 | 使用情况数据 |
|---------|:-------------:|:---------------:|:----------:|
| `all` | ✓ | ✓ | ✓ |
| `error` | ✓ | ✓ | - |
| `crash` | ✓ | - | - |
| `off` | - | - | - |

**数据类型：**

* **崩溃报告**：VS Code 崩溃时的诊断信息。
* **错误遥测**：不会导致应用程序崩溃的错误信息。
* **使用情况数据**：功能使用情况和性能信息。

### 禁用遥测 {#disable-telemetry}

　　要禁用整个组织的所有遥测，请将 `TelemetryLevel` 策略设置为 `off`：

**策略值：**

```text
off
```

> **重要**：将遥测设置为 `off` 或 `error` 会禁用 A/B 实验。这可能会推迟新功能向用户推出，直到这些功能正式发布。

### 仅启用错误遥测 {#enable-error-telemetry-only}

　　要仅收集崩溃报告和错误遥测，同时禁用使用情况数据，请将 `TelemetryLevel` 策略设置为 `error`：

**策略值：**

```text
error
```

## 配置反馈机制 {#configure-feedback-mechanisms}

　　`EnableFeedback` 策略控制用户能否访问 VS Code 中的反馈机制，例如问题报告器和调查。

　　要禁用反馈机制，请将 `EnableFeedback` 策略设置为 `false`：

**策略值：**

```text
false
```

## 扩展遥测 {#extension-telemetry}

　　VS Code 扩展可能收集自己的遥测数据。`telemetry.telemetryLevel` 设置会影响第一方 Microsoft 扩展和参与计划的第三方扩展。但某些扩展可能不遵守此设置，并可能拥有自己的遥测配置。

　　请查看组织中所用扩展的文档，了解其遥测做法。

## 智能体交互的 OpenTelemetry 支持 {#opentelemetry-support-for-agent-interactions}

　　VS Code 中的 Copilot Chat 可以通过 [OpenTelemetry](https://opentelemetry.io/)（OTel）导出跟踪、指标和事件，让你实时了解智能体交互、LLM 调用、工具执行和令牌使用情况。你可以将此遥测数据与任何兼容 OTel 的后端配合使用。

　　详细了解如何[使用 OpenTelemetry 监控智能体交互](https://github.com/microsoft/vscode-copilot-chat/blob/main/docs/monitoring/agent_monitoring.md)。

## GDPR 合规性 {#gdpr-compliance}

　　VS Code 的设计符合 GDPR。用户禁用遥测后，VS Code 会停止发送遥测数据。有关 GDPR 与 VS Code 的更多信息，请参阅[3.3.11 遥测](../../editor/3.3-ConfigureTheEditor/3.3.11-Telemetry/#gdpr-and-vs-code)。
