# 7.5 更新

　　Visual Studio Code 每周发布包含新功能、缺陷修复和安全补丁的更新。组织可以集中管理开发团队中 VS Code 更新的处理方式。本文介绍 IT 管理员如何通过[7.1 企业策略](../7.1-Policies/)配置自动更新。

## 更新策略 {#update-policy}

　　VS Code 提供 `UpdateMode` 策略来控制自动更新。此策略控制 VS Code 中的 `update.mode` 设置。了解如何向组织设备[7.1 企业策略](../7.1-Policies/)。

## 更新模式选项 {#update-mode-options}

　　`UpdateMode` 策略接受以下值：

| 值 | 说明 |
|-----------|-----------------------------------------------------------------------------|
| `default` | 启用自动检查更新，并在后台运行 |
| `start` | 仅在 VS Code 启动时检查更新 |
| `manual` | 禁用自动检查；用户可以手动检查更新 |
| `none` | 完全禁用更新 |

## 禁用自动更新 {#disable-automatic-updates}

　　要阻止 VS Code 自动检查或安装更新，请将 `UpdateMode` 策略设置为 `none`：

**策略值：**

```text
none
```

　　禁用更新后，用户无法通过应用程序更新 VS Code。你可以通过软件部署工具控制 VS Code 版本。

## 仅启用手动更新 {#enable-manual-updates-only}

　　要允许用户手动检查更新，同时禁用自动后台检查，请将 `UpdateMode` 策略设置为 `manual`：

**策略值：**

```text
manual
```

　　用户可以选择 **帮助** > **检查更新** 来检查更新。

## 仅在启动时检查更新 {#check-for-updates-at-startup-only}

　　要仅在 VS Code 启动时检查更新，而不进行后台检查，请将 `UpdateMode` 策略设置为 `start`：

**策略值：**

```text
start
```

## 网络要求 {#network-requirements}

　　VS Code 从 Microsoft 服务器下载更新。如果你的网络访问受限，请确保允许以下主机名：

* `update.code.visualstudio.com`：VS Code 下载和更新服务器。

　　完整主机名列表请参阅[9.6 网络连接](../../advanced-setup/9.6-Network/#common-hostnames)。
