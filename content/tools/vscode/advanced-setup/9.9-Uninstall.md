# 9.9 卸载

　　卸载 Visual Studio Code 的步骤取决于你的平台（Windows、macOS 或 Linux）以及使用的安装选项。例如在 Windows 上，可以使用 System 或 User Windows 安装程序，或下载 `.zip` 文件并解压到任意位置。通常，你可以像卸载其他桌面应用程序一样，按照平台推荐的软件卸载流程操作。

## Windows {#windows}

### Windows 安装程序 {#windows-installer}

　　如果通过 Windows 安装程序（User 或 System 版本）安装，请使用安装程序或系统设置卸载 VS Code。

* **开始菜单**
  * 搜索 **添加或删除程序**，在 **应用** > **应用和功能** 列表中找到 VS Code。
  * 在右侧操作下拉列表（三个垂直点）中选择 **卸载**。
  * 按照提示卸载 VS Code。
* **控制面板**
  * 在 **程序** 下选择 **卸载程序** 链接。
  * 找到 VS Code 条目，右键单击并选择 **卸载** 命令。
  * 按照提示卸载 VS Code。

### .zip 文件安装 {#zip-file-installation}

　　如果通过下载并解压 [VS Code 网站](https://code.visualstudio.com/#alt-downloads)上的 `.zip` 文件安装，请删除解压后的文件夹。

## macOS {#macos}

　　打开 **Finder** 并进入 **Applications**，右键单击 VS Code 应用程序，选择 **移到废纸篓**。

## Linux {#linux}

　　在 Linux 上，应使用包管理器的卸载或移除选项，具体命令取决于使用的包管理器（例如 `apt-get`、`rpm`、`dnf`、`yum` 等）。VS Code 包名称为：

* `code`：VS Code 稳定版
* `code-insiders`：VS Code [Insiders](https://code.visualstudio.com/insiders) 版本

　　例如，如果通过 Debian 包（`.deb`）和 `apt-get` 安装：

```bash
sudo apt-get remove code
```

## 彻底卸载 {#clean-uninstall}

　　如果卸载后还要删除所有用户数据，可以删除用户数据文件夹 `Code`、`.vscode-shared` 和 `.vscode`。这会将环境恢复到安装 VS Code 之前的状态，也可以用于在不卸载的情况下重置所有设置。

* **Windows**：删除 `%APPDATA%\Code`、`%USERPROFILE%\.vscode-shared` 和 `%USERPROFILE%\.vscode`。
* **macOS**：删除 `$HOME/Library/Application Support/Code`、`~/.vscode-shared` 和 `~/.vscode`。
* **Linux**：删除 `$HOME/.config/Code`、`~/.vscode-shared` 和 `~/.vscode`。
