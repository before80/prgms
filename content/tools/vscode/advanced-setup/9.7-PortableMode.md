# 9.7 便携模式

　　Visual Studio Code 支持[便携模式](https://en.wikipedia.org/wiki/Portable_application)。此模式使 VS Code 创建和维护的所有数据都位于其附近，因此可以在不同环境中移动。

　　此模式还提供了一种设置 VS Code 扩展安装文件夹位置的方法，适用于禁止将扩展安装到 Windows AppData 文件夹的企业环境。

　　便携模式支持 Windows 的 ZIP 下载、Linux 的 TAR.GZ 下载，以及 macOS 的常规应用程序下载。

> **重要**：不要尝试在通过 **Windows User 或 System 安装程序**安装的版本上配置便携模式。便携模式仅支持 Windows ZIP（`.zip`）压缩包。Windows ZIP 压缩包也不支持自动更新。

## 启用便携模式 {#enable-portable-mode}

### Windows、Linux {#windows-linux}

　　解压 VS Code 下载文件后，在 VS Code 文件夹中创建一个 `data` 文件夹：

```
|- VSCode-win32-x64-1.84.2
|   |- Code.exe（或 code 可执行文件）
|   |- data
|   |- bin
|   |  |- code
|   |  |- ...
|   |- ...
```

　　此后，`data` 文件夹将包含所有 VS Code 数据，包括会话状态、首选项、扩展等。

> **注意**：`data` 文件夹会覆盖 `--user-data-dir` 和 `--extensions-dir` 命令行选项。

　　`data` 文件夹可以移到其他 VS Code 安装中。这在更新便携版时很有用，可以将 `data` 文件夹移到较新的解压版本中。

### Linux {#linux}

　　在 **Linux** 上，除了创建 `data` 文件夹外，还需要设置正确的 [Electron 沙盒](https://www.electronjs.org/docs/tutorial/sandbox)权限。Chromium 在 Linux 上有[多层沙盒模型](https://chromium.googlesource.com/chromium/src/+/0e94f26e8/docs/linux_sandboxing.md)。如果 Chromium 无法使用命名空间沙盒，会尝试通过随应用提供的 `chrome-sandbox` 使用 `setuid` 沙盒。运行以下命令设置正确的权限：

```bash
sudo chown root <path-to-vscode>/chrome-sandbox
sudo chmod 4755 <path-to-vscode>/chrome-sandbox
```

### macOS {#macos}

　　在 **macOS** 上，需要将 data 文件夹放在应用程序本身旁边。由于文件夹与应用程序并列，必须使用特定名称，以便 VS Code 找到它。默认文件夹名称为 `code-portable-data`：

```
|- Visual Studio Code.app
|- code-portable-data
```

　　如果应用程序处于[隔离](https://apple.stackexchange.com/a/104875)状态（刚下载的 VS Code 默认如此），便携模式将无法工作。请移除隔离属性：

```bash
xattr -dr com.apple.quarantine Visual\ Studio\ Code.app
```

> **注意**：在 Insiders 中，文件夹应命名为 `code-insiders-portable-data`。

## 更新便携版 VS Code {#update-portable-vs-code}

　　在 **Windows** 和 **Linux** 上，可以将 `data` 文件夹复制到较新的 VS Code 版本来更新。在 **macOS** 上，自动更新应像往常一样工作，无需额外操作。

## 迁移到便携模式 {#migrate-to-portable-mode}

### Windows、Linux {#windows-linux-1}

1. 下载适用于你的平台的 [VS Code](https://code.visualstudio.com/download)（或 [Insiders](https://code.visualstudio.com/insiders)）ZIP 发行版。
2. 按上述方式创建 `data` 文件夹。
3. 复制用户数据目录 `Code` 到 `data`，并将其重命名为 `user-data`：
    * **Windows**：`%APPDATA%\Code`
    * **Linux**：`$HOME/.config/Code`
4. 复制扩展目录到 `data`：
    * **Windows**：`%USERPROFILE%\.vscode\extensions`
    * **Linux**：`~/.vscode/extensions`

**Windows** 上的目标结构示例：

```
|- VSCode-win32-x64-1.84.2
|   |- Code.exe（或 code 可执行文件）
|   |- data
|   |   |- user-data
|   |   |   |- ...
|   |   |- extensions
|   |   |   |- ...
|   |- ...
```

### macOS {#macos-1}

1. 下载适用于 macOS 的 [VS Code](https://code.visualstudio.com/download)（或 [Insiders](https://code.visualstudio.com/insiders)）。
2. 按上述方式创建 `code-portable-data` 文件夹。
3. 复制用户数据目录 `Code` 到 `code-portable-data`，并将其重命名为 `user-data`：`$HOME/Library/Application Support/Code`。
4. 复制扩展目录到 `code-portable-data`：`~/.vscode/extensions`。

## TMP 目录 {#tmp-directory}

　　默认情况下，即使在便携模式下，默认 `TMP` 目录仍使用系统目录，因为不会在那里保留状态。如果希望 TMP 目录也位于便携目录中，可以在 `data` 文件夹内创建一个空的 `tmp` 目录。只要 `tmp` 目录存在，就会用于 TMP 数据。
