# 9.8 其他组件

　　Visual Studio Code 的体积很小，只包含大多数开发工作流共用的最少组件。编辑器、文件管理、窗口管理和首选项设置等基本功能均已包含。JavaScript/TypeScript 语言服务和 Node.js 调试器也是基础安装的一部分。

　　如果你习惯了大型一体化开发工具（IDE），可能会惊讶于某些场景并非开箱即用。例如，没有预装项目模板的 **文件** > **新建项目** 对话框。大多数 VS Code 用户需要根据具体需求安装其他组件。

## 常用组件 {#commonly-used-components}

* [Git](https://git-scm.com/download)：VS Code 内置使用 Git 的源代码管理支持，但需要单独安装 Git。
* [Node.js（包含 npm）](https://nodejs.org/)：用于构建和运行 JavaScript 应用程序的跨平台运行时。
* [TypeScript](https://www.typescriptlang.org)：TypeScript 编译器 `tsc`，用于将 TypeScript 转译为 JavaScript。

## VS Code 扩展 {#vs-code-extensions}

　　可以通过[3.3.6.1 扩展概述](../../editor/3.3-ConfigureTheEditor/3.3.6-Extensions/3.3.6.1-Overview/)扩展 VS Code 编辑器本身。VS Code 社区在 [Marketplace](https://marketplace.visualstudio.com/VSCode)上构建了数千个有用的扩展。

## 其他工具 {#additional-tools}

* [Yeoman](https://yeoman.io/)：应用程序脚手架工具，相当于 **文件** > **新建项目** 的命令行版本。
* [generator-hottowel](https://github.com/johnpapa/generator-hottowel)：用于快速创建 AngularJS 应用程序的 Yeoman 生成器。
* [Express](https://expressjs.com/)：使用 Pug 模板引擎的 Node.js 应用程序框架。
* [Gulp](https://gulpjs.com/)：流式任务运行器，可轻松与 VS Code 任务集成。
* [Mocha](https://mochajs.org/)：运行在 Node.js 上的 JavaScript 测试框架。
* [Yarn](https://yarnpkg.com/)：依赖管理器，也是 npm 的替代方案。

> **注意**：大多数工具需要 Node.js 和 npm 包管理器才能安装和使用。
