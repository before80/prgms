# 9.2 Linux

　　VS Code 在 Linux 上提供官方 Debian、RPM 和 Snap 包。Arch Linux 和 Nix 还有社区维护的包。

## 在 Linux 上安装 VS Code {#install-vs-code-on-linux}

选择与 Linux 发行版匹配的包安装方式。

### Debian 和 Ubuntu 系发行版 {#debian-and-ubuntu-based-distributions}

1. 下载 [.deb 包](https://go.microsoft.com/fwlink/?LinkID=760868)。
2. 使用图形软件中心安装，或从命令行安装：

    ```bash
    sudo apt install ./<file>.deb

    # 较旧 Linux 发行版请改用以下命令：
    # sudo dpkg -i <file>.deb
    # sudo apt-get install -f # 安装依赖项
    ```

    > **注意**：其他二进制文件请参阅 [VS Code 下载页](https://code.visualstudio.com/download)。

`.deb` 包会提示安装 apt 仓库和签名密钥，从而通过系统包管理器自动更新。

非交互式安装时，请在安装 `.deb` 包前运行以下命令，自动安装 apt 仓库和签名密钥：

```bash
echo "code code/add-microsoft-repo boolean true" | sudo debconf-set-selections
```

手动安装 apt 仓库：

1. 安装签名密钥：

    ```bash
    sudo apt install wget gpg &&
    wget -qO- https://packages.microsoft.com/keys/microsoft.asc | sudo gpg --dearmor -o /usr/share/keyrings/microsoft.gpg
    ```

2. 创建包含以下内容的 `/etc/apt/sources.list.d/vscode.sources` 文件：

    ```plaintext
    Types: deb
    URIs: https://packages.microsoft.com/repos/code
    Suites: stable
    Components: main
    Architectures: amd64,arm64,armhf
    Signed-By: /usr/share/keyrings/microsoft.gpg
    ```

3. 更新包缓存并安装：

    ```bash
    sudo apt update &&
    sudo apt install code # 或 code-insiders
    ```

> **注意**：由于手动签名和发布系统，Debian 仓库可能滞后最多三小时，不一定立即包含最新版 VS Code。

### RHEL、Fedora 和 CentOS 系发行版 {#rhel-fedora-and-centos-based-distributions}

　　Microsoft 在 yum 仓库中为 RHEL、Fedora 和 CentOS 系发行版提供稳定的 64 位 VS Code 包。

1. 安装密钥和 yum 仓库：

    ```bash
    sudo rpm --import https://packages.microsoft.com/keys/microsoft.asc &&
    echo -e "[code]\nname=Visual Studio Code\nbaseurl=https://packages.microsoft.com/yumrepos/vscode\nenabled=1\nautorefresh=1\ntype=rpm-md\ngpgcheck=1\ngpgkey=https://packages.microsoft.com/keys/microsoft.asc" | sudo tee /etc/yum.repos.d/vscode.repo > /dev/null
    ```

2. 在 Fedora 22 及更高版本使用 `dnf` 更新包缓存并安装：

    ```bash
    dnf check-update &&
    sudo dnf install code # 或 code-insiders
    ```

    旧版本使用 `yum`：

    ```bash
    yum check-update &&
    sudo yum install code # 或 code-insiders
    ```

> **注意**：由于手动签名和发布系统，yum 仓库可能滞后最多三小时，不一定立即包含最新版 VS Code。

### Snap 包 {#snap-package}

　　VS Code 在 [Snap Store](https://snapcraft.io/store) 官方提供 Snap 包。

[![从 Snap Store 获取](../images/snap-store.png)](https://snapcraft.io/code)

使用以下命令安装 Snap 包：

```bash
sudo snap install --classic code # 或 code-insiders
```

　　安装后，Snap 守护进程会在后台自动更新 VS Code。有新更新时，VS Code 会显示产品内更新通知。

> **注意**：Linux 发行版没有 `snap` 时，请参阅[安装 snapd 指南](https://docs.snapcraft.io/installing-snapd)。

　　更多信息请参阅[官方 Snap 文档](https://docs.snapcraft.io)。

### openSUSE 和 SLE 系发行版 {#opensuse-and-sle-based-distributions}

　　[RHEL、Fedora 和 CentOS 面板](#rhel-fedora-and-centos-based-distributions)中的 yum 仓库也适用于 openSUSE 和 SLE 系系统。

1. 安装密钥和 yum 仓库：

    ```bash
    sudo rpm --import https://packages.microsoft.com/keys/microsoft.asc &&
    echo -e "[code]\nname=Visual Studio Code\nbaseurl=https://packages.microsoft.com/yumrepos/vscode\nenabled=1\nautorefresh=1\ntype=rpm-md\ngpgcheck=1\ngpgkey=https://packages.microsoft.com/keys/microsoft.asc" | sudo tee /etc/zypp/repos.d/vscode.repo > /dev/null
    ```

2. 更新包缓存并安装：

    ```bash
    sudo zypper install code
    ```

### Arch Linux AUR 包 {#arch-linux-aur-package}

　　[VS Code 的 Arch User Repository 包](https://aur.archlinux.org/packages/visual-studio-code-bin)由社区维护。

安装详情请参阅 Arch Linux wiki 的[安装 AUR 包](https://wiki.archlinux.org/index.php/Arch_User_Repository)文章。

### Nix 包 {#nix-package}

　　nixpkgs 仓库中的 [VS Code Nix 包](https://github.com/NixOS/nixpkgs/blob/master/pkgs/applications/editors/vscode/vscode.nix)由社区维护。

使用 Nix 安装 VS Code：

1. 在 `config.nix` 中将 `allowUnfree` 选项设置为 true。
2. 运行：

    ```bash
    nix-env -i vscode
    ```

### 手动 RPM 包 {#manual-rpm-package}

　　无法通过仓库安装时，请手动下载并安装 [VS Code .rpm 包](https://go.microsoft.com/fwlink/?LinkID=760867)。未安装仓库时自动更新不可用。

使用包管理器安装下载的 `.rpm` 包，例如 `dnf`：

```bash
sudo dnf install <file>.rpm
```

> **注意**：其他二进制文件请参阅 [VS Code 下载页](https://code.visualstudio.com/download)。

## 更新 {#updates}

　　VS Code 每周发布[版本](https://code.visualstudio.com/updates)。VS Code 仓库正确安装后，系统包管理器会像处理其他系统包一样处理自动更新。

> **注意**：[Snap 包](#snap-package)的更新自动并在后台运行。

## 将 VS Code 配置为默认文本编辑器 {#configure-vs-code-as-the-default-text-editor}

### xdg-open {#xdg-open}

将 VS Code 设置为 `xdg-open` 使用的 `text/plain` 文本文件默认编辑器：

```bash
xdg-mime default code.desktop text/plain
```

### Debian alternatives 系统 {#debian-alternatives-system}

　　Debian 系发行版支持通过 [Debian alternatives 系统](https://wiki.debian.org/DebianAlternatives)设置默认 **editor**，无需考虑 MIME 类型。使用以下命令将 VS Code 设置为默认编辑器：

```bash
sudo update-alternatives --set editor /usr/bin/code
```

　　使用 Snap 包安装 VS Code 时，请改用：

```bash
sudo update-alternatives --set editor /snap/bin/code
```

　　VS Code 未显示为默认 `editor` 替代项时，请注册：

```bash
sudo update-alternatives --install /usr/bin/editor editor $(which code) 10
```

## 使用自定义标题栏 {#use-the-custom-title-bar}

　　自定义标题栏提供主题支持，并通过键盘导航和屏幕阅读器改善辅助功能。由于 Linux 桌面环境和窗口管理器各不相同，这些优势不一定总能体现。因此 Linux 上默认不启用自定义标题栏。

　　使用屏幕阅读器时，如需辅助功能改进，请在辅助功能模式中启用自定义标题栏。

使用 **Window: Title Bar Style**（`window.titleBarStyle`）设置配置标题栏：

* `custom`：使用自定义标题栏。
* `native`：使用操作系统标题栏。

## 使用 WSL 在 Linux 上开发 {#develop-on-linux-with-wsl}

　　使用 VS Code 进行 Linux 开发的另一种方式是在 Windows 机器上使用 [Windows Subsystem for Linux](https://learn.microsoft.com/windows/wsl/install)（WSL）。

　　使用 WSL 可以在 Windows 上安装和运行 Linux 发行版，在 Windows 本地工作的同时在 Linux 上开发和测试源代码。WSL 支持 Microsoft Store 中的 Ubuntu、Debian、SUSE 和 Alpine 等 Linux 发行版。

　　与 [WSL 扩展](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-wsl)配合时，VS Code 在 WSL 中 Linux 发行版上下文中运行时提供编辑和调试支持。

　　更多信息请参阅[在 WSL 中开发](../../remote/8.6-WSL/)文档，或尝试[在 WSL 中工作](../../remote/8.7-WSLTutorial/)入门教程。

## 常见问题 {#common-questions}

### 未安装包 git {#package-git-is-not-installed}

　　包管理器列表过期时，安装期间可能出现此错误。请更新包管理器并重新安装：

```bash
# 对于 .deb
sudo apt-get update

# 对于 Fedora 21 及更早版本的 .rpm
sudo yum check-update

# 对于 Fedora 22 及更高版本的 .rpm
sudo dnf check-update
```

### 与其他仓库的 VS Code 包冲突 {#conflicts-with-vs-code-packages-from-other-repositories}

　　某些发行版（例如 [Pop!_OS](https://pop.system76.com)）提供自己的 `code` 包。要确保使用官方 VS Code 仓库，请创建包含以下内容的 `/etc/apt/preferences.d/code` 文件：

```plaintext
Package: code
Pin: origin "packages.microsoft.com"
Pin-Priority: 9999
```

### Debian 中文件移到回收站失败 {#debian-and-moving-files-to-trash}

　　在 Debian 中从 VS Code 资源管理器删除文件失败时，VS Code 使用的回收站实现可能缺失。

运行以下命令安装缺失的包：

```bash
sudo apt-get install gvfs libglib2.0-bin
```

### “VS Code 无法监视此大型工作区中的文件更改”（ENOSPC 错误） {#vs-code-is-unable-to-watch-for-file-changes-in-this-large-workspace-error-enospc}

　　此通知表示 VS Code 文件监视器耗尽文件句柄。打开包含许多文件的工作区时经常发生。调整平台限制前，请将大型文件夹（例如 Python `.venv`）添加到 `files.watcherExclude` 设置。其他运行中的应用也可能消耗文件句柄，关闭其他应用可能有帮助。

运行以下命令查看当前限制：

```bash
cat /proc/sys/fs/inotify/max_user_watches
```

编辑 `/etc/sysctl.conf` 并在文件末尾添加以下行，将限制提高到最大值。Arch Linux 和 Ubuntu 24.10 及更高版本使用 `/etc/sysctl.d/*.conf` 中的文件。

```bash
fs.inotify.max_user_watches=524288
```

加载新值：

```bash
sudo sysctl --system
```

　　每个文件监视[占用 1,080 字节](https://stackoverflow.com/a/7091897/1156119)。如果 524,288 个监视全部消耗，上限约为 540 MiB。内存受限环境中请选择较低值。

　　另一种方法是使用 `files.watcherExclude` [设置](../../editor/3.3-ConfigureTheEditor/3.3.4-Settings/)将特定工作区目录排除在 VS Code 文件监视器之外。默认 `files.watcherExclude` 值排除 `node_modules` 和 `.git` 下的某些文件夹。请添加 VS Code 不应跟踪的其他目录。

```json
"files.watcherExclude": {
    "**/.git/objects/**": true,
    "**/.git/subtree-cache/**": true,
    "**/node_modules/*/**": true
}
```

### Ubuntu 中看不到中文字符 {#i-cant-see-chinese-characters-in-ubuntu}

　　打开应用程序菜单，选择 **文件** > **首选项** > **设置**。在 **文本编辑器** > **字体** 部分将 **字体族** 设置为 `Droid Sans Mono, Droid Sans Fallback`。

直接编辑 `settings.json` 文件时，设置 `editor.fontFamily`：

```json
"editor.fontFamily": "Droid Sans Mono, Droid Sans Fallback"
```

### Ubuntu 中 code bin 命令不将窗口带到前台 {#the-code-bin-command-does-not-bring-the-window-to-the-foreground-on-ubuntu}

　　Ubuntu 中当前目录已打开 VS Code 时运行 `code .` 不会将 VS Code 带到前台。这是可以通过 `ccsm` 更改的操作系统行为。

```bash
# 安装
sudo apt-get update
sudo apt-get install compizconfig-settings-manager

# 运行
ccsm
```

在 **General** > **General Options** > **Focus & Raise Behavior** 下将 **Focus Prevention Level** 设置为 **Off**。此操作系统设置适用于所有应用，不仅 VS Code。

### 因“/etc/apt/sources.list.d/vscode.list: No such file or directory”无法安装 .deb 包 {#cannot-install-deb-package-due-to-etcaptsourceslistdvscodelist-no-such-file-or-directory}

　　`sources.list.d` 不存在或当前用户无权创建文件时可能出现此错误。请创建文件夹和空 `vscode.list` 文件：

```bash
sudo mkdir /etc/apt/sources.list.d
sudo touch /etc/apt/sources.list.d/vscode.list
```

### X 转发远程窗口时无法移动或调整窗口大小 {#cannot-move-or-resize-the-window-while-x-forwarding-a-remote-window}

　　使用 X 转发远程使用 VS Code 时，请使用原生标题栏操作窗口。将 `window.titleBarStyle` 设置为 `native`。

### 仓库更改了 origin 值 {#repository-changed-its-origin-value}

出现类似以下错误时：

```plaintext
E: Repository '...' changed its 'Origin' value from '...' to '...'
N: This must be accepted explicitly before updates for this repository can be applied. See apt-secure(8) manpage for details.
```

请使用 `apt` 而不是 `apt-get`，并在提示时接受 origin 更改：

```bash
sudo apt update
```
