# 9.4 在 Windows 上安装

　　Visual Studio Code 可通过用户安装程序、系统安装程序和 ZIP 压缩包在 Windows 上使用。对于大多数人，推荐使用 User 安装，因为它不需要管理员权限，并支持更顺畅的后台更新。

## 在 Windows 上安装 VS Code {#install-vs-code-on-windows}

### 选择 User 安装还是 System 安装 {#choose-user-setup-or-system-setup}

| 安装类型 | 使用场景 | 说明 |
|------------|----------|-------|
| [User 安装](https://go.microsoft.com/fwlink/?LinkID=534107) | 为你的 Windows 账户安装 VS Code。 | 不需要管理员权限，安装在 `%LOCALAPPDATA%\Programs\Microsoft VS Code` 下，提供最顺畅的更新体验。如果以管理员身份运行 User 安装的 VS Code，更新会被禁用。 |
| [System 安装](https://go.microsoft.com/fwlink/?linkid=852157) | 为计算机上的所有用户安装 VS Code。 | 需要管理员权限，安装在 `Program Files` 下。产品内更新也需要提升权限。 |

　　完整安装选项列表请参阅[下载 VS Code](https://code.visualstudio.com/download) 页面。

### 使用 Windows 安装程序安装 {#install-with-the-windows-installer}

1. 下载适用于 Windows 的 [VS Code User 安装程序](https://go.microsoft.com/fwlink/?LinkID=534107)。
2. 运行安装程序 `VSCodeUserSetup-{version}.exe`。默认情况下，User 安装会将 VS Code 安装在 `C:\Users\{Username}\AppData\Local\Programs\Microsoft VS Code`。

> **提示**：安装程序会将 VS Code 添加到 `%PATH%` 环境变量。安装后请重新启动控制台，然后在文件夹中运行 `code .` 打开它。

### 使用 System 安装 {#install-with-the-system-setup}

1. 下载适用于 Windows 的 [VS Code System 安装程序](https://go.microsoft.com/fwlink/?linkid=852157)。
2. 以管理员权限运行安装程序。

　　System 安装使计算机上的所有用户都可以使用 VS Code。

### 设置 copilot 命令 {#set-up-the-copilot-command}

　　安装程序可以将 `copilot` 命令添加到 `%PATH%`，以便从任何终端运行 GitHub Copilot CLI。Copilot CLI 是单独的 GitHub 产品，有自己的许可条款，并且需要 GitHub Copilot 订阅。

　　如果未安装 Copilot CLI，User 安装会显示 **GitHub Copilot CLI** 页面，提供以下选项：

* **立即安装 GitHub Copilot CLI**：安装程序将 `copilot` 添加到 `%PATH%`，安装 VS Code 后从 GitHub 下载并安装 Copilot CLI。
* **首次运行 copilot 时安装 GitHub Copilot CLI**：将 `copilot` 添加到 `%PATH%`，直到你运行 `copilot` 并确认安装时才下载。
* **不添加 copilot 命令**：不将 `copilot` 添加到 `%PATH%`。仍可在 VS Code 集成终端中运行 `copilot`。

　　System 安装仅提供为所有用户添加命令或不添加。首次运行时，`copilot` 会询问每个用户是否下载 Copilot CLI。User 安装无法访问 GitHub 时，也只提供添加或不添加命令。

　　如果已安装 Copilot CLI、以管理员身份运行 User 安装，或管理员[7.2 管理 AI 设置](../../enterprise/7.2-ManageAISettings/#enable-or-disable-the-copilot-command)，安装程序会跳过此页面。

　　更新会保留你的选择，并且不会下载 Copilot CLI。要更改选择，请重新运行安装程序。Copilot CLI 会自行更新，卸载 VS Code 不会删除 Copilot CLI 或其数据。

> **提示**：安装后打开新终端才能使用 `copilot` 命令。

### 从 ZIP 压缩包安装 {#install-from-a-zip-archive}

1. 下载适用于 Windows 的 [VS Code ZIP 压缩包](https://code.visualstudio.com/download)。
2. 解压 ZIP 压缩包，并从解压后的文件夹运行 VS Code。

> **注意**：从 ZIP 压缩包安装时，需要在每次[发布](https://code.visualstudio.com/updates)后手动更新。

## 更新 {#updates}

　　VS Code 每周发布[更新](https://code.visualstudio.com/updates)，并支持在有新版本时自动更新。收到更新提示时，接受提示即可安装新版本。

> **注意**：如果希望按自己的计划更新，请[禁用自动更新](https://code.visualstudio.com/docs/supporting/faq#how-do-i-opt-out-of-vs-code-auto-updates)。

## 在 Windows 上开发 {#develop-on-windows}

　　Windows 是良好的跨平台开发环境。本节介绍 [Windows Subsystem for Linux](https://learn.microsoft.com/windows/wsl/install)（WSL）和 Windows Terminal。

> **注意**：请保持 Windows 更新。在 **设置** > **Windows 更新**中检查可用更新。

### Windows Subsystem for Linux {#windows-subsystem-for-linux}

　　使用 WSL，可以在 Windows 上安装和运行 Linux 发行版，在本地 Windows 计算机上开发并测试 Linux 源代码。配合 [WSL 扩展](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-wsl)时，VS Code 在 WSL 上下文中提供编辑和调试支持。更多信息请参阅[8.6 在 WSL 中开发](../../remote/8.6-WSL/)，或尝试[8.7 WSL 远程开发教程](../../remote/8.7-WSLTutorial/)入门教程。

### Windows Terminal {#windows-terminal}

　　[Windows Terminal](https://apps.microsoft.com/detail/9n0dx20hk701) 可从 Microsoft Store 获取，是用于命令提示符、PowerShell 和 WSL 等命令行工具和 shell 的终端应用。其主要功能包括多个选项卡、窗格、Unicode 和 UTF-8 字符支持、GPU 加速文本渲染引擎、自定义主题、样式和配置。

## 常见问题 {#common-questions}

<details>
<summary>Windows 安装程序支持哪些命令行参数？</summary>

　　VS Code 使用 [Inno Setup](https://www.jrsoftware.org/isinfo.php) 创建 Windows 安装包，支持所有 [Inno Setup 命令行开关](https://www.jrsoftware.org/ishelp/index.php?topic=setupcmdline)。要阻止安装完成后启动 VS Code，请使用 `/mergetasks=!runcode`。要选择静默安装时如何设置 [copilot 命令](#set-up-the-copilot-command)，请使用 `/copilotcli=install`、`/copilotcli=onfirstuse` 或 `/copilotcli=none`。

</details>

<details>
<summary>安装程序有问题</summary>

　　请改用 [ZIP 压缩包](https://code.visualstudio.com/download)。将 VS Code 解压到 `AppData\Local\Programs` 文件夹中。

</details>

<details>
<summary>启用 AppLocker 时无法以管理员身份运行</summary>

　　引入进程沙盒后，由于运行时沙盒限制，配置 AppLocker 时暂不支持以管理员身份运行。如果工作需要从提升的终端运行 VS Code，请运行 **Preferences: Configure Runtime Arguments**，在 `argv.json` 中添加 `"disable-chromium-sandbox": true`，然后重新启动。

</details>

<details>
<summary>使用 UNC 路径</summary>

　　从 1.78.1 开始，Windows 上的 VS Code 只打开用户在启动时批准、或通过 `security.allowedUNCHosts` 设置配置了主机名的 UNC 路径。可以配置 `security.allowedUNCHosts`、将 UNC 路径映射为网络驱动器，或定义 `NODE_UNC_HOST_ALLOWLIST` 环境变量。

</details>
