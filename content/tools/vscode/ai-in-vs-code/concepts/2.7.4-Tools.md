# 2.7.4 工具

　　工具是让[智能体](../2.7.1-Agents/)收集信息或执行操作的能力。没有工具，[语言模型](../2.7.2-HowModelsWork/)只能生成文本。有了工具，智能体可以读取文件、编辑代码、运行终端命令、搜索代码库并连接外部服务。

　　智能体使用工具时会发起**工具调用**，提供工具所需输入。工具运行并返回**工具输出**，它成为[智能体循环](../2.7.1-Agents/#agent-loop)下一步的[上下文](../2.7.3-Context/)的一部分。

　　本文解释工具如何融入智能体循环、VS Code 中可用的工具类型以及如何控制其使用。

## 智能体循环中的工具 {#tools-in-the-agent-loop}

例如，要求智能体修复失败测试时，它可能：

1. 调用搜索和文件读取工具查找测试及相关代码。
2. 使用返回的文件内容决定更改什么。
3. 调用编辑工具应用更改。
4. 调用终端工具运行测试。
5. 使用测试输出决定任务完成还是需要另一更改。

　　每次调用都为智能体提供新信息或更改开发环境。根据[权限级别](../../work-with-ai/permissions-and-security/2.2.12.1-ApprovalsAndPermissions/#permission-levels)，VS Code 可能在工具调用运行前要求你批准。

## 工具类型 {#types-of-tools}

VS Code 支持三种工具：

* **内置工具**：VS Code 随附的常见开发任务工具，例如读写文件、运行终端命令、搜索代码库和导航编辑器。这些工具无需设置即可立即使用。
* **MCP 工具**：由[模型上下文协议（MCP）](https://modelcontextprotocol.io/)服务器提供的工具，MCP 是连接 AI 模型与外部工具和数据源的开放标准。MCP 工具可以来自你[直接配置](../../customize-and-extend/2.4.7-AddMCPServers/)的服务器、托管的 [Copilot 连接器](../../customize-and-extend/2.4.6-CopilotConnectors/)或[智能体插件](../../customize-and-extend/2.4.2-Plugins/)中捆绑的服务器。MCP 服务器可以在你的计算机上本地运行或远程托管。使用 MCP 工具连接数据库、API 和其他外部服务。
* **扩展工具**：VS Code 扩展通过 Language Model Tools API 提供的工具。扩展工具与编辑器深度集成，并在安装扩展后可用。

### 连接外部服务 {#connect-external-services}

　　[Copilot 连接器](../../customize-and-extend/2.4.6-CopilotConnectors/)是 GitHub 管理的连接，为智能体添加 MCP 工具。例如，连接 Microsoft Learn Docs，使智能体在处理任务时可以检索官方文档。

　　对于受支持服务，当希望使用托管连接而无需本地服务器设置或手动 MCP 配置时，请使用连接器。如果服务没有连接器或需要自定义集成，请[添加 MCP 服务器](../../customize-and-extend/2.4.7-AddMCPServers/)。

　　连接器在 Copilot 运行框架会话中可用，Local 会话不可用。[从智能体自定义编辑器连接服务](../../customize-and-extend/2.4.6-CopilotConnectors/#connect-a-service)。

　　[智能体插件](../../customize-and-extend/2.4.2-Plugins/)可以将 MCP 服务器与技能、自定义智能体和其他自定义项捆绑。当希望这些工具成为打包工作流的一部分时，请使用插件。

## 智能体如何选择工具 {#how-agents-choose-tools}

　　默认情况下，智能体根据请求和当前上下文从已启用工具中选择。可以给智能体高层目标，而无需命名每个应使用的工具。

　　要将智能体引导到特定工具或工具组，请在提示词中添加 `#` 引用。了解如何[在请求中使用工具](../../work-with-ai/plan-and-run-tasks/2.2.10.2-UseTools/#use-tools-in-a-request)。

## 控制可用工具 {#control-which-tools-are-available}

　　可用工具来自 VS Code、已安装扩展或 MCP 服务器。要添加 MCP 工具，请配置服务器、连接 Copilot 连接器或安装捆绑服务器的智能体插件。已启用工具是允许智能体为请求选择的工具。

　　将已启用工具限制为任务相关能力。聚焦的工具集帮助智能体选择合适的工具，减少不必要操作的机会，并限制添加到[上下文窗口](../2.7.2-HowModelsWork/#context-window)的工具输出。

　　对于 Copilot 运行框架会话，工具选择会保存在活动[用户配置文件](../../../editor/3.3-ConfigureTheEditor/3.3.8-Profiles/)中。也可以为可复用[自定义智能体](../../customize-and-extend/2.4.5-CustomAgents/)固定工具。了解如何[管理可用工具](../../work-with-ai/plan-and-run-tasks/2.2.10.2-UseTools/#manage-available-tools)。

> **注意**：**对于 Local 运行框架会话：** 工具选择适用于单个聊天请求，不会跨请求持久保存。

## 工具审批和信任 {#tool-approval-and-trust}

　　工具可以编辑文件、修改环境或访问外部服务。VS Code 提供审查和限制这些操作的控件：

* **审批提示**：根据权限级别，工具调用在运行前可能需要确认。
* **URL 审批**：工具访问 URL 时，两步过程会验证请求和响应内容。
* **权限级别**：[权限选择器](../../work-with-ai/permissions-and-security/2.2.12.1-ApprovalsAndPermissions/#permission-levels)控制智能体的自主程度，从需要手动审批到完全自主运行。

　　批准调用前审查工具名称和输入。详细了解[信任和安全](../2.7.9-TrustAndSafety/)。
