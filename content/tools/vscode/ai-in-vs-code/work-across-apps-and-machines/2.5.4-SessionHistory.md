# 2.5.4 会话历史

　　保留智能体对话副本、查找较早工作或与协作者共享结果。导出或复制对话以创建独立记录，或使用会话历史跟踪和同步搜索工作。

　　VS Code 维护 Copilot 运行框架会话的可搜索历史。会话同步（实验性）可以将本地会话历史上传到 GitHub 账户，以便跨设备访问和共享。启用同步后，可以查询来自 VS Code、GitHub Copilot CLI、代码审查和 GitHub Copilot 应用的工作。

　　同步会话默认是私有的，除非你显式共享。要恢复任务而不是搜索历史，请参阅[查找并恢复会话](../../work-with-ai/sessions/2.2.11.1-ManageSessions/)。

## 导出或复制对话 {#export-or-copy-a-conversation}

　　导出和复制创建独立记录。这些操作独立于通过同步上传会话历史。

### 将会话导出为 JSON 文件 {#export-a-chat-session-as-a-json-file}

要保存对话中所有提示词和响应：

1. 在聊天视图中打开会话。
2. 从命令面板（`Ctrl + Shift + P`，macOS：`Cmd + Shift + P`）运行 **Chat: Export Chat...**。
3. 选择 JSON 文件保存位置。

### 将聊天消息复制为 Markdown {#copy-chat-messages-as-markdown}

　　在聊天视图中右键单击消息或聊天背景，选择：

* **复制**：复制单个提示词或响应，包括文本、思考步骤和工具调用。
* **全部复制**：复制整个对话，包括提示词、响应、思考步骤和工具调用。
* **复制最终响应**：只复制最后一次工具调用后的最终 Markdown 部分，不含中间步骤。

> **重要**：共享前审查导出文件和复制消息。它们可能包含敏感提示词、响应或工具输出。

## 启用或禁用会话同步（实验性） {#enable-or-disable-session-sync-experimental}

　　检查[会话同步状态](#session-sync-status)了解同步是否启用。使用 `chat.sessionSync.enabled` 设置偏好：

* 要同步会话历史，请将 `chat.sessionSync.enabled` 设置为 `true`。还必须使用 `github.copilot.chat.localIndex.enabled` 启用本地会话跟踪。
* 要关闭会话历史同步，请将 `chat.sessionSync.enabled` 设置为 `false`。可以保持本地会话跟踪启用。关闭同步不会删除已同步到 GitHub.com 的数据；请参阅[删除同步会话](#delete-synced-sessions)。

　　开启同步前请审查[跟踪内容](#what-gets-tracked)和[隐私控制](#privacy-and-data-control)。组织通过策略禁用同步时，你无法覆盖该限制。

> **注意**：会话历史同步独立于智能体会话期间发送给模型的提示词和上下文。关闭同步不会停止这些模型请求。

## 从同步中排除仓库 {#exclude-repositories-from-sync}

　　使用 `chat.sessionSync.excludeRepositories` 防止特定仓库中的会话同步到云。设置接受确切的 `owner/repo` 名称或 glob 模式：

```json
"chat.sessionSync.excludeRepositories": [
    "my-org/private-repo",
    "my-org/secret-*"
]
```

　　匹配仓库中的会话不会由会话同步上传。

## 企业策略 {#enterprise-policy}

　　对于 Copilot Business 和 Copilot Enterprise 用户，两个策略控制会话同步：

* **GitHub.com 企业策略**（“将本地会话存储在云中”）：企业和组织所有者可在 GitHub.com 上配置，为其用户启用或禁用云同步。
* **VS Code 组策略**（`CopilotSessionSync`）：禁用时，`chat.sessionSync.enabled` 设置被强制为 `false`，会话仅保留在本地。

> **重要**：启用策略不会让管理员访问你的会话数据。同步会话与个人账户绑定，默认只有你可以访问。

　　策略禁用时，会话同步状态显示 **已被策略禁用**，用户不能覆盖设置。

## 共享会话 {#share-a-session}

　　会话默认不共享。在 GitHub.com 上，可以将同步会话共享给有权访问仓库的人，提供只读访问：

1. 在 GitHub.com 打开 **智能体** 选项卡。
2. 选择会话，从 `...` 菜单打开 **共享设置**。
3. 启用共享，为仓库协作者提供只读访问。

　　接收者可以查看会话的提示词、响应和文件更改，但不能引导或修改会话。共享会话不会为其他用户的会话查询建立索引。

## 会话同步状态 {#session-sync-status}

　　会话同步状态显示在聊天视图的 Copilot 状态栏中，显示云同步当前状态：

| 状态 | 说明 |
|-------|-------------|
| **未启用** | 会话历史同步关闭。不会删除之前同步的数据。 |
| **已启用** | 会话正在同步到 GitHub 账户。 |
| **已同步 N 个会话** | 显示已上传会话数量。选择可在 GitHub.com 查看会话。 |
| **正在同步 N 个会话** | 上传进行中。 |
| **已被策略禁用** | 组织策略阻止会话同步。 |
| **同步错误** | 上次同步出现问题。请稍后重试。 |

## 隐私和数据控制 {#privacy-and-data-control}

* 会话默认只对你可见。同步会话与个人 GitHub 账户绑定，除非显式共享，否则只有你可以访问。
* 同步前，VS Code 通过匹配已知模式和机密值过滤检测到的机密。这可以遮蔽令牌、API 密钥和凭据，但可能无法检测每个机密。
* 可以随时将 `chat.sessionSync.enabled` 设置为 `false` 关闭同步。现有同步会话会保留在 GitHub.com，直到删除。

> **重要**：避免在提示词和工具输出中包含机密，共享前审查会话内容。不要依赖机密过滤移除每个敏感值。

## 删除同步会话 {#delete-synced-sessions}

　　要删除同步会话数据，请从命令面板运行 **Delete Session Sync Data** 命令（`github.copilot.sessionSync.deleteSessions`）。命令显示选择器，选择要移除的会话。选择后，选择删除范围：

* **从本地和云删除**：从机器和 GitHub.com 移除会话数据。此操作无法撤销。
* **仅从云删除**：从 GitHub.com 移除会话数据，但保留本地数据。

　　也可以在 GitHub.com 的 **智能体** 选项卡隐藏或删除单个同步会话。隐藏会话会从会话索引移除，不再出现在查询结果中。

> **注意**：**Delete Session Sync Data** 命令要求启用会话同步。如果同步关闭或被策略禁用，请在 GitHub.com 的 **智能体** 选项卡管理以前同步的会话。

## 使用 Chronicle 查询会话历史 {#query-session-history-with-chronicle}

　　使用 Chronicle 命令或自然语言问题搜索过去会话、生成站会报告并获取个性化使用建议。

### Chronicle 命令 {#chronicle-commands}

在聊天输入框中输入：

| 命令 | 说明 |
|---------|-------------|
| `/chronicle:standup` | 将最近编码会话总结为站会报告，按 branch 和仓库分组。默认覆盖最近 24 小时。 |
| `/chronicle:tips` | 分析最近会话历史，建议更有效地使用 Copilot。 |
| `/chronicle:cost-tips` | 识别减少令牌用量和 Copilot 成本的机会。 |
| `/chronicle:search <query>` | 按关键词、文件路径或拉取请求/议题引用搜索会话。 |
| `/chronicle:reindex` | 重建本地会话索引，并在启用会话同步时同步会话数据。 |

### 询问会话历史问题 {#ask-questions-about-session-history}

　　提出自由形式问题，例如“我昨天编辑了哪些文件？”或“我处理过与支付 API 相关的内容吗？”Copilot 使用语义理解查找相关会话。需要直接内容搜索时，请使用 `/chronicle:search`。

### 跟踪内容 {#what-gets-tracked}

本地会话存储记录：

* **会话元数据**：仓库、branch、工作目录、时间戳以及智能体或参与者。
* **对话轮次**：用户消息和助手响应。
* **涉及的文件**：工具调用中的文件路径。
* **外部引用**：拉取请求编号、议题编号和提交 SHA。

　　数据存储在本地 SQLite 数据库。同步前，VS Code 按[隐私和数据控制](#privacy-and-data-control)所述过滤检测到的机密。

### 重建会话存储索引 {#reindex-the-session-store}

如果会话缺失或数据库损坏，请重建索引：

```text
/chronicle:reindex
```

　　也可以从命令面板运行 **Reindex Sessions**（`github.copilot.chronicle.reindex`）。

　　从备份恢复会话文件、意外崩溃、手动删除会话目录或重新开启会话同步后，请重建索引。

## 设置参考 {#settings-reference}

| 设置 | 默认值 | 说明 |
|---------|---------|-------------|
| `github.copilot.chat.localIndex.enabled` | `true` | 启用本地会话跟踪（同步前提） |
| `chat.sessionSync.enabled` | `false` | 将会话同步到 GitHub 账户（实验性） |
| `chat.sessionSync.excludeRepositories` | `[]` | 从同步排除的仓库模式（实验性） |
