# 2.4.6 Copilot 连接器

　　使用 GitHub Copilot 连接器（也称为 GitHub 托管的 MCP 服务器），将 Slack、Notion 和 Microsoft Learn 等服务中的上下文带入智能体会话。无需安装本地服务器、编写 MCP 配置或管理凭据，即可连接受支持的服务。

　　连接一次后，可以在使用同一账户登录的受支持 Copilot 客户端中复用该连接。GitHub 管理连接和存储的授权。如果访问过期、被撤销或根据服务策略发生变化，可能需要重新授权。

　　如果需要使用的服务没有连接器，请使用发布者的 URL 或启动命令[添加 MCP 服务器](../2.4.7-AddMCPServers/)。手动配置的服务器需要你管理其配置、身份验证和更新。

## 开始之前 {#before-you-start}

* 使用 GitHub.com 账户登录 VS Code。所有 Copilot 套餐都可以使用连接器。
* 在 **会话目标** 下拉列表中选择 **Copilot**。连接器为 [Copilot 运行框架](../../choose-models-and-agents/2.3.2-ChooseAnAgentHarness/#copilot)提供工具，不适用于 Local 运行框架会话。

　　Marketplace 发现和连接器默认通过 `chat.customizations.marketplace.enabled` 和 `chat.customizations.copilotConnectors.enabled` 启用。

　　对于 Business 和 Enterprise 套餐，管理员必须开启 **编辑器预览功能** 策略。该策略关闭时，两个设置都会被强制关闭。某些服务还需要服务管理员批准，例如允许 Slack MCP 访问。组织的 MCP 访问限制也适用。请参阅[连接器管理指南](https://docs.github.com/en/enterprise-cloud@latest/copilot/how-tos/administer-copilot/manage-mcp-usage/configure-enterprise-allowlist#allowing-copilot-connectors)。

## 连接服务 {#connect-a-service}

　　连接器是[自定义 Marketplace](../2.4.1-Overview/#discover-and-install-existing-customizations-preview)中的一种来源。与安装技能或插件不同，连接服务是授权访问其工具，而不是安装自定义文件。

1. 从命令面板（`Ctrl + Shift + P`，macOS：`Cmd + Shift + P`）运行 **Chat: Open Customizations**，然后选择 **浏览**。
2. 在来源菜单中选择 **Copilot 连接器**，或按名称搜索服务。
3. 打开连接器详情，选择 **连接**。
4. 审查请求的权限，并在浏览器中完成授权，包括需要时的服务登录。
5. 等待状态显示 **已连接**。

　　授权待处理时，可以选择 **取消** 停止连接。可以再次选择 **连接** 重试。

## 使用已连接的服务 {#use-a-connected-service}

　　返回 Copilot 会话，提出需要该服务信息的问题。当请求相关时，Copilot 会使用已连接服务的工具。

例如，连接 **Microsoft Learn Docs** 后，输入：

```text
使用 Microsoft Learn Docs 连接器查找 Kusto 查询语言 where 运算符的官方文档。
总结其语法并链接到文档。
```

　　接受工具审批请求之前请先审查。展开对话中的工具调用，检查智能体是否使用了已连接服务并收到结果。仅凭看似合理的回答不能确认使用了连接器。

　　对于示例，请检查结果是否链接到 Microsoft Learn 并描述 Kusto 的 `where` 运算符，而不是其他语言中同名运算符。答案应反映返回的文档。

　　使用同一账户启动新的 Copilot 会话，在不重新连接的情况下重复请求。确认工具调用及其有用结果。这可以检查保存的连接在授权会话之外仍然有效。

## 断开服务 {#disconnect-a-service}

　　已连接的服务会出现在 **MCP 服务器** 中，并带有 **连接器：<名称>** 标签。其连接由 GitHub 管理，而不是本地 MCP 配置文件。

1. 在选中 **Copilot** 运行框架的情况下，运行 **Chat: Open Customizations**，选择 **MCP 服务器**。
2. 找到连接器所在行，打开其省略号（**...**）菜单。
3. 选择 **断开连接**，等待操作完成。

　　**断开连接** 会移除登录账户的 GitHub 托管连接，而不仅是工作区配置。使用该账户登录的受支持客户端会共享连接状态。

　　连接器行会消失，其工具不再可用于 Copilot 会话。要移除连接器，请使用 **断开连接**，不要使用 **卸载** 或编辑配置文件。

　　要再次使用该服务，请[从智能体自定义编辑器连接](#connect-a-service)。

## 排查连接问题 {#troubleshoot-a-connection}

| 观察到的现象 | 下一步 |
|------------------|--------|
| **浏览** 中不显示连接器 | 检查是否选择了 **Copilot** 运行框架、两个发现设置是否开启，以及账户和管理员策略是否允许访问。 |
| 状态一直停留在 **正在连接** | 选择 **取消**，然后选择 **连接** 并在浏览器中完成授权。 |
| 服务登录失败或访问被拒绝 | 审查请求的权限，并检查服务管理员是否需要先批准 MCP 访问，然后重试。 |
| 连接器已连接，但没有调用工具 | 检查会话是否使用 **Copilot** 运行框架，在提示词中明确指定服务，并检查工具调用。请参阅[工具可用性和调用](../../reference-and-help/troubleshooting/2.8.2.2-DebugChatInteractions/#an-mcp-tool-is-not-being-invoked)。 |
