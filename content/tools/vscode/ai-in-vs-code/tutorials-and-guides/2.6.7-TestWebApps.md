# 2.6.7 测试 Web 应用

　　浏览器工具为 Web 应用提供智能体闭环开发流程。智能体可以创建应用、在集成浏览器中打开、按照验收标准交互、识别问题、修复并重复检查。

　　本指南通过构建和验证计算器应用带你完成该循环。浏览器工具能力、会话类型、隐私控制和提示词模式请参阅[在智能体中使用浏览器工具](../../work-with-ai/plan-and-run-tasks/2.2.10.3-BrowserTools/)。

## 前提条件 {#prerequisites}

完成本指南需要：

* 在计算机上[安装 VS Code](https://code.visualstudio.com/download)
* [GitHub Copilot 订阅](../../getting-started/2.1.2-SetUpCopilot/)
* `workbench.browser.enableChatTools` 设置已开启，这是默认值

## 智能体验证什么 {#what-the-agent-validates}

　　要求智能体测试计算器之前，请定义可观察的验收标准：

* 每个数字按钮输入正确的值。
* 加法、减法、乘法和除法返回预期结果。
* **清除** 重置计算器。
* 除以零显示错误，而不是无效数字结果。

　　这些标准为智能体提供明确的成功定义，并使其最终验证报告更易于审查。

## 第 1 步：验证浏览器工具 {#step-1-verify-browser-tools}

　　浏览器工具默认普遍可用。验证它们已为请求选中：

1. 打开聊天视图（`Ctrl + Alt + I`），从智能体下拉列表选择 **智能体**。
2. 在聊天视图标题栏中选择 **打开自定义项** > **工具**，确认 **集成浏览器** 已选中。

　　智能体现在可以使用这些工具与网页交互。如果工具缺失，请确认 `workbench.browser.enableChatTools` 已开启。组织策略也可能关闭浏览器工具。

## 第 2 步：要求智能体构建计算器 {#step-2-ask-the-agent-to-build-a-calculator}

　　启用浏览器工具后，要求智能体创建简单的计算器应用。

1. 创建新项目文件夹，并在 VS Code 中打开。
2. 在聊天视图中输入以下提示词：

    ```text
    Create a calculator with buttons for digits 0-9, operations (add, subtract, multiply, divide), clear, and equals. Use HTML, CSS, and JavaScript. Style it with a clean, modern design.
    ```

3. 智能体创建 `index.html`、`styles.css` 和 `script.js` 时，审查生成的文件。
4. [审查已保存的更改](../../work-with-ai/2.2.8-ReviewAndRevertChanges/)。如果有待审查编辑，选择 **保留** 保留或 **撤销** 还原。**保留** 会清除待审查状态；文件已经保存到工作区。

　　智能体已构建计算器应用的基本结构。

## 第 3 步：让智能体测试计算器 {#step-3-let-the-agent-test-the-calculator}

　　现在要求智能体在集成浏览器中打开计算器并验证其正常工作。

1. 在聊天视图中输入以下提示词：

    ```text
    Open the calculator in the browser and validate it against these criteria:
    each digit button enters the correct value; addition, subtraction,
    multiplication, and division return the expected result; Clear resets
    the calculator; and division by zero shows an error. Report the result
    for each criterion. If any criterion fails, fix the issue and repeat
    the complete validation.
    ```

2. 观察智能体在集成浏览器中打开 `index.html`，解析页面内容以理解结构，并通过模拟点击和检查结果系统地测试每个按钮和操作。

    <video src="https://code.visualstudio.com/assets/docs/agents/browser-agent-testing-guide/agent-testing-calculator.mp4" title="视频展示智能体在集成浏览器中测试计算器。" autoplay loop controls muted></video>

　　智能体会报告哪些操作正常工作，并指出发现的问题。

## 第 4 步：观察智能体调试和修复问题 {#step-4-watch-the-agent-debug-and-fix-issues}

　　如果智能体在测试中发现错误，它会自动分析问题并实施修复。

1. 通过移除除以零检查引入一个错误：

    ```javascript
    function calculate() {
        if (!operator || shouldReset) return;

        const a = parseFloat(previous);
        const b = parseFloat(current);
        let result;

        switch (operator) {
        case '+': result = a + b; break;
        case '-': result = a - b; break;
        case '*': result = a * b; break;
        case '/': result = a / b; break;
    }
    ```

2. 要求智能体重现问题、修复并再次验证验收标准：

    ```text
    Test division by zero. If it produces an invalid numeric result instead
    of an error, fix the issue. Then repeat the test and report the result.
    ```

3. 观察智能体在除以零时遇到错误，分析并修复代码，最后验证错误修复。

　　智能体使用浏览器工具完成了完整开发周期：构建、验证、调试、修复和重新验证。

## 第 5 步：与智能体共享浏览器页面（可选） {#step-5-share-a-browser-page-with-the-agent-optional}

　　也可以手动打开网页，并显式与智能体共享以进行分析或交互。默认情况下，智能体只能与它自己打开的网页交互。

1. 从命令面板（`Ctrl + Shift + P`）运行 **Browser: Open Integrated Browser**，打开集成浏览器。
2. 导航到希望智能体分析或交互的网页。
3. 选择浏览器工具栏中的 **与智能体共享** 按钮。浏览器选项卡上的视觉指示器显示页面正与智能体共享。
4. 要求智能体在共享页面上执行操作：

    ```text
    What is the main heading on this page? Click the first link and tell me where it goes.
    ```

　　智能体现在可以访问共享页面并代表你执行交互。完成后，再次选择 **与智能体共享** 按钮撤销访问。

> **提示**：共享页面使用现有浏览器会话，包括 cookie 和登录状态。智能体打开的页面使用隔离的临时会话，因此不会与其他浏览器选项卡共享 cookie 或存储。

## 尝试这些场景 {#try-these-scenarios}

　　了解浏览器工具工作方式后，可以尝试以下场景：

* **表单验证测试**：让智能体通过构建和测试联系表单，验证验证规则、错误消息和成功提交。
* **响应式布局验证**：要求智能体在不同视口尺寸下截取页面，验证响应式行为（例如带导航菜单的着陆页）。
* **身份验证流程测试**：让智能体测试登录页中的凭据验证、错误处理和成功重定向。
* **交互功能测试**：让智能体验证用户交互和状态管理。
* **辅助功能审计**：要求智能体检查网页中缺失的 alt 文本、标题层级、键盘导航和颜色对比度问题。
