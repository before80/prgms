# 2.6.15 提示词示例

　　本文提供 VS Code 中聊天在不同场景和智能体下的示例提示词。可以将这些示例作为灵感，为自己的开发任务编写有效提示词。

　　如果刚接触 VS Code 聊天，请先了解[聊天入门](../../work-with-ai/2.2.5-UseChat/)，或查看[提示词编写最佳实践](../../getting-started/2.1.6-BestPractices/)。

## 通用编码和技术问题 {#general-coding-and-technology-questions}

使用 **Ask** 智能体快速获取编码概念、技术主题和一般编程问题的答案。

```prompt
What is a linked list?
```

```prompt
Provide 3 ways to implement a search feature in React.
```

```prompt
Explain the difference between async/await and promises.
```

## 理解和探索代码库 {#understanding-and-exploring-your-codebase}

使用 **Ask** 智能体和 `#codebase` 理解项目工作方式、定位特定功能或探索代码关系。

　　需要带源引用和验证步骤的引导式调查，请参阅[使用智能体探索代码库](../2.6.2-ExploreACodebase/)。

```prompt
Explain how authentication works in #codebase
```

```prompt
Where is the database connection string configured? #codebase
```

```prompt
How do I build this #codebase?
```

```prompt
Which testing framework is used for #calculator.test.js?
```

## 代码生成和编辑 {#code-generation-and-editing}

使用 **Agent** 进行多文件创建，使用**内联聊天**（`Ctrl + I`）进行有针对性的就地编辑。

　　现有项目中的完整工作流请参阅[添加功能](../2.6.3-AddAFeature/)和[不改变行为地重构](../2.6.5-RefactorSafely/)。

```prompt
Add a login button and style it based on #styles.css
```

```prompt
Create a meal-planning web app using React and Node.js
```

```prompt
Refactor this code to use async/await
```

## 测试和质量保证 {#testing-and-quality-assurance}

使用 **Agent** 生成测试或修复失败测试。

```prompt
Add unit tests for the user service.
```

```prompt
Fix the failing tests #testFailure
```

## 调试和修复问题 {#debugging-and-fixing-issues}

使用 **Agent** 跨文件修复问题，或先使用 **Ask** 理解根本原因。

```prompt
Fix the issues in #problems
```

```prompt
Why is this function returning undefined?
```

## 使用源代码管理 {#working-with-source-control}

使用聊天处理待处理更改并生成发布文档。

```prompt
Summarize the #changes
```

```prompt
Generate release notes based on the #changes
```

## 使用外部资源 {#working-with-external-resources}

使用 `#fetch` 引用 Web 内容，或使用 GitHub MCP 服务器搜索公共 GitHub 仓库中的代码示例。

```prompt
How do I use the 'useState' hook in react 18? #fetch https://18.react.dev/reference/react/useState#usage
```

```prompt
Build an API endpoint to fetch address info, use the template from GitHub repo contoso/api-templates
```

```prompt
What are the top #extensions for this workspace?
```

使用[终端内联聊天](../../work-with-ai/2.2.4-InlineChatAndQuickChat/)获取 shell 命令和终端操作帮助。

```prompt
How do I install npm packages?
```

```prompt

```


## 使用 Jupyter 笔记本 {#working-with-jupyter-notebooks}

使用 **Agent** 创建、编辑和处理 Jupyter 笔记本。

```prompt

```

```prompt
Create a notebook to read data from #housing.csv and plot the distribution of prices
```

```prompt
Make sure the data is cleaned before visualizing and processing it
```


## 多轮对话示例 {#multi-turn-conversation-examples}

聊天支持同一会话中的后续提示词。使用多轮对话迭代结果并完善 AI 输出。

**第一条提示词：**

```prompt
Create a REST API with Express.js that has endpoints for users and products
```

**后续提示词：**

```prompt
Add input validation and error handling to both endpoints
```

```prompt
Now add unit tests for the validation logic
```

　　基于早期响应继续时，AI 会保留之前步骤的上下文，生成更连贯的代码。

## 编写有效提示词的技巧 {#tips-for-crafting-effective-prompts}

* **具体**：包含要完成的目标、使用的技术和预期输出格式。
* **添加上下文**：使用 # 提及引用文件、符号或 `#codebase`、`#changes`、`#problems` 等上下文变量。
* **迭代**：从简单提示词开始，根据响应完善，并通过追问改进结果。
* **分解复杂任务**：不要一次要求所有内容，将大型任务拆分为更小、可管理的步骤。

　　详细了解[编写提示词最佳实践](../../getting-started/2.1.6-BestPractices/)和[为提示词添加上下文](../../work-with-ai/2.2.7-AddPromptContext/)。
