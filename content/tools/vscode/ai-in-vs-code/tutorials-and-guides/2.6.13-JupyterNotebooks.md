# 2.6.13 Jupyter 笔记本

　　在整个笔记本工作流中使用 AI。智能体可以创建 Jupyter 笔记本、编辑和运行单元格、检查输出并针对错误迭代。对于聚焦更改，请在笔记本单元格中直接使用内联聊天。

　　本指南介绍如何在 Jupyter 笔记本中使用 AI 进行数据分析，同时审查生成的代码并控制其运行时机。

## 前提条件 {#prerequisites}

* 在 VS Code 中[设置 GitHub Copilot](../../getting-started/2.1.2-SetUpCopilot/)。
* 安装 [Jupyter 扩展](https://marketplace.visualstudio.com/items?itemName=ms-toolsai.jupyter)。要了解如何配置 Python 环境并选择内核，请参阅 [VS Code 中的 Jupyter 笔记本](https://code.visualstudio.com/docs/datascience/jupyter-notebooks)。
* 打开[信任的工作区](../../../editor/3.2-WriteCode/3.2.8-Workspaces/3.2.8.3-WorkspaceTrust/)。运行笔记本单元格会在所选内核中执行代码，并可能访问工作区文件。

## 使用智能体创建笔记本 {#create-a-notebook-with-an-agent}

　　从想要的结果开始，而不是指定各个单元格。智能体会规划笔记本、创建 Markdown 和代码单元格，并可以运行代码验证结果。

1. 打开[聊天视图](../../work-with-ai/2.2.2-ChatView/)（`Ctrl + Alt + I`，macOS：`Ctrl + Cmd + I`），启动 **Local** 智能体会话。
2. 将数据文件添加为上下文，然后描述所需分析和输出。

    ```text
    Create a Jupyter notebook that uses pandas and seaborn to analyze #housing.csv. Clean the data, summarize key metrics, and visualize the price distribution.
    ```

3. 继续之前，审查任何请求的工具和命令审批。如果笔记本没有内核，请按照提示选择或创建 Python 环境。

　　智能体会创建 `.ipynb` 文件，你可以继续在同一会话中完善。也可以使用 `/newNotebook` 开头，显式请求新的 Jupyter 笔记本。

## 通过编辑和运行单元格迭代 {#iterate-by-editing-and-running-cells}

　　智能体具有笔记本专用工具，用于理解单元格结构、编辑单元格、运行代码和读取单元格输出。此编辑-运行循环让智能体可以验证分析并响应运行时错误，而不仅是生成静态笔记本。

要求智能体从当前笔记本继续：

```text
从上到下运行笔记本。修复发现的任何错误，然后解释主要结果。
```

也可以请求特定修订：

```text
添加一个部分来识别离群值，解释它们如何影响分析，并比较移除前后结果。
```

　　智能体工作时保持笔记本编辑器打开，以审查单元格更改和输出。配置智能体权限，控制哪些工具和命令调用需要审批。详细了解[智能体审批](../../work-with-ai/permissions-and-security/2.2.12.1-ApprovalsAndPermissions/)。

## 向提示词添加笔记本上下文 {#add-notebook-context-to-a-prompt}

　　当请求依赖当前内核状态或单元格结果时，向智能体提供笔记本特定上下文。

### 添加内核变量 {#add-a-kernel-variable}

　　笔记本处于活动状态时，在聊天输入框中输入 `#`，从建议中选择内核变量。所选变量会作为请求上下文可用。

例如，添加 `df` 变量并输入：

```text
检查此 DataFrame 的缺失值并建议清理策略。
```

### 添加单元格输出 {#add-a-cell-output}

　　在单元格输出工具栏中选择 **将单元格输出添加到聊天**，附加受支持的输出。然后可以要求智能体解释图表、诊断错误或根据结果更新笔记本。

```text
解释此图表中的离群值，并更新分析以调查它们。
```

## 使用内联聊天进行聚焦单元格更改 {#make-focused-cell-changes-with-inline-chat}

　　当希望更改一个单元格而不启动更广泛的智能体工作流时，请使用内联聊天。

1. 将光标放在单元格中，或选择要更改的代码。
2. 按 `Ctrl + I`（macOS：`Cmd + I`） 并描述更改。
3. 审查建议差异。选择 **接受并运行** 应用更改并一步执行单元格。

　　要生成新单元格，请在单元格之间选择 **生成**，或在单元格编辑器未聚焦时按 `Ctrl + I`（macOS：`Cmd + I`）。**生成** 操作是实验性的，由 `notebook.experimental.generate` 设置控制。

## 跟随单元格执行（实验性） {#follow-cell-execution-experimental}

　　要让智能体正在运行的单元格保持在视野中，请启用 `github.copilot.chat.notebook.followCellExecution.enabled` 设置。智能体开始运行单元格后，使用笔记本工具栏中的固定操作暂停或恢复跟随当前执行。
