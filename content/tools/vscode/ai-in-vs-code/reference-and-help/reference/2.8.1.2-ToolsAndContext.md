# 2.8.1.2 工具和上下文参考

　　查阅 VS Code 聊天提示词中的常用工具名称和上下文引用。关于选择工具、调用工具和管理审批的说明，请参阅[在智能体中使用工具](../../../work-with-ai/plan-and-run-tasks/2.2.10.2-UseTools/)。

## 引用类型和可用性 {#reference-types-and-availability}

　　`#` 选择器包含用途不同的引用：

* **工具**执行操作，例如读取文件或运行命令。例如，`#search/textSearch` 搜索文件内容。
* **上下文项**为提示词提供信息，而不要求智能体执行操作。例如，`#selection` 添加编辑器选中文本。

　　可用引用取决于运行框架、已启用扩展和会话能力。在聊天输入框中输入 `#` 查看当前列表。扩展和 MCP 服务器可以提供此处未列出的额外工具。

　　用户定义工具集已弃用，Copilot 运行框架不支持。要替换现有工具集文件，请遵循[替换工具集](../../../customize-and-extend/2.4.11-MigrateExistingCustomizations/#replace-tool-sets)。这不会移除 **工具** 选项卡中的工具组或支持的内置别名。

　　引用工具不会绕过其[审批和权限控制](../../../work-with-ai/permissions-and-security/2.2.12.1-ApprovalsAndPermissions/)。

## 工具 {#tools}

　　以下表格使用 Local 运行框架工具引用名称。不要假设这些标识符直接映射到 Copilot 运行框架工具。在 Copilot 会话中，请使用 **工具** 选项卡[查看可用工具](../../../work-with-ai/plan-and-run-tasks/2.2.10.2-UseTools/#manage-available-tools)。

### 读取和搜索工作区文件 {#read-and-search-workspace-files}

| 引用 | 用途 |
|---|---|
| `#read/readFile` | 读取文件。 |
| `#read/problems` | 从 **问题** 面板获取诊断。 |
| `#search/changes` | 列出源代码管理更改。 |
| `#search/codebase` | 使用工作区代码搜索查找相关代码。 |
| `#search/fileSearch` | 按 glob 模式查找文件。 |
| `#search/listDirectory` | 列出目录内容。 |
| `#search/textSearch` | 在文件中查找文本。 |
| `#search/usages` | 查找符号的引用、实现和定义。 |

## 上下文项 {#context-items}

　　输入 `#` 后跟文件、文件夹或符号名，然后从选择器中选择项目。以下占位符表示要附加的项目名称。

| 引用 | 提供的上下文 |
|---|---|
| `#<file>` | 从上下文选择器中选择的文件。 |
| `#<folder>` | 从上下文选择器中选择的文件夹。 |
| `#<symbol>` | 代码符号。请先打开包含该符号的文件。 |
| `#selection` | 当前编辑器选区，在选择文本时可用。 |

　　使用 **添加上下文** 或将项目拖入聊天，以附加其他上下文，例如图像、错误或 GitHub 议题。支持的来源和附件方法请参阅[向聊天添加上下文](../../../work-with-ai/2.2.7-AddPromptContext/)。
