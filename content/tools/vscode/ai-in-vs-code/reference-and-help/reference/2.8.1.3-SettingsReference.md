# 2.8.1.3 AI 设置参考

　　本文列出 VS Code 中 AI 功能和智能体的配置设置。关于 VS Code 设置的通用信息，请参阅[用户和工作区设置](../../../../editor/3.3-ConfigureTheEditor/3.3.4-Settings/)。

　　AI 功能持续发展，部分功能仍处于实验阶段。请在 [GitHub 议题](https://github.com/microsoft/vscode/issues)中试用并反馈。功能生命周期请参阅[功能生命周期](../../../../editor/3.3-ConfigureTheEditor/3.3.4-Settings/)。

> **提示**：如果还没有 Copilot 订阅，可以注册 [Copilot Free](https://github.com/github-copilot/signup)，免费获得每月内联建议和 AI 点数额度。

> **注意**：当 [GitHub Copilot 企业托管设置生效](../../../../enterprise/7.2-ManageAISettings/#claude-and-codex-availability)时，包括托管权限或沙盒设置，Claude 和 Codex 运行框架会被禁用。启用其用户设置不能覆盖该限制。请联系部署设置的 IT 团队。

## 常规设置 {#general-settings}

* `chat.commandCenter.enabled`：在标题栏显示聊天菜单。默认 `true`。
* `workbench.settings.showAISearchToggle`：在设置编辑器中启用 AI 搜索。默认 `true`。
* `workbench.commandPalette.experimental.askChatLocation`：命令面板聊天问题的显示位置。默认 `"chatView"`。
* `search.searchView.semanticSearchBehavior`：搜索视图何时运行语义搜索：手动、无文本结果时或始终。默认 `"manual"`。
* `search.searchView.keywordSuggestions`：在搜索视图中显示关键词建议。默认 `false`。
* `chat.disableAIFeatures`：禁用并隐藏聊天、内联建议等内置 AI 功能，并禁用 Copilot 扩展。默认 `false`。

## 代码编辑设置 {#code-editing-settings}

* `github.copilot.editor.enableCodeActions`：启用 Copilot 代码操作。默认 `true`。
* `github.copilot.renameSuggestions.triggerAutomatically`：自动触发重命名建议。默认 `true`。
* `github.copilot.enable`：按语言启用或禁用内联建议。默认启用。
* `github.copilot.nextEditSuggestions.enabled`：启用下一次编辑建议。默认 `true`。
* `editor.inlineSuggest.edits.allowCodeShifting`：允许编辑建议移动代码。默认 `true`。
* `editor.inlineSuggest.edits.renderSideBySide`：并排显示较大编辑建议：`auto`、`never`。默认 `"auto"`。
* `github.copilot.nextEditSuggestions.fixes`：基于诊断启用修复建议。默认 `true`。
* `editor.inlineSuggest.edits.showCollapsed`：在导航到编辑建议前保持折叠。默认 `false`。
* `editor.inlineSuggest.fontFamily`：内联建议字体。默认继承编辑器。
* `editor.inlineSuggest.showToolbar`：显示内联建议工具栏。默认 `true`。
* `editor.inlineSuggest.minShowDelay`：显示内联建议前的最短等待毫秒数。默认 `0`。

## 聊天设置 {#chat-settings}

### 聊天体验 {#chat-experience}

* `github.copilot.chat.localeOverride`：覆盖聊天响应语言区域。
* `github.copilot.chat.useProjectTemplates`：使用项目模板回答新项目问题。默认 `true`。
* `github.copilot.chat.terminalChatLocation`：终端聊天打开位置。默认 `"chatView"`。
* `chat.detectParticipant.enabled`：启用聊天参与者检测。默认 `true`。
* `chat.stickyScroll.enabled`：在聊天记录顶部固定当前提示词。默认 `true`。
* `chat.editor.fontFamily`、`chat.editor.fontSize`、`chat.editor.fontWeight`、`chat.editor.lineHeight`：聊天代码块字体和布局。
* `chat.editor.wordWrap`：聊天代码块自动换行。默认 `"off"`。
* `chat.fontFamily`、`chat.fontSize`：聊天 Markdown 字体和字号。
* `chat.verbose`：显示请求和完成时间戳。默认 `false`。
* `chat.persistentProgress`：持续进度指示器：关闭、Draw 或单色 Draw。默认 `"draw"`。
* `chat.persistentProgressVerbosity`：进度详细程度：紧凑、详细或对话。默认 `"compact"`。
* `chat.notifyWindowOnConfirmation`：智能体需要确认时通知：关闭、窗口未聚焦或始终。默认 `"windowNotFocused"`。
* `chat.notifyWindowOnResponseReceived`：收到响应时通知。默认 `"windowNotFocused"`。
* `chat.requestQueuing.defaultAction`：发送按钮默认操作：`steer` 或 `queue`。默认 `"steer"`。
* `chat.math.enabled`：在聊天中渲染数学公式。默认 `true`。
* `imageCarousel.chat.enabled`：在聊天中启用图像轮播。默认 `true`。

### 聊天编辑和工件 {#chat-editing-and-artifacts}

* `chat.editor.workingSet.enabled`：显示 Copilot 工作集。默认 `true`。
* `chat.artifacts.enabled`：启用工件面板。默认 `true`。
* `chat.artifacts.rules.byMimeType`：按 MIME 类型提取工件。默认图像显示在“截图”组。
* `chat.artifacts.rules.byFilePath`：按文件 glob 提取工件。默认计划文档。
* `chat.artifacts.rules.byMemoryFilePath`：按记忆文件 glob 提取工件。默认计划文档。
* `chat.checkpoints.enabled`：启用会话检查点。默认 `true`。
* `chat.checkpoints.showFileChanges`：每次请求后显示文件更改摘要。默认 `false`。
* `chat.editRequests`：允许编辑之前的聊天请求。默认 `true`。
* `chat.editing.confirmEditRequestRemoval`：移除编辑请求前确认。默认 `true`。
* `chat.editing.confirmEditRequestRetry`：重试编辑请求前确认。默认 `true`。
* `chat.editing.autoAcceptDelay`：Local 会话自动保留编辑的延迟秒数。默认 `0`。
* `chat.editing.revealNextChangeOnResolve`：解决编辑后显示下一个更改。默认 `true`。

### 聊天模型和上下文 {#chat-models-and-context}

* `github.copilot.chat.scopeSelection`：将聊天范围限定到编辑器选择。默认 `false`。
* `github.copilot.chat.codesearch.enabled`：启用代码搜索工具。默认 `true`。
* `chat.copilot.imageGeneration.model`：图像生成模型，或“关闭”。默认 `"gpt-image-1"`。
* `chat.copilot.imageGeneration.watermark`：为生成图像添加“Made with AI”标签。默认 `false`。
* `chat.sendElementsToChat.enabled`：允许将浏览器元素添加到聊天。默认 `true`。
* `chat.sendElementsToChat.attachCSS`：附加元素时包含 CSS。默认 `true`。
* `chat.sendElementsToChat.attachImages`：附加元素时包含截图。默认 `true`。
* `workbench.browser.enableChatTools`：启用浏览器工具。默认 `true`。
* `chat.useClaudeMdFile`：Local 使用 `CLAUDE.md` 指令。默认 `true`。
* `chat.useNestedAgentsMdFiles`：Local 发现嵌套 `AGENTS.md`。默认 `false`。
* `github.copilot.chat.customOAIModels`：已弃用，改用自定义终结点。
* `chat.utilityModel`：一般实用任务模型。默认 `"default"`。
* `chat.utilitySmallModel`：快速实用任务模型。默认 `"default"`。
* `chat.byokUtilityModelDefault`：BYOK 主模型时的实用模型默认值：`none`、`mainAgent` 或 `copilot`。

## 智能体设置 {#agent-settings}

### 智能体行为 {#agent-behavior}

* `chat.agent.enabled`：启用智能体模式。默认 `true`。
* `chat.agent.maxRequests`：每个请求最大工具调用次数。默认 `25`。
* `github.copilot.chat.agent.autoFix`：自动修复失败的编辑。默认 `true`。
* `chat.subagents.allowInvocationsFromSubagents`：允许子智能体继续委派。默认 `false`。
* `chat.subagents.defaultToAuto`：未指定模型时子智能体使用 Auto。默认 `false`。
* `chat.subagents.useRichRendering`：在独立编辑器中显示子智能体。默认 `true`。
* `github.copilot.chat.searchSubagent.subagentSemanticSearchEnabled`：启用子智能体语义搜索。默认 `true`。
* `chat.agent.thinking.collapsedTools`：工具调用分组：`off`、`withThinking`、`always`。默认 `"withThinking"`。
* `chat.agent.thinkingStyle`：思考显示样式：`fixedScrolling`、`collapsed`、`collapsedPreview`。默认 `"fixedScrolling"`。

### MCP 设置 {#mcp-settings}

* `chat.mcp.access`：MCP 服务器访问策略。
* `chat.mcp.discovery.enabled`：从其他应用发现 MCP 配置。默认仅启用 Copilot CLI。
* `chat.mcp.serverSampling`：向 MCP 服务器公开用于采样的模型。
* `chat.mcp.apps.enabled`：启用 MCP 应用。默认 `true`。
* `chat.mcp.autostart`：提交聊天时自动启动服务器：`never`、`onlyNew`、`newAndOutdated`。默认 `"newAndOutdated"`。

### 智能体工具 {#agent-tools}

* `chat.tools.compressOutput.enabled`：压缩大型工具输出。默认 `true`。
* `chat.tools.terminal.autoReplyToPrompts`：自动回复终端提示。默认 `true`。
* `chat.tools.terminal.terminalProfile.windows`、`.osx`、`.linux`：覆盖智能体终端 shell。
* `chat.tools.terminal.outputLocation`：终端输出位置：聊天或终端。默认 `"chat"`。
* `chat.tools.terminal.outputReflow`：聊天中重排终端输出。默认 `true`。
* `chat.tools.terminal.enforceTimeoutFromModel`：强制执行模型指定的超时。默认 `true`。

### 审批和权限 {#approvals-and-permissions}

* `chat.tools.riskAssessment.enabled`：启用辅助审批 LLM 风险评估。默认 `false`。
* `chat.tools.terminal.autoApprove`：终端命令自动批准规则。
* `chat.tools.terminal.enableAutoApprove`：启用终端自动批准。默认 `true`。
* `chat.tools.edits.autoApprove`：文件编辑自动批准规则。
* `chat.tools.terminal.ignoreDefaultAutoApproveRules`：忽略内置终端规则。默认 `false`。
* `chat.tools.global.autoApprove`：全局自动批准所有工具。默认 `false`。
* `chat.permissions.default`：新会话默认权限级别：`default`、`autoApprove`、`autopilot`。默认 `"default"`。
* `chat.autopilot.advanced.enabled`：启用高级 Autopilot。默认 `false`。
* `chat.tools.urls.autoApprove`：URL 自动批准规则。
* `chat.tools.eligibleForAutoApproval`：哪些工具可自动批准。
* `chat.tools.terminal.blockDetectedFileWrites`：阻止检测到的文件写入：`never`、`outsideWorkspace`、`always`。默认 `"outsideWorkspace"`。
* `github.copilot.chat.additionalReadAccessFolders`：额外只读文件夹。
* `github.copilot.chat.claudeAgent.allowDangerouslySkipPermissions`：绕过 Claude 权限检查。默认 `false`。

### 沙盒和网络访问 {#sandboxing-and-network-access}

* `chat.agent.sandbox.enabled`：启用智能体沙盒。默认 `"off"`。
* `chat.agent.sandbox.network.allowNetwork`：允许出站网络。默认 `true`。
* `chat.agent.sandbox.network.allowLocalNetwork`：允许本地网络。默认 `false`。
* `chat.agent.sandbox.allowUnsandboxedCommands`：允许在沙盒外运行。默认 `true`。
* `chat.agent.sandbox.fileSystem.userConfiguredPaths`：读写、只读和拒绝路径。
* `chat.agent.sandbox.fileSystem.allowDevToolAccess`：授予开发工具、配置和缓存访问。默认 `true`。
* `chat.agent.sandbox.mcpServers`：在沙盒中运行托管 MCP 服务器。默认 `true`。
* `chat.agent.sandbox.lspServers`：在沙盒中运行语言服务器。默认 `true`。
* `chat.agent.sandbox.credentials.authenticategit`：为沙盒提供 Git 身份验证。默认 `true`。
* `chat.agent.sandbox.credentials.authenticategh`：为沙盒提供 GitHub CLI 身份验证。默认 `true`。
* `chat.agent.networkFilter`：为浏览器工具启用网络域筛选。默认 `false`。
* `chat.agent.allowedNetworkDomains`：允许的域。
* `chat.agent.deniedNetworkDomains`：拒绝的域。
* `chat.agent.sandbox.retryWithAllowNetworkRequests`：Local 沙盒网络重试。已弃用。
* `chat.agent.sandbox.fileSystem.linux`、`.mac`：已弃用的平台路径设置。
* `chat.agent.sandbox.allowNetwork`：已弃用，改用 `network.allowNetwork`。

### 计划、模型和智能体提供程序 {#planning-models-and-agent-providers}

* `chat.planWidget.inlineEditor.enabled`：以行内编辑器打开计划。默认 `true`。
* `chat.planAgent.defaultModel`：Plan 智能体模型。默认 `"default"`。
* `github.copilot.chat.implementAgent.model`：Local 实现智能体模型。默认 `"default"`。
* `github.copilot.chat.planAgent.additionalTools`：Plan 智能体额外工具。默认 `[]`。
* `github.copilot.chat.claudeAgent.enabled`：启用 Claude 运行框架。
* `github.copilot.chat.summarizeAgentConversationHistory.enabled`：自动总结长对话。默认 `true`。
* `github.copilot.chat.virtualTools.threshold`：启用虚拟工具的工具数量阈值。默认 `128`。
