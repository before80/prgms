# 2.8.1.1 AI 功能速查表

　　查找适合任务的 VS Code AI 功能，从聚焦编辑到委派给智能体的工作。本参考列出常见任务、有用控件和快捷键。

　　不熟悉智能体？请先[使用智能体完成第一个任务](../../../getting-started/2.1.3-AgentsQuickstart/)。可用功能取决于[智能体运行框架](../../../choose-models-and-agents/2.3.2-ChooseAnAgentHarness/)、模型、账户和组织策略。

## 选择功能 {#choose-a-feature}

| 我想要… | 使用 | 开始方式 |
|---|---|---|
| 在不更改代码的情况下理解不熟悉的代码 | [Ask](../../../choose-models-and-agents/2.3.2-ChooseAnAgentHarness/#choose-a-built-in-agent) | 选择 **Ask**，输入“跟踪请求如何到达数据库”。 |
| 规划复杂更改 | [Plan 智能体](../../../work-with-ai/plan-and-run-tasks/2.2.10.1-PlanWork/) | 选择 **Plan**，描述要在实现前研究的更改。 |
| 构建功能、修复错误或创建项目 | [智能体](#use-agents) | 选择 **Agent**，描述结果并指定如何验证。 |
| 进行聚焦编辑 | [内联聊天](../../../work-with-ai/2.2.4-InlineChatAndQuickChat/) | 在编辑器中选择代码并描述更改。 |
| 在输入和编辑时获取帮助 | [内联建议](../../../../editor/3.2-WriteCode/3.2.3-InlineSuggestions/) | 接受幽灵文本补全代码，或使用下一次编辑建议导航并应用相关编辑。 |
| 管理跨项目的独立任务 | [智能体窗口](../../../work-with-ai/2.2.3-AgentsWindow/) | 选择标题栏中的 **在智能体中打开**，然后启动并监控会话。 |
| 跨应用和设备继续智能体工作 | [GitHub Environments（预览）](../../../work-across-apps-and-machines/2.5.2-RemoteAgentSessions/) | 从 **远程连接** 注册开发计算机，然后从受支持的 Copilot 客户端连接。VS Code 专用访问请使用 [SSH 或开发隧道](../../../work-across-apps-and-machines/2.5.2-RemoteAgentSessions/#choose-how-to-connect)。 |
| 在不保持机器在线的情况下运行和继续交互式工作 | [云会话](../../../work-across-apps-and-machines/2.5.3-CloudSessions/) | 开启云会话支持，选择 **Cloud** 并选择仓库。重新打开现有会话继续。 |
| 检查 Web 应用行为 | [浏览器工具](../../../work-with-ai/plan-and-run-tasks/2.2.10.3-BrowserTools/) | 要求智能体打开应用、测试用户流程并报告结果。 |
| 按计划或仓库事件重复常规工作 | [自动化](../../../work-with-ai/plan-and-run-tasks/2.2.10.5-Automations/) | 在智能体窗口中保存提示词和配置。先检查手动运行。云自动化还支持服务公布的议题和拉取请求触发器。 |
| 生成提交消息或重命名符号 | [智能操作](../../../../editor/3.2-WriteCode/3.2.4-SmartActions/) | 使用闪光操作或编辑器上下文菜单，无需编写提示词。 |
| 探索数据或编辑笔记本 | [笔记本 AI](../../../tutorials-and-guides/2.6.13-JupyterNotebooks/) | 在 **Local** 智能体会话中，要求智能体创建、编辑和运行笔记本单元格。 |
| 按含义查找代码或设置 | [语义搜索预览](../../../../editor/3.2-WriteCode/3.2.4-SmartActions/)和 [AI 设置搜索](../../../../editor/3.3-ConfigureTheEditor/3.3.4-Settings/) | 在搜索视图中按含义搜索，或在设置编辑器中描述设置。 |

## 使用智能体 {#use-agents}

　　使用[聊天视图](../../../work-with-ai/2.2.2-ChatView/)在代码旁工作，或使用**智能体窗口**专注于分配更高层任务并审查结果。

对于复杂更改，请**规划**、**实现**、**验证**，然后**审查**：

* **规划**：要求 Plan 智能体研究更改并识别风险。将方法交给实现智能体前先审查。
* **实现**：描述预期行为和约束。智能体搜索代码、编辑文件并使用工具。
* **验证**：要求智能体运行相关测试或操作应用。检查它实际验证了什么。
* **审查**：提交或合并前审查差异和验证结果。

例如，给智能体一个具体的浏览器检查：

```text
打开应用并测试缺少电子邮件地址时的注册流程。验证它显示验证错误且不提交表单。
报告你测试的内容和发现的问题。
```

组织较大任务：

* 对不应共享代码更改的独立任务使用[单独会话和工作树](../../../tutorials-and-guides/2.6.8-RunParallelTasks/)。
* 使用[子智能体](../../../work-with-ai/plan-and-run-tasks/2.2.10.4-Subagents/)在单独上下文中委派任务的聚焦部分。
* 当希望使用另一个受支持运行框架继续工作时，[交接会话](../../../choose-models-and-agents/2.3.2-ChooseAnAgentHarness/#continue-with-a-different-harness)。云执行请[启动云会话](../../../work-across-apps-and-machines/2.5.3-CloudSessions/)。

## 获得更好的结果 {#get-better-results}

| 需求 | 使用 |
|---|---|
| 将请求建立在特定代码或故障上 | 通过 **添加上下文**、`#` 提及或拖动文件[添加上下文](../../../work-with-ai/2.2.7-AddPromptContext/)。附加相关代码、错误、测试输出或 GitHub 议题。 |
| 不必自己找到每个文件即可探索代码库 | 让智能体使用搜索和语言工具收集[工作区上下文](../../../concepts/2.7.8-WorkspaceContext/)。 |
| 平衡推理、速度和成本 | 使用[模型选择器](../../../choose-models-and-agents/2.3.1-ChooseAndConfigureModels/)，或可用时的 **自动**。更改模型不会更改智能体运行框架。 |
| 使用其他智能体提供商 | [选择运行框架](../../../choose-models-and-agents/2.3.2-ChooseAnAgentHarness/)，例如 Copilot、Anthropic Claude 或 OpenAI Codex。检查其工具、身份验证选项和设置要求。 |
| 使用自己的模型提供商或本地模型 | 配置[自带密钥（BYOK）](../../../choose-models-and-agents/2.3.1-ChooseAndConfigureModels/#bring-your-own-language-model-key)。内联建议和语义搜索仍需要 Copilot 服务。 |
| 跨对话保留有用知识 | 让智能体使用[记忆](../../../work-with-ai/sessions/2.2.11.1-ManageSessions/)记住。使用 **Chat: Show Memory Files** 检查存储的笔记。 |
| 管理长对话或其成本 | 检查[上下文使用量](../../../work-with-ai/sessions/2.2.11.1-ManageSessions/#manage-session-context)、压缩对话或为无关任务开始新聊天。请参阅[使用指南](../../../tutorials-and-guides/2.6.14-ReduceCreditUsage/)。 |

## 保持控制 {#stay-in-control}

| 我需要… | 操作 |
|---|---|
| 决定哪些操作需要确认 | 选择会话[权限级别](../../../work-with-ai/permissions-and-security/2.2.12.1-ApprovalsAndPermissions/#permission-levels)并审查工具请求。**全部允许** 会绕过确认，不应视为使用智能体的前提。 |
| 重定向进行中的工作 | [引导、排队后续消息或停止请求](../../../work-with-ai/2.2.5-UseChat/#send-messages-while-a-request-is-running)。停止不会撤销已完成操作。 |
| 检查或撤销智能体更改 | [审查差异、提供反馈或恢复检查点](../../../work-with-ai/2.2.8-ReviewAndRevertChanges/)。整合前验证结果。 |
| 限制终端对文件和网络的访问 | 使用[智能体终端沙盒](../../../work-with-ai/permissions-and-security/2.2.12.2-AgentSandboxing/)。Git 工作树隔离代码更改，但不是安全边界。 |
| 要求 AI 审查代码 | 使用[代码审查智能操作](../../../../editor/3.2-WriteCode/3.2.4-SmartActions/)。这会生成审查反馈，不能替代你审查智能体更改。 |

> **重要**：智能体可以直接将会话文件夹或工作树中的编辑保存。**手动审批** 不会为每次文件编辑请求确认。在现有项目中工作前，请审查[安全基线](../../../work-with-ai/permissions-and-security/2.2.12.3-AISecurity/#recommended-security-baseline)。

## 自定义工作流 {#customize-your-workflow}

| 我想要… | 使用 |
|---|---|
| 应用项目约定而不重复 | [指令](../../../customize-and-extend/2.4.4-Instructions/)，用于编码标准、架构和测试命令。 |
| 打包带支持脚本或示例的工作流 | [智能体技能](../../../customize-and-extend/2.4.3-AgentSkills/)，在相关时加载或按名称调用。 |
| 按需运行保存的提示词 | [提示词文件](../../../customize-and-extend/2.4.10-PromptFiles/)，作为斜杠命令调用。 |
| 定义专门角色和工具选择 | [自定义智能体](../../../customize-and-extend/2.4.5-CustomAgents/)，例如只读审查者。 |
| 连接数据库、议题跟踪器或其他外部系统 | 提供工具的 [MCP 服务器](../../../customize-and-extend/2.4.7-AddMCPServers/)。 |
| 在智能体工作流特定点运行命令 | [钩子](../../../customize-and-extend/2.4.9-Hooks/)，而不是依赖模型遵循指令。 |
| 安装打包自定义项 | [智能体插件](../../../customize-and-extend/2.4.2-Plugins/)。 |

　　使用[智能体自定义编辑器](../../../customize-and-extend/2.4.1-Overview/#agent-customizations-editor)为所选运行框架创建和管理这些选项。

## 调试和修复问题 {#debug-and-fix-problems}

| 任务 | 起点 |
|---|---|
| 生成测试 | 选择代码并使用 **生成代码** > **生成测试**，或要求智能体使用项目框架添加并运行测试。 |
| 诊断失败测试 | 在测试资源管理器中选择 **修复测试失败**，或将失败输出附加到聊天。 |
| 修复编译器或 lint 错误 | 使用编辑器代码操作（灯泡），或将问题附加到聊天。 |
| 配置调试会话 | 请求调试配置，或在终端运行命令前使用 `copilot-debug`（预览），例如 `copilot-debug python foo.py`。 |

将任务、约束和验证合并在一个请求中：

```text
找出失败的身份验证测试的原因。在不改变预期行为的情况下修复实现。
运行相关测试并总结更改和结果。
```

　　请参阅[测试和错误的智能操作](../../../../editor/3.2-WriteCode/3.2.4-SmartActions/)和[调试](../../../../debugging-and-testing/6.1-Debugging/)。

## 聊天参考 {#chat-reference}

### 聊天工具 {#chat-tools}

　　智能体自动选择工具，无需在提示词中命名每个工具。输入 `#` 浏览可用工具和上下文项，或引用工具将智能体引导到某种能力。具体名称请参阅[工具和上下文参考](../2.8.1.2-ToolsAndContext/)。

### 斜杠命令 {#slash-commands}

　　输入 `/` 查看当前会话可用命令。可用性取决于聊天界面、运行框架、角色和已启用功能。

| 命令 | 用途 |
|---|---|
| `/plan` | 研究并提出实现计划。 |
| `/explain`、`/fix`、`/tests` | 解释代码、建议修复或生成测试。 |
| `/doc` | 从编辑器内联聊天生成文档注释。 |
| `/setupTests`（实验性） | 帮助选择并设置测试框架。 |
| `/new`、`/newNotebook` | 搭建工作区、文件或笔记本。 |
| `/compact` | 压缩对话上下文。 |
| `/fork` | [分叉对话](../../../work-with-ai/sessions/2.2.11.1-ManageSessions/#fork-a-chat-session)及其历史。 |
| `/fork <title>`、`/fork prompt <prompt>` | 命名分叉，或分叉并立即发送带上下文的提示词。需要受支持的 Agent Host 会话。 |
| `/clear` | 开始新聊天并归档或标记当前聊天完成。 |
| `/rename <name>`、`/help` | 重命名本地聊天，或列出本地 Ask 聊天中的命令和智能体。 |
| `/models`、`/tools` | 打开模型选择器，或为本地聊天配置工具。 |
| `/init` | 在本地智能体会话中生成或更新工作区指令。 |
| `/agents`、`/instructions`、`/skills`、`/prompts`、`/hooks` | 配置相应自定义类型。聊天视图中 **Local** 可使用全部；**Copilot** 仅支持 `/prompts` 和 `/hooks`。 |
| `/create-agent`、`/create-instructions`、`/create-skill`、`/create-prompt`、`/create-hook` | 在本地智能体会话中生成自定义项。 |
| `/troubleshoot` | 分析本地或 Copilot CLI 会话中的智能体调试日志。 |
| `/debug` | 从聊天视图打开 Chat Debug 视图，不在智能体窗口中。 |
| `/sandbox policy` | 检查 Copilot 会话的[有效沙盒策略](../../../work-with-ai/permissions-and-security/2.2.12.2-AgentSandboxing/)。 |
| `/<name>` | 按名称调用智能体技能或可复用提示词。 |

　　例如，`.github/skills/webapp-testing/SKILL.md` 中的技能可以用 `/webapp-testing` 调用。权限和 Autopilot 命令请参阅[审批和权限](../../../work-with-ai/permissions-and-security/2.2.12.1-ApprovalsAndPermissions/)。

### 聊天参与者（已弃用） {#chat-participants-deprecated}

　　Copilot 运行框架不支持聊天参与者。请直接询问智能体并附加相关上下文，或使用带技能和 MCP 工具的插件处理领域特定工作流。请参阅[替换聊天参与者](../../../customize-and-extend/2.4.11-MigrateExistingCustomizations/#replace-chat-participants)。
