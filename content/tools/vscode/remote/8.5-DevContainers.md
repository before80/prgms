# 8.5 开发容器

　　开发容器（Dev Containers）让你可以在容器内使用完整的开发环境，同时继续使用 Visual Studio Code 的编辑、调试和终端功能。容器可以使用单独的工具链或运行基于容器的应用程序，并确保团队使用一致的环境。

　　此页面在官方文档中重定向到独立的 Dev Containers 文档。有关安装扩展、创建 `devcontainer.json`、在容器中打开文件夹以及自定义开发容器的完整说明，请参阅 [Dev Containers 文档](https://code.visualstudio.com/docs/devcontainers/containers)。

## 使用 Dev Containers {#using-dev-containers}

1. 在本地安装 [Dev Containers 扩展](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers)和 Docker。
2. 打开一个包含 `.devcontainer/devcontainer.json` 配置的项目文件夹，或使用 **Dev Containers: Add Dev Container Configuration Files...** 命令添加配置。
3. 从命令面板（`F1`、`Ctrl + Shift + P`（macOS：`Cmd + Shift + P`））运行 **Dev Containers: Reopen in Container**。
4. VS Code 会构建或启动容器，并在容器中重新打开工作区。终端、扩展和调试器随后会在容器环境中运行。

　　你也可以将 Remote - SSH 或 Remote - Tunnels 与 Dev Containers 结合，在远程主机的容器中打开文件夹。
