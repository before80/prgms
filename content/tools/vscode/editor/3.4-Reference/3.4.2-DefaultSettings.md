# 3.4.2 默认设置

　　VS Code 自带一组默认设置，用户或工作区设置可以覆盖它们。可以通过设置编辑器修改，也可以直接编辑 `settings.json`。

## 查看默认设置 {#view-default-settings}

1. 打开命令面板（`Ctrl + Shift + P`）。
2. 运行 **Preferences: Open Default Settings (JSON)**。
3. VS Code 会打开只读文件 `defaultSettings.json`，其中包含所有默认设置及说明。

　　默认设置文件用于查阅和参考，不能直接编辑。要更改设置，请编辑用户或工作区 `settings.json`，或在设置编辑器中选择 **在 settings.json 中编辑**。

## 覆盖默认值 {#override-defaults}

```json
{
  "editor.fontSize": 16,
  "editor.tabSize": 4,
  "files.autoSave": "onFocusChange"
}
```

　　用户设置覆盖默认设置；工作区设置覆盖用户设置；语言特定设置覆盖非语言特定设置。

## 重置设置 {#reset-settings}

在设置编辑器中将鼠标悬停在修改过的设置上，选择齿轮图标，然后选择 **重置设置**。要重置所有设置，请删除用户 `settings.json` 中花括号之间的内容。
