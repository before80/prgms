# 3.4.1 默认键盘快捷键

　　VS Code 提供一组默认键盘快捷键。本文列出常用默认快捷键。

要查看完整列表，请在 VS Code 中使用以下任一方式：

* 在命令面板中选择 **Preferences: Open Default Keyboard Shortcuts (JSON)**。
* 打开键盘快捷键编辑器，然后在 **更多操作**（**...**）菜单中选择 **显示系统键绑定**。

> **注意**：以下按键基于标准美式键盘布局。使用其他[键盘布局](../3.3-ConfigureTheEditor/3.3.3-KeyboardShortcuts/)时，快捷键可能不同。
