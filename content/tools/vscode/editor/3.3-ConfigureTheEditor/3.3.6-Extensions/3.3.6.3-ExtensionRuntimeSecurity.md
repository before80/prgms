# 3.3.6.3 扩展运行时安全

　　扩展极大地增强了 Visual Studio Code 的功能，但也可能引入风险，例如恶意代码执行和数据隐私问题。[Visual Studio Marketplace](https://marketplace.visualstudio.com/vscode) 有多种方式保护你免受不良扩展侵害。此外，VS Code 提供多种扩展可靠性指标。

## 扩展运行时权限 {#about-extension-runtime-permissions}

　　[扩展宿主](https://code.visualstudio.com/api/advanced-topics/extension-host)负责在 VS Code 中运行扩展。扩展宿主具有与 VS Code 本身相同的权限。这意味着 VS Code 能执行的任何操作，扩展也可以通过扩展宿主执行。例如，扩展可以读写计算机上的文件、发起网络请求、运行外部进程并修改工作区设置。

## 扩展发布者信任 {#extension-publisher-trust}

　　从 VS Code 1.97 开始，首次安装来自第三方发布者的扩展时，VS Code 会显示对话框，要求确认信任该扩展的发布者。信任扩展包或具有依赖项扩展的发布者时，也会信任依赖扩展的发布者。

　　之前安装的扩展发布者被视为受信任，并自动添加到受信任发布者列表。可以使用 **Extensions: Manage Trusted Extensions Publishers** 命令管理受信任扩展列表。

> **重要**：使用 [3.3.10 命令行界面](../../3.3.10-CommandLineInterface/#working-with-extensions)安装扩展时，扩展发布者不会自动被信任。

## 判断扩展可靠性 {#determine-extension-reliability}

　　安装扩展之前，可以采取多种步骤判断其可靠性：

* **评分和评论**：阅读其他人对扩展的看法。
* **问答**：查看现有问题和发布者的响应程度。
* **议题、仓库和许可证**：检查发布者是否提供这些信息，以及是否提供你期望的支持。
* **已验证发布者**：发布者名称和域名旁的蓝色对勾是额外的信任信号，表示发布者已向 Marketplace 证明域名所有权，并且 Marketplace 已验证域名存在以及发布者在 Marketplace 的良好状态至少六个月。

    ![已验证发布者](./images/bluecheck.png)

> **提示**：如果要在组织中强制执行允许使用的扩展，请了解如何[7.3 扩展管理](../../../../enterprise/7.3-Extensions/#configure-allowed-extensions)。

## Marketplace 保护措施 {#marketplace-protections}

* **恶意软件扫描**：Marketplace 会对每个发布的扩展包运行恶意软件扫描，使用多个防病毒引擎，并在每次新扩展和更新时运行。扫描全部通过前，扩展不会发布。
* **动态检测**：Marketplace 通过在沙盒环境（*干净环境 VM*）中运行扩展，验证其运行时行为。
* **已验证发布者**：发布者可以通过证明域名所有权验证身份（蓝色对勾）。
* **异常使用监控**：Marketplace 监控扩展的下载和使用模式，以检测异常行为。
* **名称抢注**：Marketplace 阻止扩展作者盗用 Microsoft、RedHat 等官方发布者以及 GitHub Copilot 等热门扩展的名称。
* **阻止列表**：如果恶意扩展被报告并验证，或扩展依赖项中发现漏洞，扩展会从 Marketplace 移除并加入*阻止列表*。如果已安装，VS Code 会自动卸载。
* **扩展签名验证**：Marketplace 在发布时对所有扩展签名。VS Code 安装扩展时会检查签名，验证扩展包的完整性和来源。
* **机密扫描**：Marketplace 会自动扫描每个新发布扩展中的 API 密钥或凭据等机密。如果检测到机密，会阻止发布以防安全风险。VSCE 工具在打包时扫描 `.env` 文件，发现机密时阻止发布。

　　详细了解 [Visual Studio Marketplace 安全与信任](https://devblogs.microsoft.com/blog/security-and-trust-in-visual-studio-marketplace)。

## 报告可疑扩展 {#report-suspicious-extensions}

　　如果发现可疑扩展，请向 Marketplace 团队报告。Marketplace 团队会在一个工作日内提供初步响应。在 [Visual Studio Marketplace](https://marketplace.visualstudio.com/vscode) 中打开扩展页面，选择 **更多信息** 部分底部的 **报告问题** 链接。
