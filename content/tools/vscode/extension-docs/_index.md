# 11 扩展文档

　　扩展为 Visual Studio Code 添加专门的工具和工作流。选择一个领域，探索其功能、设置指南、教程和参考文档。

## 选择工作流 {#choose-a-workflow}

* [**容器工具**](https://code.visualstudio.com/docs/containers/overview)：使用 Docker 和 Kubernetes 构建、管理、调试和部署容器化应用程序。
* [8.5 开发容器](../remote/8.5-DevContainers/)：将容器用作项目的完整、可复现的开发环境。
* [8 远程](../remote/)：在远程计算机、WSL 或 GitHub Codespaces 等云托管环境中工作。
* [**Azure**](https://code.visualstudio.com/docs/azure/overview)：在 VS Code 中创建、部署和管理应用程序及云资源。
* [**数据科学**](https://code.visualstudio.com/docs/datascience/overview)：探索数据、运行 Jupyter 笔记本并构建机器学习模型。
* [**智能应用**](https://code.visualstudio.com/docs/intelligentapps/overview)：使用 Foundry Toolkit 中的模型、游乐场和评估工具构建 AI 应用程序和智能体。
