> 原文链接: [https://docs.brew.sh/Manpage](https://docs.brew.sh/Manpage)

brew 的命令基本形式为：

```text
brew <command> [--verbose|-v] [options] [formula] ...
```

`--verbose` 和 `--debug` 会输出更多调试信息，并且只能出现在命令名称之后，例如 `brew install --verbose git`。

## install：安装 formula

```sh
brew install <formula>
```

`<formula>` 通常是 formula 名称，但也可以是其他语法，例如第三节提到的全限定名 `user/repository/formula`。安装 cask 时加 `--cask`：

```sh
brew install --cask <cask>
```

## uninstall：卸载

```sh
brew uninstall <formula>
```

卸载一个 formula 会移除其符号链接和 keg。若 formula 被其他软件依赖，brew 会提示你可能需要先处理依赖；`brew autoremove` 可以清理不再被依赖的残留（见 4.3）。

## list：列出已安装内容

```sh
brew list                    # 列出所有已安装的 formula
brew list --cask             # 列出所有已安装的 cask
brew list <formula>          # 列出某个 formula 安装的文件
```

## search：搜索软件

```sh
brew search <text>    # 按子串搜索 cask 名称与 formula 名称
brew search /<regex>/ # 两侧加斜线则按正则表达式搜索
brew search           # 不带参数时列出本地所有可用 formula
```

`brew search` 的在线搜索会扩展到官方仓库 `homebrew/core` 与 `homebrew/cask`。也可以用浏览器在 [formulae.brew.sh](https://formulae.brew.sh/) 搜索，它会展示依赖、版本与下载统计。

## 获取详细信息

```sh
brew info <formula>          # 版本、依赖、keg-only 原因、注意事项
brew info --json=v2 <formula> # 输出 JSON 格式信息，便于脚本处理
brew deps <formula>          # 查看 formula 的依赖
brew uses <formula>          # 查看哪些已安装 formula 依赖它
```

## 查找命令帮助

```sh
brew help
brew help <command>
man brew
```

任何命令的完整选项都以 `--help` 为准，例如 `brew install --help`。官方 FAQ 也提醒：如果某个功能不在 `man brew` 中，它很可能是外部命令，请用其自带的 `--help` 查看。

## 小练习

```sh
brew search jq
brew info jq
brew install jq
brew list jq
```

完成后用 `jq --version` 验证安装。这个“搜索→查看→安装→确认”的循环会陪伴你使用 brew 的每一天。
