> 原文链接: [https://brew.sh/](https://brew.sh/)

Homebrew 的官方口号是 “The Package Manager for Everywhere”（无处不在的包管理器）。它支持 macOS（Sonoma 14 及更新版本）、Linux 以及 Windows Subsystem for Linux（WSL）。

## 它解决什么问题

macOS 本身只附带一套经过 Apple 挑选的命令行工具，很多 Unix/Linux 生态中的常用软件并不会预装。Homebrew 的作用是：

- 安装命令行工具，例如 `git`、`wget`、`jq`、`ripgrep`；
- 安装需要编译的库与运行环境，例如 `openssl`、`python`、`node`；
- 安装桌面应用、字体和插件（通过 Cask，见第 1.3 节）；
- 管理后台服务，例如用 `brew services` 启动 PostgreSQL、Redis；
- 用 `Brewfile` 声明式重现一整台机器的软件环境。

## 它不会做什么

Homebrew 不会在它的安装前缀（prefix）之外安装文件。每个软件包会被安装进 `Cellar` 中独立的 “keg”（酒桶，一个版本对应一个目录），再把可执行文件等符号链接到安装前缀中，也就是 Homebrew 本身所在的目录：

- Apple Silicon Mac（包括 MacBook Pro M4）：`/opt/homebrew`
- Linux 与 WSL：`/home/linuxbrew/.linuxbrew`
- Intel Mac：`/usr/local`

这种设计意味着绝大多数情况下你不需要 `sudo`，Homebrew 对“目录所有权”和系统安全边界有着非常严格的约定，后面章节会展开说明。

## 快速感受一下

在 macOS 的“终端”（Terminal）应用中粘贴下面这行命令，即可开始安装：

```sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

脚本会先说明它要做什么，然后暂停等待你确认。安装完成后，你的 M4 Mac 上 brew 就在 `/opt/homebrew/bin/brew`。详细安装步骤见 [第 2 章](../../installation/)。
