> 原文链接: [https://brew.sh/](https://brew.sh/)

Homebrew（通常直接称为 brew）是 macOS、Linux 与 Windows Subsystem for Linux（WSL）上最流行的包管理器之一。对刚入手 MacBook Pro M4 的你来说，brew 是补齐系统自带工具链、快速安装开发依赖和桌面应用的最直接方式。

本章先回答三个问题：brew 是什么、它把文件装到哪里、它管理的“软件包”有哪些种类。读完本章，你会对之后每条命令背后的设计思路有清晰认识。
