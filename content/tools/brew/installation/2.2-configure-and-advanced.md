## 把 brew 加进 shell

Homebrew 安装完会打印一段提示：在 shell 配置文件中加入

```sh
eval "$(/opt/homebrew/bin/brew shellenv)"
```

具体加到哪个文件取决于你的 shell：

- zsh（macOS 默认）：`~/.zshrc`
- bash：`~/.bashrc`（或登录 shell 的 `~/.bash_profile`）

其中的 `/opt/homebrew/bin` 就是你的 Homebrew prefix 路径。`brew shellenv` 会设置好 `PATH`、`MANPATH`、shell 补全路径等环境变量，因此以后不要在配置里手工把 `/opt/homebrew/bin` 写死，直接使用这行 `eval` 最稳妥。

如果你希望同一份 dotfiles 在 macOS 与 Linux 之间通用，可以参考 [7.1 实用技巧精选](../../advanced/7.1-practical-tips/) 中“跨操作系统加载 Homebrew”的做法。

## Git 远程镜像

如果连接 GitHub.com 有困难，可以在安装脚本执行前通过环境变量指定 Git 镜像：

```sh
export HOMEBREW_BREW_GIT_REMOTE="..."  # 填入 Homebrew/brew 的 Git 镜像
export HOMEBREW_CORE_GIT_REMOTE="..."  # 填入 Homebrew/homebrew-core 的 Git 镜像
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

> 警告：设置这些变量等同于授予镜像仓库与 Homebrew 本身同等的信任级别。请务必确认镜像不会失陷。

## 回到旧的“克隆 Tap”模式

Homebrew 4.0 起默认通过 JSON API 获取 formula/cask 元数据。若想让安装时克隆 `homebrew/homebrew-core` 并回到 4.0 之前的行为：

```sh
export HOMEBREW_NO_INSTALL_FROM_API=1
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

除非你是 Homebrew 维护者或贡献者，一般不建议全局开启此设置；确有需要也可以在安装后随时开启。

## 无人值守安装

在自动化脚本中执行安装且不希望脚本等待交互确认，可在安装命令前加：

```sh
NONINTERACTIVE=1 /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

## .pkg 安装器指定安装用户

若需要在登录窗口阶段（尚无用户登录）以其他用户身份安装，可提前创建 `/var/tmp/.homebrew_pkg_user.plist` 并写入 `HOMEBREW_PKG_USER` 值。该文件必须由 `root` 所有、权限为 0600、不能是符号链接、不能带 ACL，否则安装器会忽略此配置并回退到当前控制台用户。普通个人使用无需关注这一项。

## 在 Linux 或 WSL 安装

Linux 与 WSL 的安装说明见官方 [Homebrew on Linux](https://docs.brew.sh/Homebrew-on-Linux) 文档，默认前缀为 `/home/linuxbrew/.linuxbrew`。本书其余章节的命令在所有平台基本通用。
