## 官方支持的安装条件

针对 macOS，官方支持的配置要求如下：

- 在 Apple Silicon 上使用 64 位 CPU（M4 完全满足）；
- 安装 macOS Sonoma（14）或更高版本；
- 已安装 Xcode 的 Command Line Tools（CLT），可通过 `xcode-select --install` 安装，或从 [Apple 开发者网站](https://developer.apple.com/download/all/) 获取；也可以安装完整 Xcode；
- 安装脚本使用 Bourne-again shell（即 `bash`），不能用 zsh、fish、tcsh 或 csh 执行那一行安装命令。

> 提示：CLT 是“从源码构建 formula”所必需的；cask 和 bottle 没有开发者工具也能安装，但官方仍建议先装好 CLT，`brew doctor` 也不会因此报警。

## 方式一：官方一行命令安装

在 macOS 的“终端”中粘贴：

```sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

脚本会安装到 Apple Silicon 的默认前缀 `/opt/homebrew`。它是一份“谨慎”的脚本：

- 安装前会准确说明每一步要做什么，并要求你逐项确认；
- 即使 prefix 中已经有一些内容，也可以安全运行；
- 安装完成后不需要 `sudo` 就能执行 `brew install`。

## 方式二：macOS .pkg 安装器

如果你需要交互式或无人值守的 MDM（移动设备管理）批量部署，可以下载 Homebrew 官方 GitHub 最新发行版中的 `.pkg` 安装器。该安装器只支持 Apple Silicon，同样把 Homebrew 安装到默认前缀 `/opt/homebrew`。

## 安装后必须做的配置

安装完成后，终端里会打印需要写入 shell 配置的提示。**不执行这一步，brew 将无法工作。** 详细说明见 [2.2 安装后的环境配置](../2.2-configure-and-advanced/)。

## 如何确认安装成功

重开一个终端窗口后，检查：

```sh
brew --version
which brew
```

`which brew` 应输出 `/opt/homebrew/bin/brew`。如果输出系统自带的其他路径或找不到命令，请先检查 shell 配置是否加载了 `brew shellenv`。
