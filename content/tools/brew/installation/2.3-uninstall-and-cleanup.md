## 完整卸载 Homebrew

如需彻底卸载 Homebrew，运行 [Homebrew/install](https://github.com/Homebrew/install) 仓库提供的卸载脚本：

```sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/uninstall.sh)"
```

脚本会移除 Homebrew 前缀、缓存、已安装的 formula 与 cask，并打印每步操作。卸载前如果希望保存当前安装清单以便日后恢复，先执行：

```sh
brew bundle dump
```

把生成的 `Brewfile` 保存到 Homebrew 前缀之外的安全位置。Brewfile 的用法见 [第 6 章](../../bundle/)。

## 升级时旧版本的去留

默认情况下，执行 `brew upgrade` 升级某个 formula 时，Homebrew 会自动卸载它的旧版本 keg；此外 Homebrew 每 30 天会定期执行一次额外的清理。因此多数用户无需手动删除旧版本。

如果希望关闭自动清理：

```sh
export HOMEBREW_NO_INSTALL_CLEANUP=1
```

只对指定 formula 关闭自动清理：

```sh
export HOMEBREW_NO_CLEANUP_FORMULAE=foo,bar
```

> 注意：关闭自动清理后，`brew uninstall <formula>` 只会移除当前最新版本，而不会删除历史上安装过的其他版本；`brew upgrade` 仍会尝试安装它知道的最新版本。若想彻底删除某个 formula 的所有版本，需要运行 `brew uninstall --force <formula>`，这是一个具有破坏性的操作，请谨慎使用。

## 迁移到新机器或新前缀

官方推荐用 Brewfile 完成“换机迁移”：

1. 在旧机器上 `brew bundle dump` 生成清单；
2. 在新机器上安装 Homebrew；
3. 运行 `brew bundle install` 按清单恢复。

更完整的说明见 [6.2 使用 brew bundle 管理机器状态](../../bundle/6.2-manage-machine-state/)。
