# 9.1.1.9.1 集合操作概览

Kotlin 标准库提供了种类丰富的函数用于对集合执行操作。这既包括获取或添加元素这样的简单操作，也包括搜索、排序、过滤、转换等更复杂的操作。

## 扩展函数与成员函数 {#extension-and-member-functions}

集合操作在标准库中以两种方式声明：集合接口的[成员函数](../../../../../languageguide/5.8-Classesandinterfaces/5.8.1-Classes/)和[扩展函数](../../../../../languageguide/5.8-Classesandinterfaces/5.8.3-Extensions/#extension-functions)。

成员函数定义了集合类型必不可少的操作。例如，[`Collection`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/-collection/index.html) 包含用于检查是否为空的函数 [`isEmpty()`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/-collection/is-empty.html)；[`List`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/-list/index.html) 包含用于按索引访问元素的 [`get()`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/-list/get.html)，等等。

当你创建集合接口的自定义实现时，必须实现它们的成员函数。为了让创建新实现更容易，请使用标准库中集合接口的骨架实现：[`AbstractCollection`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/-abstract-collection/index.html)、[`AbstractList`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/-abstract-list/index.html)、[`AbstractSet`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/-abstract-set/index.html)、[`AbstractMap`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/-abstract-map/index.html) 以及它们对应的可变版本。

其他集合操作声明为扩展函数。它们是过滤、转换、排序以及其他集合处理函数。

## 通用操作 {#common-operations}

通用操作对[只读集合和可变集合](../../9.1.1.1-CollectionsOverview/#collection-types)都可用。通用操作可分为以下几组：

* [转换](../../9.1.1.6-CollectionTransformations/)
* [过滤](../../9.1.1.7-CollectionFiltering/)
* [`plus` 和 `minus` 运算符](../9.1.1.9.7-CollectionPlusMinus/)
* [分组](../../9.1.1.5-CollectionGrouping/)
* [获取集合的一部分](../../9.1.1.8-Retrieve/9.1.1.8.1-CollectionParts/)
* [获取单个元素](../../9.1.1.8-Retrieve/9.1.1.8.2-CollectionElements/)
* [排序](../../9.1.1.4-CollectionOrdering/)
* [聚合操作](../9.1.1.9.2-CollectionAggregate/)

这些页面上描述的操作在返回结果时不会影响原集合。例如，过滤操作会产生一个*新集合*，其中包含所有匹配过滤条件的元素。这类操作的结果应当存入变量，或以其他方式使用，例如传给其他函数。

```kotlin

fun main() {
    val numbers = listOf("one", "two", "three", "four")
    numbers.filter { it.length > 3 } // `numbers` 没有任何变化，结果被丢弃了
    println("numbers are still $numbers")
    val longerThan3 = numbers.filter { it.length > 3 } // 结果存入 `longerThan3`
    println("numbers longer than 3 chars are $longerThan3")
}
```

对于某些集合操作，可以选择指定*目标*对象。目标是一个可变集合，函数会把结果项追加到它里面，而不是以新对象的形式返回。要执行带目标的操作，可以使用名称带 `To` 后缀的单独函数，例如用 [`filterTo()`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/filter-to.html) 代替 [`filter()`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/filter.html)，或用 [`associateTo()`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/associate-to.html) 代替 [`associate()`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/associate.html)。这些函数会把目标集合作为额外参数。

```kotlin

fun main() {
    val numbers = listOf("one", "two", "three", "four")
    val filterResults = mutableListOf<String>() // 目标对象
    numbers.filterTo(filterResults) { it.length > 3 }
    numbers.filterIndexedTo(filterResults) { index, _ -> index == 0 }
    println(filterResults) // 包含两个操作的结果
}

```

为方便起见，这些函数会把目标集合返回，因此你可以直接在函数调用的相应实参中创建它：

```kotlin

fun main() {
    val numbers = listOf("one", "two", "three", "four")
    // 直接把数字过滤进一个新的哈希集，
    // 从而消除结果中的重复项
    val result = numbers.mapTo(HashSet()) { it.length }
    println("distinct item lengths are $result")
}
```

带目标的函数可用于过滤、关联、分组、展平以及其他操作。目标操作的完整列表见 [Kotlin 集合参考](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/index.html)。

## 写操作 {#write-operations}

对于可变集合，还有会改变集合状态的*写操作*。这类操作包括添加、移除和更新元素。写操作列在[写操作](../9.1.1.9.3-CollectionWrite/)以及 [List 特有操作](../9.1.1.9.4-ListOperations/#list-write-operations)和[映射特有操作](../9.1.1.9.6-MapOperations/#map-write-operations)的相应章节中。

对于某些操作，有成对的函数执行同样的操作：一个原地应用该操作，另一个把结果作为单独的集合返回。例如，[`sort()`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/sort.html) 会原地排序可变集合，因此它的状态会改变；[`sorted()`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/sorted.html) 则创建一个新集合，其中包含按排序顺序排列的相同元素。

```kotlin

fun main() {
    val numbers = mutableListOf("one", "two", "three", "four")
    val sortedNumbers = numbers.sorted()
    println(numbers == sortedNumbers) // false
    numbers.sort()
    println(numbers == sortedNumbers) // true
}
```
