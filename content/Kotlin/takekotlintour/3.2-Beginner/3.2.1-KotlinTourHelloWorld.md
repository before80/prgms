# 3.2.1 Hello world

下面是一个打印 "Hello, world!" 的简单程序：

```kotlin
fun main() {
    println("Hello, world!")
    // Hello, world!
}
```

在 Kotlin 中：

* `fun` 用于声明函数
* `main()` 函数是程序的入口
* 函数体写在一对花括号 `{}` 中
* [`println()`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.io/println.html) 和 [`print()`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.io/print.html) 函数把它们的参数打印到标准输出

函数是一组执行特定任务的指令。一旦创建了函数，你就可以在需要执行该任务时随时使用它，而不必把那些指令重新写一遍。函数会在后面几章中详细讨论。在那之前，所有示例都使用 `main()` 函数。

## 变量 {#variables}

所有程序都需要能够存储数据，而变量正是帮你做到这一点的工具。在 Kotlin 中，你可以声明：

* 用 `val` 声明的只读变量
* 用 `var` 声明的可变变量

> **注意：** 一旦给只读变量赋了值，就不能再修改它。

要赋值，请使用赋值运算符 `=`。

例如：

```kotlin
fun main() {
    val popcorn = 5    // 有 5 盒爆米花
    val hotdog = 7     // 有 7 个热狗
    var customers = 10 // 队列中有 10 位顾客

    // 一些顾客离开了队列
    customers = 8
    println(customers)
    // 8
}
```

> **提示：** 变量可以在程序开头、`main()` 函数之外声明。以这种方式声明的变量称为**顶层**变量。

由于 `customers` 是可变变量，它的值可以在声明之后重新赋值。

> **注意：** 我们建议默认把所有变量都声明为只读变量（`val`）。只有确实需要时才使用可变变量（`var`）。这样你就更不容易意外修改本不该改变的东西。

## 字符串模板 {#string-templates}

知道如何把变量的内容打印到标准输出是很有用的。你可以用**字符串模板**做到这一点。模板表达式可以用来访问存储在变量和其他对象中的数据，并把它们转换成字符串。字符串值是一串放在双引号 `"` 中的字符。模板表达式总是以美元符号 `$` 开头。

要在模板表达式中求一段代码的值，请把该代码放在美元符号 `$` 之后的花括号 `{}` 中。

例如：

```kotlin
fun main() {
    val customers = 10
    println("There are $customers customers")
    // There are 10 customers

    println("There are ${customers + 1} customers")
    // There are 11 customers
}
```

更多信息请参阅[字符串模板](../../../languageguide/5.4-Types/5.4.6-Strings/#string-templates)。

你会注意到，这里没有为变量声明任何类型。Kotlin 自己推断出了类型：`Int`。本次导览会在[下一章](../3.2.2-KotlinTourBasicTypes/)讲解 Kotlin 的各种基本类型以及如何声明它们。

fun main() {

}

    val name = "Mary"
    val age = 20
    println("$name is $age years old")
