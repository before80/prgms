# 13.5 Kotlin 发布流程

了解 Kotlin 的各类版本、如何更新到各个版本，以及 Kotlin 的发布历史。

> 最新 Kotlin 版本：**2.4.20** 参见 [Kotlin 2.4.0 的新变化](../../whatsnewinkotlin/4.1-Whatsnew2420/)，并在[更新日志](https://github.com/JetBrains/kotlin/releases/tag/v2.4.20)中查看缺陷修复的详细信息。

本页介绍 Kotlin 的发布周期、我们发布的各类版本，还包含过去和即将发布的 Kotlin 版本详情，以及如何更新到特定版本的说明。

自 Kotlin 2.0.0 起，我们发布以下类型的版本：

* *语言版本*（2._x_._0_），带来语言中的重大变化并包含工具更新。每 6 个月发布一次。
* *工具版本*（2._x_._20_），在语言版本之间发布，包含工具更新、性能改进和缺陷修复。在相应的*语言版本*发布 3 个月后发布。
* *缺陷修复版本*（2._x_._yz_），包含针对*工具版本*的缺陷修复。这类版本没有确切的发布计划。

> **提示：** 例如，对于语言版本 2.2.0，只有一个工具版本 2.2.20 和一个缺陷修复版本 2.2.21。

对于每个语言版本和工具版本，我们还会提供若干个预览（*EAP*）版本，供你在新特性正式发布前试用。更多信息请参阅[参与 Kotlin 早期访问预览](../../earlyaccessprevieweap/14.1-Eap/)。

> **注意：** 如果你想收到新 Kotlin 版本的通知，请订阅 [Kotlin 新闻通讯](https://lp.jetbrains.com/subscribe-to-kotlin-news/)，在 [X 上关注 Kotlin](https://x.com/kotlin)，或在 [Kotlin GitHub 仓库](https://github.com/JetBrains/kotlin)上启用 **Watch | Custom | Releases** 选项。

## 更新到新的 Kotlin 版本 {#update-to-a-new-kotlin-version}

要把你的项目升级到新版本，请在构建系统中更新 Kotlin 版本。

### Gradle {#gradle}

要更新到 Kotlin 2.4.20，请在 `build.gradle(.kts)` 文件中修改 Kotlin Gradle 插件的版本：

**Kotlin**

```kotlin
plugins {
    // 把 `<...>` 替换为适合你的目标环境的插件名称
    kotlin("<...>") version "2.4.20"
    // 例如，如果你的目标环境是 JVM：
    // kotlin("jvm") version "2.4.20"
    // 如果你的目标是 Kotlin Multiplatform：
    // kotlin("multiplatform") version "2.4.20"
}
```

**Groovy**

```groovy
plugins {
    // 把 `<...>` 替换为适合你的目标环境的插件名称
    id 'org.jetbrains.kotlin.<...>' version '2.4.20'
    // 例如，如果你的目标环境是 JVM：
    // id 'org.jetbrains.kotlin.jvm' version '2.4.20'
    // 如果你的目标是 Kotlin Multiplatform：
    // id 'org.jetbrains.kotlin.multiplatform' version '2.4.20'
}
```

如果你有使用较早 Kotlin 版本创建的项目，请检查是否还需要[更新任何 kotlinx 库的版本](../../buildtools/11.1-Gradle/11.1.3-GradleConfigureProject/#set-a-dependency-on-a-kotlinx-library)。

如果你要迁移到新的语言版本，Kotlin 插件的迁移工具会帮助你完成这一过程。

> **提示：** 想进一步了解如何在项目中使用 Gradle，请参阅[配置 Gradle 项目](../../buildtools/11.1-Gradle/11.1.3-GradleConfigureProject/)。

### Maven {#maven}

要更新到 Kotlin 2.4.20，请在 `pom.xml` 文件中修改版本：

```xml
<properties>
    <kotlin.version>2.4.20</kotlin.version>
</properties>
```

或者，你也可以在 `pom.xml` 文件中修改 `kotlin-maven-plugin` 的版本：

```xml
<plugins>
    <plugin>
        <groupId>org.jetbrains.kotlin</groupId>
        <artifactId>kotlin-maven-plugin</artifactId>
        <version>2.4.20</version>
    </plugin>
</plugins>
```

如果你有使用较早 Kotlin 版本创建的项目，请检查是否还需要[更新任何 kotlinx 库的版本](../../buildtools/11.2-Maven/11.2.3-MavenSetDependencies/#dependency-on-a-kotlinx-library)。

> **提示：** 想进一步了解如何在项目中使用 Maven，请参阅 [Maven](../../buildtools/11.2-Maven/11.2.1-Maven/)。

Kotlin 在 [IntelliJ IDEA](https://www.jetbrains.com/idea/download/) 和 [Android Studio](https://developer.android.com/kotlin/get-started) 中开箱即用地获得完整支持。

## 标准库安全支持 {#standard-library-security-support}

从 Kotlin 2.4.0 开始，面向 JVM 的 Kotlin 标准库对每个发布线提供 18 个月的支持窗口。语言版本（2._x_._0_）及其后续工具版本（2._x_._20_）属于同一条发布线（2._x_）。

如果我们发现影响面向 JVM 的 Kotlin 标准库的安全漏洞，我们会同时发布：

* 一个基于该发布线中最新 Kotlin 版本的缺陷修复版本，其中包含该安全修复。
* 为处于活动支持窗口内的每条发布线发布缺陷修复版本。

例如，如果我们发现一个安全漏洞，而最新的 Kotlin 版本是 Kotlin 2.4.20，那么我们只会为 Kotlin 2.4.20 发布缺陷修复版本，而不会为 Kotlin 2.4.0 发布。

下表列出了所有 Kotlin 版本及其支持窗口：

| Kotlin 发布线 | 发布日期 | 支持结束 | 最新版本 |
| --- | --- | --- | --- |
| **2.4** | 2026 年 6 月 3 日 | 2027 年 12 月 3 日 | 2.4.20 |

> **提示：** 我们始终希望了解你发现的任何安全问题。要报告你在 Kotlin 中发现的问题，请直接向我们的[问题跟踪器](https://youtrack.jetbrains.com/newIssue?project=KT&c=Type%20Security%20Problem)发送消息，或给我们发送[电子邮件](mailto:security@jetbrains.org)。
