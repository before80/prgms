# 11.2.5 打包你的 Maven 应用

要用 Maven 打包你的 Kotlin 应用，你可以创建标准的 JAR 文件，也可以创建包含所有依赖的自包含（fat）JAR 文件。打包应用后，你就可以分发它，并在任何装有 Java 运行时环境（JRE）的机器上运行。

## 创建 JAR 文件 {#create-jar-files}

要创建一个仅包含你模块代码的小型 JAR 文件，请在 Maven 的 `pom.xml` 文件中的 `<build><plugins>` 下加入以下内容，其中 `main.class` 被定义为属性并指向 Kotlin 或 Java 的主类：

```xml
<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-jar-plugin</artifactId>
    <version>3.5.0</version>
    <configuration>
        <archive>
            <manifest>
                <addClasspath>true</addClasspath>
                <mainClass>${main.class}</mainClass>
            </manifest>
        </archive>
    </configuration>
</plugin>
```

## 创建自包含的 JAR 文件 {#create-self-contained-jar-files}

要创建一个既包含你模块代码又包含其依赖的自包含 JAR 文件，请在 Maven 的 `pom.xml` 文件中的 `<build><plugins>` 下加入以下内容，其中 `main.class` 被定义为属性并指向 Kotlin 或 Java 的主类：

```xml
<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-assembly-plugin</artifactId>
    <version>3.8.0</version>
    <executions>
        <execution>
            <id>make-assembly</id>
            <phase>package</phase>
            <goals> <goal>single</goal> </goals>
            <configuration>
                <archive>
                    <manifest>
                        <mainClass>${main.class}</mainClass>
                    </manifest>
                </archive>
                <descriptorRefs>
                    <descriptorRef>jar-with-dependencies</descriptorRef>
                </descriptorRefs>
            </configuration>
        </execution>
    </executions>
</plugin>
```

这个自包含的 JAR 文件可以直接交给 JRE 来运行你的应用：

``` bash
java -jar target/mymodule-0.0.1-SNAPSHOT-jar-with-dependencies.jar
```
