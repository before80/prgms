# 11.2.1 Maven

Maven 是一个构建系统，帮助你管理纯 Kotlin 或 Kotlin−Java 混合项目，并自动化构建过程。它适用于基于 JVM 的项目，会下载所需的依赖、编译并打包你的代码。你可以在 [Maven](https://maven.apache.org/) 网站上进一步了解它的基础知识和细节。

使用 Kotlin Maven 项目时的一般工作流程如下：

1. [配置你的 Java 或 Kotlin 项目](../11.2.2-MavenConfigureProject/)。
2. [声明仓库](../11.2.3-MavenSetDependencies/#declare-repositories)。
3. [设置项目依赖](../11.2.3-MavenSetDependencies/)。
4. [配置 Kotlin 编译器](../11.2.4-MavenKotlinCompiler/)。
5. [打包你的应用](../11.2.5-MavenCompilePackage/)。

要快速上手，你也可以跟着我们的分步教程操作：

* [配置 Java 项目以使用 Kotlin](../../../development/6.1-Backenddevelopment/6.1.2-MixingJavaKotlinIntellij/)
* [用 Kotlin 和 JUnit 测试你的 Java Maven 项目](../../../development/6.1-Backenddevelopment/6.1.3-JvmTestUsingJunit/)

> **提示：** 你可以查看我们的公开[示例项目](https://github.com/kotlin-hands-on/kotlin-junit-sample/tree/main/complete)，其中已经为 Kotlin/Java 混合项目配好了 Maven 和 Gradle 构建文件。

## 接下来学什么？ {#what-s-next}

* **改善调试体验**：使用 [`power-assert` 插件](../../../compilerandplugins/12.2-Kotlincompilerplugins/12.2.6-PowerAssert/#maven)。
* **度量测试覆盖率并生成报告**：使用 [`kover-maven-plugin`](https://kotlin.github.io/kotlinx-kover/maven-plugin/)。
* **配置注解处理**：使用 [kapt 插件](../../../compilerandplugins/12.2-Kotlincompilerplugins/12.2.3-Kapt/#set-up-in-maven)。
* **生成文档**：使用 [Dokka 文档引擎](../../../development/6.7-Developmenttooling/6.7.3-Dokka/6.7.3.3-Rundokka/6.7.3.3.5-DokkaMaven/)。它支持混合语言项目，并能以多种格式生成输出，包括标准 Javadoc。
* **启用 OSGi 支持**：添加 [`kotlin-osgi-bundle`](../../../development/6.7-Developmenttooling/6.7.6-KotlinOsgi/#maven)。
