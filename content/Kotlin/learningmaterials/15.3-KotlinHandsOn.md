# 15.3 Kotlin 动手实践

这是一系列动手实践教程，你可以用各种不同的技术、面向多种平台来创建 Kotlin 应用。这些练习被划分为一系列步骤，带你逐步完成每一部分。

## 使用 Spring Boot 和 Kotlin 创建 Web 应用 {#creating-a-web-app-with-spring-boot-and-kotlin}

使用 Spring Boot 和 Kotlin 构建一个带数据库功能的简单应用，并从语法角度了解用 Kotlin 做后端开发的好处。

[开始](../../development/6.1-Backenddevelopment/6.1.7-Createawebappwithkotlinandspringboot/6.1.7.1-JvmGetStartedSpringBoot/)

## 使用 React 和 Kotlin/JS 构建 Web 应用 {#building-web-applications-with-react-and-kotlin-js}

用 Kotlin/JS 创建一个 React 应用，看看如何利用 Kotlin 的类型系统、库生态和互操作特性。

[开始](https://kotlinlang.org/docs/js-react.html)

## 使用 Spring Boot 和 Kotlin 构建 Web 应用 {#building-web-applications-with-spring-boot-and-kotlin}

结合 Spring Boot 和 Kotlin 的强大能力，构建一个简单的博客应用。

[开始](https://spring.io/guides/tutorials/spring-boot-kotlin/)

## 使用 Ktor 创建 HTTP API {#creating-http-apis-with-ktor}

为你的应用创建一个响应 HTTP 请求的后端 API。

[开始](https://ktor.io/docs/creating-http-apis.html)

## 使用 Ktor 创建 WebSocket 聊天 {#creating-a-websocket-chat-with-ktor}

使用 Ktor 创建一个简单的聊天应用，包含 JVM 服务端和 JVM 客户端。

[开始](https://ktor.io/docs/creating-web-socket-chat.html)

## 使用 Ktor 创建交互式网站 {#creating-an-interactive-website-with-ktor}

学习如何使用 Ktor 提供文件服务、使用 Freemarker 和 kotlinx.html DSL 这类模板引擎，以及处理表单输入。

[开始](https://ktor.io/docs/creating-interactive-website.html)

## Kotlin 协程与通道入门 {#introduction-to-kotlin-coroutines-and-channels}

了解 Kotlin 中的协程，以及如何使用通道在它们之间通信。
