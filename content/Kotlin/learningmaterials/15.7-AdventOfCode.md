# 15.7 用地道 Kotlin 风格解答 Advent of Code 谜题

[Advent of Code](https://adventofcode.com/) 是一年一度的十二月活动，从 12 月 1 日到 12 月 25 日每天都会发布一道节日主题的谜题。在 Advent of Code 的创建者 [Eric Wastl](http://was.tl/) 的许可下，我们将展示如何用地道的 Kotlin 风格来解答这些谜题：

* [Advent of Code 2025](https://www.youtube.com/playlist?list=PLlFc5cFwUnmx9-VIcfxqhjHrwD3Lab4o4)

* [Advent of Code 2023](https://www.youtube.com/playlist?list=PLlFc5cFwUnmzk0wvYW4aTl57F2VNkFisU)

我们会带你了解一些基本技巧，帮助你开始用 Kotlin 解答 Advent of Code 挑战：

## Advent of Code 2022 {#advent-of-code-2022}

### 第 1 天：卡路里计数 {#day-1-calorie-counting}

了解 [Kotlin Advent of Code 模板](https://github.com/kotlin-hands-on/advent-of-code-kotlin-template)，以及在 Kotlin 中处理字符串和集合的便捷函数，例如 [`maxOf()`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/max-of.html) 和 [`sumOf()`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/sum-of.html)。看看扩展函数如何帮助你以优雅的方式组织解法。

* 阅读 [Advent of Code](https://adventofcode.com/2022/day/1) 上的谜题描述
* 在视频中查看解法：

![YouTube](./images/youtube.svg) [Advent of Code 2022 Day 1 | Kotlin](https://www.youtube.com/watch?v=ntbsbqLCKDs)

### 第 2 天：石头剪刀布 {#day-2-rock-paper-scissors}

理解 Kotlin 中 `Char` 类型的操作，看看 `Pair` 类型和 `to` 构造器如何与模式匹配很好地配合。了解如何使用 [`compareTo()`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin/-comparable/compare-to.html) 函数为自己的对象排序。

* 阅读 [Advent of Code](https://adventofcode.com/2022/day/2) 上的谜题描述
* 在视频中查看解法：

![YouTube](./images/youtube.svg) [Advent of Code 2022 Day 2 | Kotlin](https://www.youtube.com/watch?v=Fn0SY2yGDSA)

### 第 3 天：背包重新整理 {#day-3-rucksack-reorganization}

了解 [kotlinx.benchmark](https://github.com/Kotlin/kotlinx-benchmark) 库如何帮助你理解代码的性能特征。看看 `intersect` 这样的集合操作如何帮助你筛选出重叠的数据，并比较同一解法不同实现之间的性能。

* 阅读 [Advent of Code](https://adventofcode.com/2022/day/3) 上的谜题描述
* 在视频中查看解法：

![YouTube](./images/youtube.svg) [Advent of Code 2022 Day 3 | Kotlin](https://www.youtube.com/watch?v=IPLfo4zXNjk)

### 第 4 天：营地清理 {#day-4-camp-cleanup}

看看 `infix` 和 `operator` 函数如何让代码更具表现力，以及 `String` 和 `IntRange` 类型的扩展函数如何让输入解析变得简单。

* 阅读 [Advent of Code](https://adventofcode.com/2022/day/4) 上的谜题描述
* 在视频中查看解法：

![YouTube](./images/youtube.svg) [Advent of Code 2022 Day 4 | Kotlin](https://www.youtube.com/watch?v=dBIbr55YS0A)

### 第 5 天：补给堆栈 {#day-5-supply-stacks}

了解如何使用工厂函数构造更复杂的对象、如何使用正则表达式，以及双端队列 [`ArrayDeque`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.collections/-array-deque/) 类型。

* 阅读 [Advent of Code](https://adventofcode.com/2022/day/5) 上的谜题描述
* 在视频中查看解法：

![YouTube](./images/youtube.svg) [Advent of Code 2022 Day 5 | Kotlin](https://www.youtube.com/watch?v=lKq6r5Nt8Yo)

* 阅读 [Advent of Code](https://adventofcode.com/2022/day/6) 上的谜题描述

了解如何为树形结构建模，并观看以编程方式生成 Kotlin 代码的演示。

探索字符串工具函数、正则表达式、集合操作，以及 [`let`](../../libraryguides/9.1-Standardlibrary/9.1.4-ScopeFunctions/#let) 函数如何帮助你转换表达式。

* 在 [Kotlin 博客](https://blog.jetbrains.com/kotlin/2021/09/validating-input-advent-of-code-in-kotlin/)上查看 Sebastian Aigner 的解法，或观看视频：

使用 Kotlin 标准库函数（`replace()`、`toInt()`、`find()`）处理数字的二进制表示，探索强大的局部函数，并了解如何在 Kotlin 1.5 中使用 `max()` 函数。

### 第 6 天：自定义海关 {#day-6-custom-customs}

了解如何使用标准库函数 `map()`、`reduce()`、`sumOf()`、`intersect()` 和 `union()` 对字符串和集合中的字符进行分组和计数。
