# 15.1 学习资料概览

你可以使用以下材料和资源来学习 Kotlin：
* [基本语法](../../languageguide/5.1-Basicsyntax/5.1.1-BasicSyntax/)——快速了解 Kotlin 语法。
* [Kotlin 之旅](../../takekotlintour/3.1-KotlinTourWelcome/)——学习 Kotlin 编程语言的基础知识。
* [惯用法](../../languageguide/5.3-Idioms/)——学习如何为常见场景编写符合 Kotlin 习惯的代码。
* [Java 到 Kotlin 迁移指南：字符串](../../interoperability/7.1-Javainterop/7.1.5-Javatokotlinmigrationguides/7.1.5.1-JavaToKotlinIdiomsStrings/)——学习如何在 Java 和 Kotlin 中完成字符串的常见任务。
* [Java 到 Kotlin 迁移指南：集合](../../interoperability/7.1-Javainterop/7.1.5-Javatokotlinmigrationguides/7.1.5.2-JavaToKotlinCollectionsGuide/)——学习如何在 Java 和 Kotlin 中完成集合的常见任务。
* [Java 到 Kotlin 迁移指南：可空性](../../interoperability/7.1-Javainterop/7.1.5-Javatokotlinmigrationguides/7.1.5.3-JavaToKotlinNullabilityGuide/)——学习如何在 Java 和 Kotlin 中处理可空性。
* [Kotlin Koans](../15.5-Koans/)——通过练习学习 Kotlin 语法。每个练习都是一个失败的单元测试，你的任务就是让它通过。推荐有 Java 经验的开发者使用。
* JetBrains Academy 的 [Kotlin Core 学习路径](https://hyperskill.org/tracks?category=4&utm_source=jbkotlin_hs&utm_medium=referral&utm_campaign=kotlinlang-docs&utm_content=button_1&utm_term=22.03.23)——在一步步创建可运行应用的过程中掌握 Kotlin 的全部要点。
* [Kotlin 图书](../15.6-Books/)——找到我们审阅并推荐的学习 Kotlin 的图书。
* [Kotlin 小技巧](../15.4-KotlinTips/)——观看短视频，Kotlin 团队会在其中展示如何更高效、更符合习惯地使用 Kotlin，让你在写代码时获得更多乐趣。
* [Advent of Code 题目](../15.7-AdventOfCode/)——通过完成短小有趣的题目来学习惯用的 Kotlin 并检验你的语言能力。
* [Kotlin 动手实践教程](../15.3-KotlinHandsOn/)——完成长篇教程以全面掌握某项技术。这些教程会带你完成一个与特定主题相关的自包含项目。
* [面向 Java 开发者的 Kotlin](https://www.coursera.org/learn/kotlin-for-java-developers)——在 Coursera 的这门课程中了解 Java 与 Kotlin 的异同。
* [PDF 格式的 Kotlin 文档](../../otherresources/16.6-KotlinPdf/)——离线阅读我们的文档。
