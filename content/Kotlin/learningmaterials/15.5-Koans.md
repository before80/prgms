# 15.5 Kotlin Koans

Kotlin Koans 是一系列练习，主要面向 Java 开发者，帮助你熟悉 Kotlin 语法。每个练习都是一个失败的单元测试，你的任务就是让它通过。

> **注意：** 你可以在我们的 [GitHub 仓库](https://github.com/Kotlin/kotlin-koans-edu)中查看任务内容。

你可以通过以下方式之一完成 Kotlin Koans 任务：

* 你可以玩[在线版 Koans](https://play.kotlinlang.org/koans)。
* 你也可以在 IntelliJ IDEA 或 Android Studio 内直接完成这些任务：先[安装 JetBrains Academy 插件](https://plugins.jetbrains.com/plugin/10081-jetbrains-academy/docs/install-jetbrains-academy-plugin.html)，然后[选择 Kotlin Koans 课程](https://plugins.jetbrains.com/plugin/10081-jetbrains-academy/docs/learner-start-guide.html?section=Kotlin%20Koans)。

无论你选择哪种方式解决 koans，都可以看到每个任务的解答：
* 在线版本中，点击 **Show answer**。
* 使用 JetBrains Academy 插件时，先尝试完成任务，如果答案不正确，再选择 **Peek solution**。

我们建议你在实现任务之后再查看解答，把自己的答案与建议的答案做比较。请务必不要作弊！
