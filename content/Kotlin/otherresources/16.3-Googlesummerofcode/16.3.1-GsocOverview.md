# 16.3.1 与 Kotlin 一起参与 Google Summer of Code

Kotlin 基金会为 Google Summer of Code（GSoC）提供指导。这是一个全球性的在线项目，旨在引导新的贡献者参与开源开发。

在 [Google Summer of Code 官方网站](https://summerofcode.withgoogle.com/)上进一步了解 GSoC。
