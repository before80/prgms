# 7.1.1 与 Java 的比较

## Kotlin 解决了 Java 的一些问题 {#some-java-issues-addressed-in-kotlin}

Kotlin 修复了 Java 存在的一系列问题：

* 空引用[由类型系统控制](../../../languageguide/5.9-NullSafety/)。
* [没有原始类型](../7.1.2-JavaInterop/#java-generics-in-kotlin)
* Kotlin 中的数组是[不变的](../../../languageguide/5.4-Types/5.4.7-Arrays/)
* Kotlin 有真正的[函数类型](../../../languageguide/5.7-Functions/5.7.2-Lambdas/#function-types)，而不是 Java 的 SAM 转换
* [使用处型变](../../../languageguide/5.11-Generics/#use-site-variance-type-projections)无需通配符
* Kotlin 没有受检[异常](../../../languageguide/5.6-Exceptions/)
* [为只读集合和可变集合提供各自的接口](../../../libraryguides/9.1-Standardlibrary/9.1.1-Collections/9.1.1.1-CollectionsOverview/)

## Java 有而 Kotlin 没有的特性 {#what-java-has-that-kotlin-does-not}

* [受检异常](../../../languageguide/5.6-Exceptions/)
* 不是类的[基本类型](../../../languageguide/5.4-Types/5.4.1-TypesOverview/)。字节码会尽可能使用基本类型，但它们不能显式使用。
* [静态成员](../../../languageguide/5.8-Classesandinterfaces/5.8.1-Classes/)被替换为[伴生对象](../../../languageguide/5.8-Classesandinterfaces/5.8.7-ObjectDeclarations/#companion-objects)、[顶层函数](../../../languageguide/5.7-Functions/5.7.1-Functions/)、[扩展函数](../../../languageguide/5.8-Classesandinterfaces/5.8.3-Extensions/#extension-functions)或 [@JvmStatic](../7.1.3-JavaToKotlinInterop/#static-methods)。
* [通配符类型](../../../languageguide/5.11-Generics/)被替换为[声明处型变](../../../languageguide/5.11-Generics/#declaration-site-variance)和[类型投影](../../../languageguide/5.11-Generics/#type-projections)。
* [三元运算符 `a ? b : c`](../../../languageguide/5.5-Controlflow/5.5.1-ControlFlow/#if-expression)被替换为 [if 表达式](../../../languageguide/5.5-Controlflow/5.5.1-ControlFlow/#if-expression)。
* [记录类型（Records）](https://openjdk.org/jeps/395)
* 包级私有的[可见性修饰符](../../../languageguide/5.1-Basicsyntax/5.1.5-VisibilityModifiers/)

> **注意：** Kotlin 没有模式匹配，但 [Kotlin 中的智能转换](../../../languageguide/5.4-Types/5.4.8-Typecasts/#smart-casts)提供了与 [Java 中的模式匹配](https://openjdk.org/projects/amber/design-notes/patterns/pattern-matching-for-java)类似的功能。可以在[官方的 Kotlin by JetBrains 频道视频](https://www.youtube.com/watch?v=yJDoa42X-wQ)中了解更多。

* [Lambda 表达式](../../../languageguide/5.7-Functions/5.7.2-Lambdas/) + [内联函数](../../../languageguide/5.7-Functions/5.7.5-InlineFunctions/) = 高性能的自定义控制结构

* [第一类委托](../../../languageguide/5.8-Classesandinterfaces/5.8.5-Delegation/)
* [变量和属性类型的类型推断](../../../languageguide/5.4-Types/5.4.1-TypesOverview/)（**Java 10**：[局部变量类型推断](https://openjdk.org/jeps/286)）
* [单例](../../../languageguide/5.8-Classesandinterfaces/5.8.7-ObjectDeclarations/)
* [声明处型变与类型投影](../../../languageguide/5.11-Generics/)
* [区间表达式](../../../libraryguides/9.1-Standardlibrary/9.1.1-Collections/9.1.1.11-Ranges/)

* [伴生对象](../../../languageguide/5.8-Classesandinterfaces/5.8.1-Classes/#companion-objects)

* [中缀函数](../../../languageguide/5.7-Functions/5.7.1-Functions/#infix-notation)
* [expect 与 actual 声明](https://kotlinlang.org/docs/multiplatform/multiplatform-expect-actual.html)
