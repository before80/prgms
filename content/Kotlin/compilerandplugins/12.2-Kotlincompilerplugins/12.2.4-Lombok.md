# 12.2.4 Lombok 编译器插件

**Alpha**

Kotlin Lombok 编译器插件允许 Kotlin 代码在同一个 Java/Kotlin 混合模块中生成并使用 Java 的 Lombok 声明。如果你从另一个模块调用这类声明，那么编译那个模块时不需要使用该插件。

Lombok 编译器插件不能替代 [Lombok](https://projectlombok.org/)，但它能让 Lombok 在 Java/Kotlin 混合模块中工作。因此，使用该插件时你仍然需要像往常一样配置 Lombok。进一步了解[如何配置 Lombok 编译器插件](#using-the-lombok-configuration-file)。

## 支持的注解 {#supported-annotations}

该插件支持以下注解：
* `@Getter`、`@Setter`
* `@Builder`、`@SuperBuilder`
* `@NoArgsConstructor`、`@RequiredArgsConstructor` 和 `@AllArgsConstructor`
* `@Data`
* `@With`
* `@Value`

我们仍在继续开发该插件。要了解当前的详细状态，请访问 [Lombok 编译器插件的 README](https://github.com/JetBrains/kotlin/tree/master/plugins/lombok)。

目前我们没有支持 `@Tolerate` 注解的计划。不过，如果你在 YouTrack 上为 [@Tolerate issue](https://youtrack.jetbrains.com/issue/KT-53564/Kotlin-Lombok-Support-Tolerate) 投票，我们会考虑它。

> **注意：** 如果你在 Kotlin 代码中使用 Lombok 注解，Kotlin 编译器会忽略它们。

## Gradle {#gradle}

在 `build.gradle(.kts)` 文件中应用 `kotlin-plugin-lombok` Gradle 插件：

**Kotlin**

```kotlin
plugins {
    kotlin("plugin.lombok") version "2.4.20"
    id("io.freefair.lombok") version "9.5.0"
}
```

**Groovy**

```groovy
plugins {
    id 'org.jetbrains.kotlin.plugin.lombok' version '2.4.20'
    id 'io.freefair.lombok' version '9.5.0'
}
```

请参阅这个[使用 Lombok 编译器插件的示例测试项目](https://github.com/kotlin-hands-on/kotlin-lombok-examples/tree/master/kotlin_lombok_gradle/nokapt)。

### 使用 Lombok 配置文件 {#using-the-lombok-configuration-file}

如果你使用 [Lombok 配置文件](https://projectlombok.org/features/configuration)`lombok.config`，则需要设置该文件的路径，以便插件能够找到它。该路径必须相对于模块目录。例如，在 `build.gradle(.kts)` 文件中添加以下代码：

**Kotlin**

```kotlin
kotlinLombok {
    lombokConfigurationFile(file("lombok.config"))
}
```

**Groovy**

```groovy
kotlinLombok {
    lombokConfigurationFile file("lombok.config")
}
```

请参阅这个[使用 Lombok 编译器插件和 `lombok.config` 的示例测试项目](https://github.com/kotlin-hands-on/kotlin-lombok-examples/tree/master/kotlin_lombok_gradle/withconfig)。

## Maven {#maven}

要使用 Lombok 编译器插件，请把 `lombok` 插件添加到 `compilerPlugins` 部分，并把 `kotlin-maven-lombok` 依赖添加到 `dependencies` 部分。如果你使用 [Lombok 配置文件](https://projectlombok.org/features/configuration)`lombok.config`，请在 `pluginOptions` 中向插件提供它的路径。把以下几行添加到 `pom.xml` 文件中：

```xml
<plugin>
    <groupId>org.jetbrains.kotlin</groupId>
    <artifactId>kotlin-maven-plugin</artifactId>
    <version>${kotlin.version}</version>
    <configuration>
        <compilerPlugins>
            <plugin>lombok</plugin>
        </compilerPlugins>
        <pluginOptions>
            <option>lombok:config=${project.basedir}/lombok.config</option>
        </pluginOptions>
    </configuration>
    <dependencies>
        <dependency>
            <groupId>org.jetbrains.kotlin</groupId>
            <artifactId>kotlin-maven-lombok</artifactId>
            <version>${kotlin.version}</version>
        </dependency>
        <dependency>
            <groupId>org.projectlombok</groupId>
            <artifactId>lombok</artifactId>
            <version>1.18.20</version>
            <scope>provided</scope>
        </dependency>
    </dependencies>
</plugin>
```

请参阅这个[使用 Lombok 编译器插件和 `lombok.config` 的示例测试项目](https://github.com/kotlin-hands-on/kotlin-lombok-examples/tree/master/kotlin_lombok_maven/nokapt)。

## 与 kapt 一起使用 {#using-with-kapt}

默认情况下，[kapt](../12.2.3-Kapt/) 编译器插件会运行所有注解处理器，并禁用 javac 的注解处理。要让 [Lombok](https://projectlombok.org/) 与 kapt 一起运行，请配置 kapt 以保持 javac 的注解处理器正常工作。

如果你使用 Gradle，请在 `build.gradle(.kts)` 文件中添加该选项：

```groovy
kapt {
    keepJavacAnnotationProcessors = true
}
```

在 Maven 中，请使用以下设置让 Lombok 与 Java 编译器一起启动：

```xml
<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-compiler-plugin</artifactId>
    <version>3.5.1</version>
    <configuration>
        <source>1.8</source>
        <target>1.8</target>
        <annotationProcessorPaths>
            <annotationProcessorPath>
                <groupId>org.projectlombok</groupId>
                <artifactId>lombok</artifactId>
                <version>${lombok.version}</version>
            </annotationProcessorPath>
        </annotationProcessorPaths>
    </configuration>
</plugin>
```

如果注解处理器不依赖 Lombok 生成的代码，Lombok 编译器插件可以与 [kapt](../12.2.3-Kapt/) 正确配合工作。

浏览这些使用 kapt 和 Lombok 编译器插件的示例测试项目：
* 使用 [Gradle](https://github.com/JetBrains/kotlin/tree/master/libraries/tools/kotlin-gradle-plugin-integration-tests/src/test/resources/testProject/lombokProject/yeskapt)。
* 使用 [Maven](https://github.com/kotlin-hands-on/kotlin-lombok-examples/tree/master/kotlin_lombok_maven/yeskapt)

## 命令行编译器 {#command-line-compiler}

Lombok 编译器插件的 JAR 包含在 Kotlin 编译器的二进制发行版中。你可以通过 `Xplugin` kotlinc 选项提供其 JAR 文件的路径来挂载该插件：

```bash
-Xplugin=$KOTLIN_HOME/lib/lombok-compiler-plugin.jar
```

如果你想使用 `lombok.config` 文件，请把 `<PATH_TO_CONFIG_FILE>` 替换为你的 `lombok.config` 的路径：

```bash
# The plugin option format is: "-P plugin:<plugin id>:<key>=<value>".
# Options can be repeated.

-P plugin:org.jetbrains.kotlin.lombok:config=<PATH_TO_CONFIG_FILE>
```
