# 6.7.2 Kotlin Language Server

**Alpha**

Kotlin Language Server 是 JetBrains 官方的 Kotlin LSP 实现，支持 VS Code，并提供代码补全、诊断、格式化和重构。

[Kotlin Language Server](https://github.com/Kotlin/kotlin-lsp) 是 JetBrains 对 Kotlin 的[语言服务器协议（LSP）](https://microsoft.github.io/language-server-protocol/)官方实现。

该服务器基于 IntelliJ IDEA、IntelliJ IDEA Kotlin 插件、JetBrains AIR 和 Fleet。它的设计目标是与任何支持 LSP 的代码编辑器配合使用。

> **注意：** [IntelliJ IDEA](https://www.jetbrains.com/idea/) 和 [Android Studio](https://developer.android.com/studio) 提供最佳的 Kotlin 开发体验。

## 在 Visual Studio Code 中使用 Kotlin {#kotlin-in-visual-studio-code}

Kotlin Language Server 为 [Visual Studio Code](https://code.visualstudio.com/) 提供官方的 Kotlin 语言支持。

如果你使用 Visual Studio Code 进行 Kotlin 开发，请从 Visual Studio Marketplace 安装官方的 [Kotlin by JetBrains](https://marketplace.visualstudio.com/items?itemName=JetBrains.kotlin-server) 扩展。

对于兼容 VS Code 的编辑器（例如 Cursor 或 VSCodium），请从 [Open VSX Registry](https://open-vsx.org/extension/JetBrains/kotlin-server) 安装该扩展。

要激活 **Kotlin by JetBrains** 扩展，请在 Visual Studio Code 中打开一个 Kotlin 项目，然后打开任意 Kotlin 文件。

## 支持的特性 {#supported-features}

Kotlin Language Server 包含以下核心语言特性：

* 支持最新的 Kotlin 语言版本
* 由 IntelliJ 驱动的代码补全
* 由 IntelliJ 驱动的、针对 Kotlin 和 `kotlinx.*` 库的诊断与快速修复
* 对 JVM 项目的构建系统支持：Gradle、Maven，以及对 Android Gradle 插件的实验性支持

> 对 Kotlin Multiplatform 项目的支持正在开发中。

* 语义高亮
* 整理导入
* 重命名重构
* 代码格式化
* 文档导航与悬停提示支持
* 调用层级
* 代码折叠
