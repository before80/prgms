# 6.7.1 用于 Kotlin 开发的 IDE

JetBrains 为 IntelliJ IDEA、Android Studio 和 Visual Studio Code 提供官方的 Kotlin IDE 支持。

JetBrains 为以下 IDE 和代码编辑器提供官方 Kotlin 支持：[IntelliJ IDEA](#intellij-idea) 和 [Android Studio](#android-studio)。你还可以为 [Visual Studio Code](#visual-studio-code) 安装官方的 Kotlin by JetBrains 扩展，它目前处于 [Alpha](../../../kotlinevolutionandroadmap/13.4-ComponentsStability/#stability-levels-explained) 阶段。

其他 IDE 和代码编辑器只有社区支持的 Kotlin 插件。

## IntelliJ IDEA {#intellij-idea}

[IntelliJ IDEA](https://www.jetbrains.com/idea/download/) 是一款为 Kotlin、Java 等 JVM 语言设计的 IDE，旨在最大化开发者的生产力。它通过智能代码补全、静态代码分析和重构替你完成例行、重复的工作。它让你专注于软件开发中美好的一面，不仅高效，而且令人愉快。

Kotlin 插件随每个 IntelliJ IDEA 版本一同提供。每个 IDEA 版本都会带来新的特性和升级，改善 IDE 中 Kotlin 开发者的体验。关于 Kotlin 的最新更新和改进，请参阅 [IntelliJ IDEA 新特性](https://www.jetbrains.com/idea/whatsnew/)。

关于 IntelliJ IDEA 的更多内容，请阅读[官方文档](https://www.jetbrains.com/help/idea/discover-intellij-idea.html)。

## Android Studio {#android-studio}

[Android Studio](https://developer.android.com/studio) 是用于 Android 应用开发的官方 IDE，基于 [IntelliJ IDEA](https://www.jetbrains.com/idea/)。在 IntelliJ 强大的代码编辑器和开发者工具之上，Android Studio 还提供了更多功能，帮助你在构建 Android 应用时提高生产力。

Kotlin 插件随每个 Android Studio 版本一同提供。

关于 Android Studio 的更多内容，请阅读[官方文档](https://developer.android.com/studio/intro)。

## Visual Studio Code {#visual-studio-code}
**Alpha**

[Visual Studio Code](https://code.visualstudio.com/) 是一款拥有大量扩展的代码编辑器，其中包括[官方的 Kotlin by JetBrains 扩展](https://marketplace.visualstudio.com/items?itemName=JetBrains.kotlin-server)。

Kotlin 扩展通过 Kotlin Language Server 提供代码补全、导航、调试以及其他 Kotlin 开发功能。

更多信息请参阅 [Kotlin Language Server 与 Visual Studio Code](../6.7.2-KotlinLsp/#kotlin-in-visual-studio-code)。

## 其他 IDE 的支持 {#other-ides-support}

JetBrains 不为其他 IDE 提供官方 Kotlin 插件。你可以在其他代码编辑器中使用 [Kotlin Language Server](../6.7.2-KotlinLsp/)。

要在没有 IDE 相关功能（例如代码格式化、调试工具、重构）的文本编辑器中使用 Kotlin，你可以从 Kotlin 的 [GitHub Releases](https://github.com/JetBrains/kotlin/releases/tag/v2.4.20) 下载最新的 Kotlin 命令行编译器（`kotlin-compiler-2.4.20.zip`）并[手动安装](../../../compilerandplugins/12.1-Kotlincompiler/12.1.2-CommandLine/#manual-install)。此外，你也可以使用包管理器，例如 [Homebrew](../../../compilerandplugins/12.1-Kotlincompiler/12.1.2-CommandLine/#homebrew)、[SDKMAN!](../../../compilerandplugins/12.1-Kotlincompiler/12.1.2-CommandLine/#sdkman) 和 [Snap 包](../../../compilerandplugins/12.1-Kotlincompiler/12.1.2-CommandLine/#snap-package)。

## 与 Kotlin 语言版本的兼容性 {#compatibility-with-the-kotlin-language-versions}

对于 IntelliJ IDEA 和 Android Studio，Kotlin 插件随每个版本一同提供。当新的 Kotlin 版本发布时，这些工具会自动建议把 Kotlin 更新到最新版本。最新支持的语言版本见 [Kotlin 版本发布](../../../kotlinevolutionandroadmap/13.5-Releases/#ide-support)。
