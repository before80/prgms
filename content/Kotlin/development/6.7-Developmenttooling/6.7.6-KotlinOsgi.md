# 6.7.6 Kotlin 与 OSGi

要在你的 Kotlin 项目中启用 Kotlin 的 [OSGi](https://www.osgi.org/) 支持，请引入 `kotlin-osgi-bundle` 而不是常规的 Kotlin 库。建议移除 `kotlin-runtime`、`kotlin-stdlib` 和 `kotlin-reflect` 依赖，因为 `kotlin-osgi-bundle` 已经包含了它们。在包含外部 Kotlin 库时你也应当注意。大多数常规 Kotlin 依赖并非 OSGi 就绪，因此不应使用它们，并应把它们从项目中移除。

## Maven {#maven}

要把 Kotlin OSGi bundle 引入 Maven 项目：

```xml
<dependencies>
    <dependency>
        <groupId>org.jetbrains.kotlin</groupId>
        <artifactId>kotlin-osgi-bundle</artifactId>
        <version>${kotlin.version}</version>
    </dependency>
</dependencies>
```

要把标准库从外部库中排除（注意"星号排除"只在 Maven 3 中有效）：

```xml
<dependency>
    <groupId>some.group.id</groupId>
    <artifactId>some.library</artifactId>
    <version>some.library.version</version>

    <exclusions>
        <exclusion>
            <groupId>org.jetbrains.kotlin</groupId>
            <artifactId>*</artifactId>
        </exclusion>
    </exclusions>
</dependency>
```

## Gradle {#gradle}

要把 `kotlin-osgi-bundle` 引入 Gradle 项目：

**Kotlin**

```kotlin
dependencies {
    implementation(kotlin("osgi-bundle"))
}
```

**Groovy**

```groovy
dependencies {
    implementation "org.jetbrains.kotlin:kotlin-osgi-bundle:2.4.20"
}
```

要排除作为传递依赖引入的默认 Kotlin 库，可以使用以下方式：

**Kotlin**

```kotlin
dependencies {
    implementation("some.group.id:some.library:someversion") {
        exclude(group = "org.jetbrains.kotlin")
    }
}
```

**Groovy**

```groovy
dependencies {
    implementation('some.group.id:some.library:someversion') {
        exclude group: 'org.jetbrains.kotlin'
    }
}
```

## 常见问题 {#faq}

### 为什么不直接给所有 Kotlin 库添加所需的 manifest 选项 {#why-not-just-add-required-manifest-options-to-all-kotlin-libraries}

尽管这是提供 OSGi 支持最可取的方式，但遗憾的是目前无法这样做，原因是所谓的["包拆分"问题](https://docs.osgi.org/specification/osgi.core/7.0.0/framework.module.html#d0e5999)难以简单消除，而如此大的改动目前也不在计划之列。虽然有 `Require-Bundle` 特性，但它也不是最佳选择，并且不建议使用。因此决定为 OSGi 单独制作一个构件。
