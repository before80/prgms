# 6.3.11 Kotlin/Native 二进制文件的许可证文件

与许多其他开源项目一样，Kotlin 依赖第三方代码，也就是说 Kotlin 项目包含一些并非由 JetBrains 或 Kotlin 编程语言贡献者开发的代码。有时它是衍生作品，例如从 C++ 改写成 Kotlin 的代码。

> **注意：** 你可以在我们的 GitHub 仓库中找到 Kotlin 所用第三方作品的许可证：* [Kotlin 编译器](https://github.com/JetBrains/kotlin/tree/master/license/third_party) * [Kotlin/Native](https://github.com/JetBrains/kotlin/tree/master/kotlin-native/licenses/third_party)

特别是，Kotlin/Native 编译器生成的二进制文件可能包含第三方代码、数据或衍生作品。这意味着由 Kotlin/Native 编译的二进制文件须遵守第三方许可证的条款和条件。

在实践中，如果你分发由 Kotlin/Native 编译的[最终二进制文件](https://kotlinlang.org/docs/multiplatform/multiplatform-build-native-binaries.html)，就应当始终在二进制分发中包含必要的许可证文件。这些文件应当以可读的形式，方便你的分发包用户查阅。

请始终为相应项目包含以下许可证文件：

| 项目 | 需要包含的文件 |
| --- | --- |
| [Kotlin](https://kotlinlang.org/) |              [Apache License 2.0](https://github.com/JetBrains/kotlin/blob/master/license/LICENSE.txt)             [Apache Harmony 版权声明](https://github.com/JetBrains/kotlin/blob/master/kotlin-native/licenses/third_party/harmony_NOTICE.txt)           |
| [Apache Harmony](https://harmony.apache.org/) |  |
| [GWT](https://www.gwtproject.org/) |  |
| [Guava](https://guava.dev) |  |
| [libbacktrace](https://github.com/ianlancetaylor/libbacktrace) | [带版权声明的 3 条款 BSD 许可证](https://github.com/JetBrains/kotlin/blob/master/kotlin-native/licenses/third_party/libbacktrace_LICENSE.txt) |
| [mimalloc](https://github.com/microsoft/mimalloc) | [MIT 许可证](https://github.com/JetBrains/kotlin/blob/master/kotlin-native/licenses/third_party/mimalloc_LICENSE.txt)           如果你使用 mimalloc 内存分配器而不是默认分配器（即设置了 `-Xallocator=mimalloc` 编译器选项），请一并包含。 |
| [Unicode 字符数据库](https://www.unicode.org/) | [Unicode 许可证](https://github.com/JetBrains/kotlin/blob/master/kotlin-native/licenses/third_party/unicode_LICENSE.txt) |
| 多生产者/多消费者有界队列 | [版权声明](https://github.com/JetBrains/kotlin/blob/master/kotlin-native/licenses/third_party/mpmc_queue_LICENSE.txt) |

`mingwX64` 目标需要额外的许可证文件：

| 项目                                                               | 需要包含的文件                                                                                                                                                                                                                                                                                                              |

| [MinGW-w64 头文件与运行时库](https://www.mingw-w64.org/) | [MinGW-w64 运行时许可证](https://sourceforge.net/p/mingw-w64/mingw-w64/ci/master/tree/COPYING.MinGW-w64-runtime/COPYING.MinGW-w64-runtime.txt)[Winpthreads 许可证](https://sourceforge.net/p/mingw-w64/mingw-w64/ci/master/tree/mingw-w64-libraries/winpthreads/COPYING) |

> **注意：** 这些库都不要求分发的 Kotlin/Native 二进制文件开源。
