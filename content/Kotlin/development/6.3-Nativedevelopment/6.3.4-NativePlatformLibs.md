# 6.3.4 平台库

为提供对操作系统原生服务的访问，Kotlin/Native 发行版包含一组针对每个目标的预构建库。它们被称为*平台库*。

平台库中的包默认可用。你不需要为使用它们指定额外的链接选项。Kotlin/Native 编译器会自动检测访问了哪些平台库，并链接必要的库。

不过，编译器发行版中的平台库只是对原生库的封装和绑定。这意味着你需要在本地机器上安装原生库本身（`.so`、`.a`、`.dylib`、`.dll` 等）。

## POSIX 绑定 {#posix-bindings}

Kotlin 为所有基于 UNIX 和 Windows 的目标（包括 Android 和 iOS）提供 POSIX 平台库。这些平台库包含对遵循 [POSIX 标准](https://en.wikipedia.org/wiki/POSIX)的平台实现的绑定。

要使用该库，请把它导入你的项目：

```kotlin
import platform.posix.*
```

> **注意：** 由于 POSIX 实现存在差异，`platform.posix` 的内容在不同平台上有所不同。

你可以在这里查看每个受支持平台的 `posix.def` 文件内容：

* [iOS](https://github.com/JetBrains/kotlin/tree/master/kotlin-native/platformLibs/src/platform/ios/posix.def)
* [macOS](https://github.com/JetBrains/kotlin/tree/master/kotlin-native/platformLibs/src/platform/osx/posix.def)
* [tvOS](https://github.com/JetBrains/kotlin/tree/master/kotlin-native/platformLibs/src/platform/tvos/posix.def)
* [watchOS](https://github.com/JetBrains/kotlin/tree/master/kotlin-native/platformLibs/src/platform/watchos/posix.def)
* [Linux](https://github.com/JetBrains/kotlin/tree/master/kotlin-native/platformLibs/src/platform/linux/posix.def)
* [Windows (MinGW)](https://github.com/JetBrains/kotlin/tree/master/kotlin-native/platformLibs/src/platform/mingw/posix.def)
* [Android](https://github.com/JetBrains/kotlin/tree/master/kotlin-native/platformLibs/src/platform/android/posix.def)

POSIX 平台库不适用于 [WebAssembly](../../6.2-Webdevelopment/6.2.3-Webassemblywasm/6.2.3.1-WasmOverview/) 目标。

## 常用原生库 {#popular-native-libraries}

Kotlin/Native 为各种在不同平台上常用的流行原生库提供绑定，例如 OpenGL、zlib 和 Foundation。

在 Apple 平台上，还包含 `objc` 库，以启用[与 Objective-C 的互操作](../../../interoperability/7.3-Swiftobjectivecandcinterop/7.3.1-Swiftobjectivecinterop/7.3.1.1-NativeObjcInterop/) API。

根据你的安装方式，你可以在编译器发行版中浏览 Kotlin/Native 目标可用的原生库：

* 如果你[安装了独立的 Kotlin/Native 编译器](../6.3.2-NativeGetStarted/#download-and-install-the-compiler)：

1. 打开解压后的编译器发行版归档，例如 `kotlin-native-prebuilt-macos-aarch64-2.1.0`。
2. 进入 `klib/platform` 目录。
3. 选择对应目标的文件夹。

* 如果你在 IDE 中使用 Kotlin 插件（随 IntelliJ IDEA 和 Android Studio 一同提供）：

1. 在命令行工具中运行以下命令，进入 `.konan` 文件夹：

**macOS 和 Linux**

```none
     ~/.konan/
```

**Windows**

```none
     %\USERPROFILE%\.konan
```

2. 打开 Kotlin/Native 编译器发行版，例如 `kotlin-native-prebuilt-macos-aarch64-2.1.0`。
3. 进入 `klib/platform` 目录。
4. 选择对应目标的文件夹。

> **提示：** 如果你想查看每个受支持平台库的定义文件：在编译器发行版文件夹中进入 `konan/platformDef` 目录，并选择所需的目标。
