# 6.4 用于 Android 的 Kotlin

自 2019 年 Google I/O 以来，Android 移动开发就一直[以 Kotlin 为先](https://developer.android.com/kotlin/first)。

超过 50% 的专业 Android 开发者以 Kotlin 作为主要语言，而只有 30% 把 Java 作为主要语言。在以 Kotlin 为主要语言的开发者中，70% 表示 Kotlin 让他们更高效。

使用 Kotlin 进行 Android 开发，你可以获得以下好处：

* **更少的代码，更高的可读性**。花更少的时间编写代码和理解他人的代码。
* **更少的常见错误**。根据 [Google 的内部数据](https://medium.com/androiddevelopers/fewer-crashes-and-more-stability-with-kotlin-b606c6a6ac04)，用 Kotlin 构建的应用崩溃的可能性低 20%。
* **Jetpack 库对 Kotlin 的支持**。[Jetpack Compose](https://developer.android.com/jetpack/compose) 是 Android 推荐的、用于在 Kotlin 中构建原生 UI 的现代工具包。[KTX 扩展](https://developer.android.com/kotlin/ktx)把协程、扩展函数、lambda 和命名参数等 Kotlin 语言特性带到了现有的 Android 库中。
* **支持多平台开发**。Kotlin Multiplatform 不仅支持开发 Android 应用，还支持 [iOS](https://kotlinlang.org/multiplatform/)、后端和 Web 应用。[一些 Jetpack 库](https://developer.android.com/kotlin/multiplatform)已经是多平台的。基于 Kotlin 和 Jetpack Compose 的 JetBrains 声明式 UI 框架 [Compose Multiplatform](https://www.jetbrains.com/lp/compose-multiplatform/)，让跨平台共享 UI 成为可能——包括 iOS、Android、桌面和 Web。
* **成熟的语言与环境**。自 2011 年诞生以来，Kotlin 一直在持续发展，不仅作为一门语言，也作为一个拥有强大工具链的完整生态。如今它已无缝集成到 [Android Studio](https://developer.android.com/studio) 中，并被许多公司积极用于开发 Android 应用。
* **与 Java 互操作**。你可以在应用中同时使用 Kotlin 和 Java 编程语言，而无需把所有代码都迁移到 Kotlin。
* **易于学习**。Kotlin 非常容易学习，对 Java 开发者尤其如此。
* **庞大的社区**。Kotlin 拥有社区的大力支持和大量贡献，这个社区正在全球范围内不断壮大。排名前一千的 Android 应用中有超过 95% 使用了 Kotlin。

许多初创公司和《财富》500 强公司已经用 Kotlin 开发了 Android 应用，你可以在 [Google 的 Android 开发者网站](https://developer.android.com/kotlin/stories)上查看名单。

要开始把 Kotlin 用于：

* Android 开发，请阅读 [Google 关于用 Kotlin 开发 Android 应用的文档](https://developer.android.com/kotlin/get-started)。
* 开发跨平台移动应用，请参阅[创建带共享逻辑和原生 UI 的应用](https://kotlinlang.org/docs/multiplatform/multiplatform-create-first-app.html)。
