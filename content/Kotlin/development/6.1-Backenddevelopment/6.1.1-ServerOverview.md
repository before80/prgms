# 6.1.1 使用 Kotlin 进行后端开发

使用 Spring、Ktor 以及其他后端框架，用 Kotlin 构建服务器应用

Kotlin 非常适合开发服务器端应用。使用 Kotlin，你可以编写简洁而富有表现力的代码，同时与现有的基于 Java 的技术栈保持完全兼容。

## 快速上手 {#get-started}

Kotlin 支持把大型代码库从 Java 逐步迁移到 Kotlin。你可以先用 Kotlin 编写测试或新的生产代码，同时让项目的其他部分继续使用 Java。

配置你的 Java 项目以兼容 Kotlin，并利用 IntelliJ IDEA 中内置的 Java 到 Kotlin 自动转换器：

[在你的 Java 项目中引入 Kotlin](../6.1.2-MixingJavaKotlinIntellij/)

## 探索框架 {#explore-frameworks}

Kotlin 与所有基于 Java 的框架完全兼容，因此你可以在享受 Kotlin 语法优势的同时继续使用熟悉的技术栈。除了出色的 IDE 支持外，Kotlin 还提供针对特定框架的工具支持，例如在 IntelliJ IDEA 中（需要 Ultimate 订阅）对 Spring 和 Ktor 的支持。

### Spring {#spring}

[Spring](https://spring.io) 利用 Kotlin 的语言特性提供了更简洁的 API。[在线项目生成器](https://start.spring.io/#!language=kotlin)让你可以快速生成一个 Kotlin 项目。

[开始使用 Spring Boot 与 Kotlin](../6.1.7-Createawebappwithkotlinandspringboot/6.1.7.1-JvmGetStartedSpringBoot/)

### Ktor {#ktor}

[Ktor](https://github.com/kotlin/ktor) 是 JetBrains 推出的、用于在 Kotlin 中创建 Web 应用的框架。它使用协程以获得高可扩展性，并提供易于使用的惯用 API。

[创建一个新的 Ktor 项目](https://ktor.io/docs/server-create-a-new-project.html)

### 其他框架 {#other-frameworks}

下面是一些其他可用于 Kotlin 的后端框架：

| 框架                                              | 说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

| [Quarkus](https://quarkus.io/guides/kotlin)            | 一个为 Kotlin 提供一流支持的开源框架。Quarkus 从一开始就是为 Kubernetes 打造的，并通过不断增长的数百个优秀库提供一体的全栈框架。                                                                                                                                                                                                                                                   |
| [Vert.x](https://vertx.io)                             | 一个用于在 JVM 上构建响应式 Web 应用的框架。Vert.x 为 Kotlin 提供[专门支持](https://github.com/vert-x3/vertx-lang-kotlin)，包括[集成 Kotlin 协程](https://vertx.io/docs/vertx-lang-kotlin-coroutines/kotlin/)。                                                                                                                                                                                            |
| [kotlinx.html](https://github.com/kotlin/kotlinx.html) | 一个可用于在 Web 应用中构建 HTML 的 DSL。它可以作为 JSP、FreeMarker 等传统模板系统的替代方案。                                                                                                                                                                                                                                                                                                                                             |
| [Micronaut](https://micronaut.io/)                     | 一个基于 JVM 的现代全栈框架，用于构建模块化、易于测试的微服务和无服务器应用。可以观看网络研讨会 [Micronaut for microservices with Kotlin](https://micronaut.io/2020/12/03/webinar-micronaut-for-microservices-with-kotlin/)，并浏览一份详细的[指南](https://guides.micronaut.io/latest/micronaut-kotlin-extension-fns.html)，了解如何在 Micronaut 框架中使用 [Kotlin 扩展函数](../../../languageguide/5.8-Classesandinterfaces/5.8.3-Extensions/#extension-functions)。 |
| [http4k](https://http4k.org/)                          | 一个用纯 Kotlin 编写、体积小巧的 Kotlin HTTP 应用函数式工具包。http4k 提供了[支持 CLI 的工具箱](https://toolbox.http4k.org)来生成完整的项目模板，以及基于 Web 的[项目向导](https://toolbox.http4k.org/project)，用于按所选后端、模块和构建工具快速搭建可运行的 http4k 应用。                                                                                                           |
| [Javalin](https://javalin.io)                          | 一个非常轻量的 Kotlin 和 Java Web 框架，支持 WebSockets、HTTP2 和异步请求。                                                                                                                                                                                                                                                                                                                                                      |

## 部署你的应用 {#deploy-your-applications}

Kotlin 应用可以部署到任何支持 Java Web 应用的主机上，包括 Amazon Web Services (AWS)、Google Cloud Platform (GCP) 以及许多其他平台。

* **AWS** 提供了专门的 [Kotlin SDK](https://docs.aws.amazon.com/sdk-for-kotlin/latest/developer-guide/home.html) 来与它的服务交互。对于无服务器部署，可以参考 [AWS Lambda 的 Kotlin 代码示例](https://docs.aws.amazon.com/sdk-for-kotlin/latest/developer-guide/kotlin_lambda_code_examples.html)。
* **Ktor** 允许你把 Kotlin 应用发布到各种云服务商。例如，你可以按照 Ktor 教程了解如何部署到 [Google App Engine](https://ktor.io/docs/google-app-engine.html) 及其他服务。
* **Spring** 应用也与大多数流行的云服务商兼容。关于如何把 Spring Boot 应用部署到云端，请参阅 [Spring 官方文档](https://docs.spring.io/spring-boot/how-to/deployment/cloud.html)。
