# 5.4.1 类型概览

在 Kotlin 中，一切都可以看作对象：你可以在任何变量上调用成员函数和属性。虽然某些类型在运行期有优化过的内部表示（例如数值、字符和布尔值），但对你来说它们看起来和行为上都像普通类。

本节介绍 Kotlin 中使用的基本类型：

* [数值](../5.4.2-Numbers/)及其[无符号对应类型](../5.4.3-UnsignedIntegerTypes/)
* [布尔值](../5.4.4-Booleans/)
* [字符](../5.4.5-Characters/)
* [字符串](../5.4.6-Strings/)
* [数组](../5.4.7-Arrays/)

要了解 Kotlin 的其他类型（例如 `Nothing`、`Any` 和 `Unit`），请查阅 Kotlin API 参考：

* [`Any`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin/-any/)
* [`Nothing`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin/-nothing.html)
* [`Unit`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin/-unit/)

Kotlin 还有不可表示类型（non-denotable types）。这类类型无法在 Kotlin 代码中直接书写，而是由编译器在内部使用，例如用于与其他语言的互操作。Kotlin 创建不可表示类型是为了表示比 Kotlin 源码语法所能表达的更精确的类型信息。

虽然你不能自己声明不可表示类型，但你可能会在编译器诊断信息、IDE 工具提示或推断类型的显示中遇到它们。关于不可表示类型的更多内容，请参阅：
