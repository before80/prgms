# 5.3 惯用法

这里汇集了 Kotlin 中一些零散但常用的惯用法。如果你有喜欢的惯用法，欢迎通过发送 pull request 来贡献。

## 创建 DTO（POJO/POCO） {#create-dtos-pojos-pocos}

```kotlin
data class Customer(val name: String, val email: String)
```

它提供一个具有以下功能的 `Customer` 类：

* 所有属性的 getter（如果是 `var` 还有 setter）
* `equals()`
* `hashCode()`
* `toString()`
* `copy()`
* 所有属性对应的 `component1()`、`component2()`……（参见[数据类](../5.8-Classesandinterfaces/5.8.2-DataClasses/)）

## 函数参数的默认值 {#default-values-for-function-parameters}

```kotlin
fun foo(a: Int = 0, b: String = "") { ... }
```

## 过滤列表 {#filter-a-list}

```kotlin
val positives = list.filter { x -> x > 0 }
```

或者更简短：

```kotlin
val positives = list.filter { it > 0 }
```

了解 [Java 与 Kotlin 过滤](../../interoperability/7.1-Javainterop/7.1.5-Javatokotlinmigrationguides/7.1.5.2-JavaToKotlinCollectionsGuide/#filter-elements)之间的区别。

## 检查集合中是否存在某个元素 {#check-the-presence-of-an-element-in-a-collection}

```kotlin
if ("john@example.com" in emailsList) { ... }

if ("jane@example.com" !in emailsList) { ... }
```

## 安全地读取标准输入 {#read-standard-input-safely}

```kotlin
// Reads a string and returns null if the input can't be converted into an integer. For example: Hi there!
val wrongInt = readln().toIntOrNull()
println(wrongInt)
// null

// Reads a string that can be converted into an integer and returns an integer. For example: 13
val correctInt = readln().toIntOrNull()
println(correctInt)
// 13
```

更多信息请参阅[读取标准输入。](../../libraryguides/9.1-Standardlibrary/9.1.2-ReadStandardInput/)

## 遍历映射或键值对列表 {#traverse-a-map-or-a-list-of-pairs}

```kotlin
for ((k, v) in map) {
    println("$k -> $v")
}
```

`k` 和 `v` 可以是任何方便的名称，例如 `name` 和 `age`。

## 遍历区间 {#iterate-over-a-range}

```kotlin
for (i in 1..100) { ... }  // closed-ended range: includes 100
for (i in 1..<100) { ... } // open-ended range: does not include 100
for (x in 2..10 step 2) { ... }
for (x in 10 downTo 1) { ... }
(1..10).forEach { ... }
```

## 用内联值类实现类型安全的值 {#use-inline-value-classes-for-type-safe-values}

```kotlin
@JvmInline
value class EmployeeId(private val id: String)

@JvmInline
value class CustomerId(private val id: String)
```

如果你不小心把 `EmployeeId` 和 `CustomerId` 弄混，就会触发编译错误。

> **注意：** `@JvmInline` 注解只对 JVM 后端有必要。

## 实例化抽象类 {#instantiate-an-abstract-class}

```kotlin
abstract class MyAbstractClass {
    abstract fun doSomething()
    abstract fun sleep()
}

fun main() {
    val myObject = object : MyAbstractClass() {
        override fun doSomething() {
            // ...
        }

        override fun sleep() { // ...
        }
    }
    myObject.doSomething()
}
```

## 非空简写 {#if-not-null-shorthand}

```kotlin
val files = File("Test").listFiles()

println(files?.size) // size is printed if files is not null
```

## 非空否则简写 {#if-not-null-else-shorthand}

```kotlin
val files = File("Test").listFiles()

// For simple fallback values:
println(files?.size ?: "empty") // if files is null, this prints "empty"

// To calculate a more complicated fallback value in a code block, use `run`
val filesSize = files?.size ?: run {
    val someSize = getSomeSize()
    someSize * 2
}
println(filesSize)
```

## 在 when 语句中返回 {#return-on-when-statement}


## 单表达式函数 {#single-expression-functions}

```kotlin
fun theAnswer() = 42
```

它等价于

```kotlin
fun theAnswer(): Int {
    return 42
}
```

这可以与其他惯用法有效地结合，从而得到更短的代码。例如与 `when` 表达式结合：

```kotlin
fun transform(color: String): Int = when (color) {
    "Red" -> 0
    "Green" -> 1
    "Blue" -> 2
    else -> throw IllegalArgumentException("Invalid color param value")
}
```

## 在对象实例上调用多个方法（with） {#call-multiple-methods-on-an-object-instance-with}

```kotlin
class Turtle {
    fun penDown()
    fun penUp()
    fun turn(degrees: Double)
    fun forward(pixels: Double)
}

val myTurtle = Turtle()
with(myTurtle) { //draw a 100 pix square
    penDown()
    for (i in 1..4) {
        forward(100.0)
        turn(90.0)
    }
    penUp()
}
```

## 把代码标记为未完成（TODO） {#mark-code-as-incomplete-todo}

Kotlin 标准库有一个 `TODO()` 函数，它总是抛出 `NotImplementedError`。它的返回类型是 `Nothing`，因此无论期望什么类型都可以使用。还有一个接受原因参数的重载：

```kotlin
fun calcTaxes(): BigDecimal = TODO("Waiting for feedback from accounting")
```

IntelliJ IDEA 的 Kotlin 插件理解 `TODO()` 的语义，并会在 TODO 工具窗口中自动添加一个代码指针。
